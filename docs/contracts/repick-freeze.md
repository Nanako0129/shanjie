# 改選後其他字不動（2026-10-08）

## 0. 起因與目標

使用者回報：打「ㄅㄢˇ ㄎㄨㄥˋ」（前文「要進」）出現「板控」；把第一個字改選成「版」之後，引擎重新解碼其餘的段，第二個字從「控」變成「空」，原本對的字被改錯。

- **實測（`imeshot`）**：
  - 小麥注音：「ㄗㄞˋ ㄧㄝˇ」預設「在野」，第一字改選「再」之後變成「再也」，會重算其餘的字。
  - 蘋果注音：「再也」第一字改選「在」→「在也」；「由於」第一字改選「遊」→「遊於」。兩例第二個字都沒變。推論蘋果是固定其餘的字，兩例還不能完全排除重算。
- **使用者決定（2026-10-08）**：學蘋果，改選只動選的那一段，其他已經顯示的字不動。

**目標**：在候選窗改選一段之後，那一段以外、改選前已經顯示的詞全部固定。改了幾個錯字就改幾次，不會改一個、翻一個。

## 1. 規則（`core/src/engine.rs` 的 `choose`）

改選範圍是 `[start, end)`。在加入改選的固定詞**之前**，依改選前顯示的路徑（`self.path`，逐詞、以音節為單位）處理。

- **詞與音節的對應**：`path` 的每個詞加上它佔的音節數，從解碼器帶出來（解碼時就知道每個詞用了幾個音節；標點是 1）。不用字數推算：疊加詞庫有字數和音節數不同的條目（`docs/contracts/s3a.md` 寫明疊加層沒有這個過濾）。`recompute_pred` 現在用字數推算起點，同一片改成用這個欄位。
- **固定詞要能分辨**：`Fixed` 加一個欄位 `frozen: bool`，這一片產生的固定詞是 `true`，使用者自己選的（候選窗、預測列）是 `false`。

規則：

1. **完全在範圍外的詞**（含標點）：變成固定詞，`Fixed { pre: None, key: None }`。已經是固定詞的照舊，不重複加。
2. **和範圍部分重疊的詞**：範圍外的那幾個音節，**逐音節**看顯示的字：
   - 該音節的讀音在詞庫裡有這個單字，就固定成單字固定詞（`pre: None, key: None`）；
   - 沒有（例如一個字跨兩個音節的條目）就不固定，留給解碼。
3. 改選的那一段照現行規則加入（`pre`、`key` 的學習語意不變）。
4. 之後照現行的 `refresh` 解碼：改選當下被固定的詞不變，只有沒被固定的音節（第 2 項的例外）會解碼。之後插入音節時，緊貼插入點的 frozen 詞照 §6.1 的規則決定放不放開（§6.1 取代本句原本「被固定的詞不再變」的說法）。
- 沒有語言模型的模式（S1 unigram）沒有 `path`，行為不變。
- 預測列選取（`choose_pred`）不在這一片，行為不變。

## 2. 和其他功能的關係

- **選字記憶（S4）**：新的固定詞 `pre` 是 `None`，送出時不學、不遺忘；改選的那一段照舊學。
- **刪除與插入**：新的固定詞和其他固定詞一樣，照 `docs/contracts/s3a.md` 的固定詞規則平移或移除。
- **即時預測（V3）**：預測鍵的失效規則照舊（`choose` 對右邊固定詞清 `key`）；新加的固定詞 `key` 本來就是 `None`。
- **之後新打的音節**：不受影響，照常解碼；已固定的詞不因新打的字而改變。
- **遺忘（S4 §1.5，⌘⌫）**：遺忘一個（讀音, 詞）時，`frozen` 為 `true` 而且（讀音, 詞）相同的固定詞一併移除。那幾個音節在**沒有那筆紀錄**的情況下重新解碼，其餘的固定詞（使用者選的與其他 frozen 的）照舊當前後文、不變。這是有固定詞時 §1.5「回到沒學過時的輸出」的精確意思，同一個 PR 把這句寫進 `docs/contracts/s4-learning.md` §1.5。使用者自己選的固定詞照現行規則（只清 `pre`）。

## 3. 驗收

1. **回報的情境**（`core/tests/`，真實模型、書面設定、前文「要進」）：打 ㄅㄢˇ ㄎㄨㄥˋ → 第一名「板控」；游標移到第一字後改選「版」→ 顯示「版控」。改動前的程式是「版空」（同一個測試在改動前要失敗，並在研究紀錄寫出）。
2. **部分重疊**：顯示成一個兩字詞時改選它的第一字，第二字固定成單字。例子以實際解碼為準：若 ㄗㄞˋ ㄧㄝˇ 預設是「在野」，改選「再」→「再野」（改動前若是「再也」就寫出）；若預設不是「在野」，挑另一個預設是兩字詞、改選第一字後改動前會變第二字的例子，寫進測試與研究紀錄。
3. **完全在外的詞**：三個以上的詞的句子改選中間一段，左右的詞逐字不變。
4. **字數和音節數不同的條目**：用 `with_lexicon`＋`set_lm` 造一個疊加條目（例如一個字佔兩個音節），讓它解碼在另一個詞旁邊，改選那另一個詞：引擎回傳 `Ok`、這個條目照原樣固定、組字區沒有被清掉。再造一個部分重疊、範圍外的音節沒有單字條目的情況：那個音節不固定、留給解碼，同樣回傳 `Ok`、組字區沒有被清掉。
5. **學習**：上面任一情境送出後，學習紀錄只有改選的那一段（和改動前比較紀錄筆數與內容）。
5b. **遺忘**（`core/tests/engine_learn.rs`）：兩個詞的句子 A＋B。教 A（A 的讀音下原本不是第一名的詞），解碼出 A；改選 B，A 被固定；對 A 的範圍開候選窗按 ⌘⌫。預期顯示＝A 的音節以 `lm::decode_segment` 直接解碼的第一名（同一個 profile、左邊同樣的開頭、右邊 `End::Next(B)`、沒有學習）接上 B。測試用這個程序算出預期字串，並寫出實際的例子。
5c. **預測起點**：`recompute_pred` 改用音節數後，既有的 V3 測試與 `sp-predict` golden 不變。
6. **不改到不改選的路徑**：`cargo test`（debug、release）、`swift test` 全綠；所有 golden 與評測摘要行（`shanjie-eval`／`lm_eval.py` 印的 `## …` 行）不變（沒有改選就沒有差別）。為了改選後重算而寫的既有測試若要改，逐一列出原因。
6b. **用改選模擬教學的量測**：改選後左邊的字固定，學到的前文 key 可能和以前不同。下列測試印出的數字，改動前後各記一次，寫進研究紀錄：`core/tests/engine_learn.rs` 的 `a2_candidate_pick_learning_on_cases_tsv`（同前文學會率、moot 組）、`mirror`（經 `global_eps_table` 印出的鏡像學會率）、`global_eps_table`（全域學會、污染）、`pollution_zai_taught_under_two_contexts`；`core/tests/engine_predict.rs` 用到 `teach_typing76_picks` 的測試。規則：這些測試的斷言仍要全過；斷言失敗是停止條件。斷言都過但數字變了，照實記進研究紀錄與 `docs/contracts/s4-learning.md` 對應的量測段（標明是 repick-freeze 之後重量），不算停止條件。
7. 文件：`docs/contracts/s3a.md` 的按鍵規則表與固定詞規則、`core/include/shanjie.h` 若描述了改選後的重算要跟著改；`docs/contracts/s4-learning.md` §1.5 加上有固定詞時的精確意思（§2 遺忘那一條）；研究紀錄記下實測與改法。
8. **實機**：`imeshot` 在書面設定的 App 打「要進」＋ ㄅㄢˇ ㄎㄨㄥˋ、改選第一字為「版」，畫面是「版控」；以及第 2 項選定的例子，畫面是固定後的結果。

## 6. 修訂一（2026-10-08，本地 code review 後）

review 實際跑出兩個問題：

- **改選後繼續打字**：打 ㄊㄚ ㄕˋ（他是）、第一字改選「她」、游標到尾端再打 ㄐㄧㄝˋ，第一版得到「她是界」（「是」被固定，不能和新音節合成「世界」）；沒有改選時是「他世界」。

- **遺忘不完整**：改選切開一個學過的詞時，切剩的單字被固定；⌘⌫ 遺忘那個詞只移除（讀音, 詞）完全相同的固定詞，切剩的字留在畫面上。

改法：

1. **插入音節時放開「只在合成新詞時」**（取代 §2「之後新打的音節」那一條，以及 §1 第 4 條原本「被固定的詞不再變」的說法）。音節索引一律用 `insert_token` 平移右邊固定詞**之後**的值；新音節佔 `[c, c+1)`。
   - 候選：左鄰 L 是 `frozen` 且 `end == c` 的固定詞；右鄰 R 是 `frozen` 且 `start == c + 1` 的固定詞。標點的固定詞不當候選（不會和音節成詞）。使用者自己選的固定詞（`frozen == false`）不當候選，照現行規則。
   - 暫時拿掉所有候選，照 `refresh_lm` 解碼一次（暫定解碼）。
   - **逐詞判斷**：L 放開的條件是暫定路徑裡有一個詞的音節範圍包含 `[L.start, c + 1)`（L 的**全部**音節加上新音節）；R 放開的條件是有一個詞包含 `[c, R.end)`。只涵蓋 L 或 R 的一部分音節不算，該詞照舊固定。字數和音節數不同的條目也照音節範圍判斷。

   - 刪除音節（`remove_syllable`）不變。
   - 效果：「她是」＋ ㄐㄧㄝˋ，「世界」包含「是」與新音節 →「她世界」；「版控」＋一個不和「控」成詞的音節，「控」放回、不變。
