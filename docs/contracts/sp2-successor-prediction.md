# SP 第二片：由前文後繼詞產生候選的即時預測（離線研究）

使用者 2026-10-07 決定：#44 的即時預測進 v0.3.0，**前綴補完正式上線，縮寫做成設定、預設關**；候選只由前文在語言模型裡的後繼詞產生，已打的注音只用來篩選。這一片量這個做法，給之後的介面契約與核心契約用。只做離線研究，不動核心、殼層、介面，不調參數。

第一片的定義（`docs/contracts/sp-partial-zhuyin.md`，以下記為 SP1）照用：詞庫 `lex`、候選身分、分數 `lm.word`、相容（SP1 §2）、樣本與位置（SP1 §3.1–§3.2）、悲觀名次與決定性順序（SP1 §1）。程式沿用 `experiments/sp/predict.py` 的函式（import，不複製）。

## 1. 做法

- `v = lm.history(lm.context_key(前文), lm)`（SP1 §1）。前文是空的、`context_key` 是空的（前文結尾是標點或非漢字），或兩字與一字的歷史都不在模型裡時，`v = <s>`；所以前文非空也可能是 `<s>`。
- `succ(v)`：模型裡 `v` 有保留二元組條目的後繼詞集合（`predict.succ_words`）。
- **候選**：`C(v, z) = { W ∈ lex 的字串 : W ∈ succ(v)，而且 W 和查詢 z 相容 }`。分數和 SP1 的 c 組相同（`lm.word(λ, v, W, lp_max)`）。
- **兩種模式**：
  - **P（預設，前綴）**：相容只用 SP1 §2 的前綴解讀。
  - **PA（縮寫設定打開）**：前綴解讀與縮寫解讀的聯集（SP1 §2 原樣）。
- **顯示**：`C` 非空才算「有預測」；`C` 是空的就什麼都不顯示。
- **對照**：SP1 的 c 組（全部相容字串、聯集、同一個分數），在同一批樣本、同一個位置上算。

## 2. 評測

- **資料與樣本**：和 SP1 §3.1 相同的檔案、抽樣種子 20261007、樣本定義與丟掉規則。
- **位置**：P1–P4 用 P 與 PA 兩種模式各算一次；A1、A2 只在 PA 模式算。
- **母體**（每個樣本剛好屬於一個，各印樣本數，加總等於保留的樣本數）：
  - **M（主要）**：`W*` 兩字以上，`v ≠ <s>`。
  - **S0**：`W*` 兩字以上，`v = <s>`，前文是空的。
  - **S1**：`W*` 兩字以上，`v = <s>`，前文非空。
  - **U**：`W*` 單字（不分 `v`）。
  - 每個母體各自一張表；下面的指標都在母體內算。
- **每個位置的指標**：
  - 顯示率：`C` 非空的比例。
  - **hit@k**（k = 1、5、9）：分母是全部樣本，沒有顯示或 `W*` 不在 `C` 都算沒中。
  - **顯示時的 hit@k**：分母只算有顯示的樣本。
  - **空顯示率**：（有顯示而且 `W*` 不在 `C` 的樣本數）÷（有顯示的樣本數）。
  - `|C|`：只算有顯示的樣本（`|C| ≥ 1`），報中位、p95、最大；沒有顯示的比例看顯示率。
- **省鍵率 KS(k)**（k = 1、3、9）：P 模式的前綴按鍵序列，定義同 SP1 §3.2，名次在 `C` 裡算。
- **第一名翻轉率**：P 模式，定義同 SP1 §3.2，只算前後兩鍵都有顯示的鍵對；分母另報。
- **配對檢定**：V3-P 對 c 組，P1 與 P3 的 hit@9（每個樣本的對錯），母體 M；每個集合、每個設定一個 McNemar 精確檢定（雙尾），n 等於 M 的樣本數。
- **時間**：Python 每次查詢（求 `C`、算分、取前 64 名）p50／p95。
