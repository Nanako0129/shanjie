# 契約：經典台詞詞包（quote pack）

狀態：READY（2026-10-22；plan-verifier REVISE 五項照改後，收尾審查 READY）。已實作（分支 `feat/quote-pack`，2026-10-22）：建置工具、引擎位元、CLI、App 開關、打包與測試；2026-10-29 合併 main 並換上核對過的清單（208 句，核對來源皆填；逐句找文字來源核對，查無來源的 26 句不收），重建的詞包有 278 個分句、311 列讀音，版號 c5584db7；§3 開著時的評測與實機還沒做。

## 0. 起因、要做到什麼、怎麼看到

- **維護者 2026-10-22 提議**：「加入經典電影台詞詞包，主要是一些華語、港片之類的」。例句是「你開馬自達，難怪你遲到」「吃著火鍋唱著歌」。同日兩題選擇題的結果：
  1. 預設關，在設定裡開。
  2. 來源不限維基語錄，以收齊為主：「本身這些已經是梗了沒有版權，主要是能收齊比較重要」。各種來源都可以，維護者與 Discord 補充。每句仍要核對原文用字。
- 同日決定「現在開始」：先寫契約與收集清單，在 Discord 開討論請大家補。
- **要做到**：
  - 打一句經典台詞的注音時，開了詞包，台詞的每一個分句都能整串選對。
  - 詞包關掉時，選字和沒有這個詞包的引擎逐位元組相同。
  - 開了詞包，一般句子不受影響（§3 的評測）。
- **怎麼看到**：
  1. 建置工具對清單裡每一個分句，開詞包解碼的第一名就是那個分句（兩種設定）；做不到的分句列出來，不默默丟掉。
  2. 評測集合開與關的比較（§3）。
  3. 實機：維護者在設定打開「經典台詞」，打兩句台詞看到選對；關掉後回到原本的選字。

## 1. 收集與清單

- **清單檔** `data/packs/quotes-manual.tsv`，一列一句台詞。欄位：
  1. 台詞原文（含標點）；
  2. 出處（電影或劇名）；
  3. 年份；
  4. 核對來源：網址、片段時間點，或「維護者核對」；
  5. 收錄人：維護者、Discord 暱稱，或「起始清單」；
  6. 選填的讀音：分句的注音，以 `｜` 分隔各分句，給讀音工具標錯的字用。
- `#` 開頭是註解。
- **每句都要核對原文用字才收**：
  - 核對欄空白的列，建置工具拒絕收錄，並列在報告裡。
  - 同一句有不同說法（電影原版、廣為流傳的版本）時，維護者決定收哪一種或兩種都收，寫在備註。
- **起始清單**：
  - 我先列一批大家熟的華語、港片台詞，例如周星馳、成龍、經典國片。核對欄先空著，標「待核對」。
  - 維護者與 Discord 補充並核對。核對過的才進詞包。
- **Discord**：
  - 在開發討論串貼起始清單，請大家補台詞、附出處。
  - 只收公開影視作品的台詞，不收私人訊息的句子。
- **授權**：
  - 台詞是短句、廣為流傳，維護者的判斷是不涉版權。
  - 清單檔以 CC0 釋出。每列記出處與核對來源，`LICENSES/data.md` 加一列。

## 2. 詞包與引擎（照 ACG 詞包的機制）

- **建置工具** `tools/build_quote_pack.py`：讀清單，產生 `data/packs/quotes-add.tsv` 與 `data/packs/quotes.json`。
  - **分句**：在標點（，。！？、；：…以及全形與半形的引號、刪節號、空白）處切開。每個分句 2 到 10 個字，當成一個詞條。超過 10 字的分句不收，列在報告裡：分數規則（`build_overlay.py` 的 `length_scores`）只涵蓋 2–10 字，而且引擎每個位置要試的詞長由詞庫最長的詞決定（現在是 ACG 的 10 字），收更長的分句會讓每一鍵多試幾種長度。11 字以上要另寫分數規則並量延遲，之後另議。分句裡如果有英文、數字等不是漢字的字元，那個分句不收，並列在報告裡。
  - **讀音**：用 `tools/readings.py`，清單第 6 欄有讀音時以它為準。標 CHECK 的列在報告裡，交維護者看。
  - **「一」「不」的變調列**：含「一」「不」的分句，照 `build_overlay.py` 加變調列，扣分照它的 `VARIANT_PENALTY`。衝突檢查與報告的解碼都包含變調讀音。
  - **分數**：照 ACG 詞包的規則（`tools/build_overlay.py` 的同字數第 25 百分位）。
  - **去重**：分句已經以同一個字串出現在基底、`overlay-add.tsv`、`sandhi-add.tsv`、`names-add.tsv` 或 ACG 詞包的任何讀音下，就不收。這照 ACG 詞包 A.1 的理由：`CappedLexicon` 會封頂同名詞條。
  - **衝突**：照 ACG 詞包 A.1 的 (c)。開了詞包後，某個讀音的第一名由既有詞變成台詞分句，就是既有詞被擠掉。這時既有詞勝，那個分句不收，寫進報告。
    - **解碼設定**：用出貨的 `data/lm/` 模型，雜湊寫成建置工具的具名常數，開始前核對。「不開」與「開」兩次解碼都帶 ACG 詞包（照出貨），兩種設定（聊天、書面）都做。使用者關掉 ACG、只開台詞的組合不另外解碼：被 ACG 詞蓋過的基底詞，在這個組合下可能被台詞分句擠掉而建置看不到（審查 2026-10-23 指出；〔推論〕台詞分句 2–10 字、和基底詞同讀音的少，這一版不量）。
    - **既有詞**的範圍：基底、`overlay-add.tsv`、`sandhi-add.tsv`、`names-add.tsv`、ACG 詞包的詞。
    - 同一份輸入建置兩次，輸出逐位元組相同。
  - **報告**：每個分句開了詞包時，在聊天與書面各自的第一名是不是它自己。不是的列出來，不默默丟掉。
- **引擎**：
  - `PACK_QUOTES = 2`，`PACK_FILES` 加 `quotes-add.tsv`，`PACK_ALL` 跟著更新（2026-10-29 合併 main：資訊詞包佔了位元 2，`PACK_ALL = PACK_ACG | PACK_QUOTES | PACK_IT`，`PACK_FILES` 依 ACG、台詞、IT 的順序）。
  - C ABI 的遮罩說明加 bit1，同時改 `core/include/shanjie.h` 與 `docs/contracts/s3a.md`。
  - 載入、封頂、檔案不存在時的行為，全部照 ACG 詞包 A.2。
  - CLI 的 `--packs` 接受 `quotes`（也可以 `acg,quotes`）。
- **App**：
  - 設定視窗「詞包」區塊加「經典台詞」開關，偏好鍵 `quotePack`。偏好鍵沒設過就當成**關**，打開後寫入 `true`。
  - 切換時照 ACG 詞包重建引擎。
  - `scripts/build-app.sh` 打包 `quotes-add.tsv`，`check-app.sh` 核對它的 SHA-256。
  - selftest 不加這一項：預設是關的。

## 3. 評測

- **關掉時**：兩組都要和 main 逐位元組相同：沒有詞包一組、`--packs acg` 一組（出貨設定），各跑聊天與書面，比 dev302、打字測驗、錯字回報的 `top1_sha256`。golden 不變。
- **開著時**：
  - 對 main（不開台詞詞包；ACG 開著，照出貨）比較 dev302、打字測驗、錯字回報兩種設定，以及 discordtune、cvtune-clean 聊天（GCP）的選字。
  - 每一列不同都列出來（公開集合可以寫句子，私人集合只寫數字）。
  - 照出貨標準的規則判：改壞 ≤ 2 且淨值 ≥ 0，或逐列相同。
  - 〔推論〕預期幾乎都逐列相同：台詞分句很少出現在一般句子裡。
- **台詞本身**：報每個分句開詞包時在兩種設定的第一名是不是它，以及有多少比例的分句不開詞包也已經是第一名。

## 4. 驗收、停止條件、範圍外

- **驗收**：
  - 建置工具與測試（`make test-python`）；
  - 引擎與 App 的測試（`make test-rust`、`make test-swift`）：詞包關掉時逐位元組相同，開著時能載入，遮罩與偏好鍵正確；`quotePack` 沒設過時，傳給 `shanjie_engine_new_packs` 的遮罩沒有 `SHANJIE_PACK_QUOTES` 那一位（2026-10-29 合併 main 後，資訊詞包預設開，遮罩是 ACG 與 IT 兩位，值 5；Swift 測試斷言）；建置工具的測試涵蓋 11 字分句進報告不崩潰、和 `names-add.tsv` 同字串的分句不收、含「不」的分句有變調列；
  - §3 的評測；
  - 實機（維護者）。
- **停止條件**：
  - 關掉時有任何不同；
  - 開著時評測超過「改壞 ≤ 2 且淨值 ≥ 0」；
  - 授權或來源有疑問的台詞。這些列交維護者決定，不收。
- **回滾**：revert 本片的 merge commit。詞包預設關，使用者不開就不受影響。
- **預算**：GCP VM ≤ 1 小時，只用來跑私人集合的開與關比較。
- **範圍外**：
  - 自動從字幕檔抓台詞；
  - 台詞的前後文預測（打前半句就提示後半句）；
  - 詞包 Release 與獨立更新。這兩件照 ACG 詞包的 B、C 片，之後再說。
