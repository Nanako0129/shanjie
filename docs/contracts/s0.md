## 2. 詞庫（`ime.py` `Lexicon`）

- 逐行讀；以 `#` 或 `_` 開頭的行略過；以空白切欄，欄數 ≠ 3 略過；`讀音 詞 分數`，讀音以 `-` 切成音節；詞長（Unicode code point 數）≠ 音節數略過。分數用 f64 解析（與 Python `float()` 相同）。
- `by_reading[音節序列]`：依檔案順序收 `(詞, 分數)`，最後依分數**由高到低穩定排序**（同分保留檔案順序）。同一讀音下可能有重複的詞，照收。
- `by_word[詞]`：只在「第一次出現」或「分數嚴格大於現有值」時寫入 `(音節序列, 分數)`；同分保留先出現的。
- `max_len`：所有讀音的最大音節數。

## 3. 讀音產生（`to_syllables`）

字元 DP：`best[0]=0`，其餘 −∞；`i` 從 1 到 n，`L` 從 1 遞增到 `min(max_len, i)`，`w = text[i-L..i]`（以 code point 切），`w` 在 `by_word` 且 `best[i-L]` 有限時，`s = best[i-L] + 分數`，**嚴格 `>`** 才取代 `best[i]` 與回溯點。`best[n]` 為 −∞ 時回傳「無」。回溯得到詞序列，攤平成音節序列。

## 4. 解碼（`decode`，beam N-best）

參數：`BEAM = 32`、`PER_KEY = 12`。

```
hyps[0] = [(0.0, [])]
for i in 1..=n:
    cand = 依插入順序的 map：surface 字串 → (分數, 詞序列)
    for L in 1..=min(max_len, i):            # L 遞增
        key = syls[i-L .. i]
        entries = by_reading[key]；不存在或 hyps[i-L] 為空就跳過
        for (word, lp) in entries 的前 PER_KEY 個:
            for (s, ws) in hyps[i-L]（依序）:
                prev = ws 的最後一個詞，空的話是 "<s>"
                sc = (s + lp) + bonus(prev, key, word)    # 浮點運算順序照此
                surface = ws 串接 + word
                若 surface 不在 cand，或 sc 嚴格大於 cand[surface].分數：
                    cand[surface] = (sc, ws + [word])
                    # 注意：取代時保留該 surface 第一次插入的位置（Python dict 行為）
    hyps[i] = cand 的值依分數由高到低**穩定排序**後取前 BEAM 個（`heapq.nlargest` 同分時保留迭代順序）
回傳 hyps[n]
```

## 5. 學習策略（`NoLearning`、`GlobalBoost`、`ContextKeyed`、`Promotion`）

照 `ime.py` 逐行移植。兩個容易漏的副作用：

- `GlobalBoost.bonus` 與 `ContextKeyed.bonus` 用 `dict(by_reading[讀音])[詞]` 取分數：同讀音下重複的詞取**最後一筆**；`best` 取 `by_reading[讀音][0]` 的分數。
- `Promotion.bonus` 在計數 ≥ 3 時會寫入 `top[讀音] = 詞`（在 bonus 裡有副作用）。

`segment_words`、學習模擬 `simulate` 與 `LEARN_CASES` 照 `eval.py` 移植。

## 6. 評測（`eval.py` `evaluate`、`load_rows`、`load_moedict`）

- `trap`、`daily`：逐行讀，去掉行尾換行；空行與 `#` 開頭略過；在第一個 `|` 切成 `前文|句子`。若有第二個 `|`，之後是**確認過的讀音**（以空白分隔音節），此時直接使用、不呼叫 `to_syllables`。
- `moedict`：整檔以空白切開（Python `str.split()`），每一個是句子，前文為空。
- 評測前剔除 `to_syllables` 回傳「無」的列（有讀音欄的列不剔除）。
- 每句取 `decode` 的第一名當輸出；`oracle` 是正解是否在整個 N-best 裡。
- 指標：`n`（整數）、`sent_acc = round(對的句數/n, 3)`、`lenient_acc = round(寬鬆對的句數/n, 3)`、`char_acc = round(逐位置相同的字數/總字數, 4)`（以 code point 比、`zip` 到較短者）、`oracle@32 = round(命中數/n, 3)`。寬鬆對照：`她妳它牠嘗周臺裏` → `他你他他嚐週台裡`，兩邊都轉換後比較。
- `round` 必須與 Python `round(x, k)` 相同（對二進位浮點值做正確捨入、half-even）。建議作法：`format!("{:.k$}", x)` 再解析回 f64，以最短可往返的十進位輸出；整數值補 `.0`（Python 印 `1.0`，Rust 預設印 `1`）。

## 7. CLI 與輸出

`shanjie-eval [--set NAME ...] [--learn-sim] [--check-readings] [--bench]`

- `NAME`：`trap → 同音陷阱集`（`eval/sets/trap.txt`）、`daily → 日常驗證集`（`eval/sets/daily.txt`）、`moedict → 萌典例句`（`eval/sets/moedict.txt`）、`dev → 開發集`（`eval/dev/*.txt`）、`holdout → 保留集`（`eval/holdout/*.txt`）。
- 輸出必須與 `eval/golden/unigram.txt` **逐位元組相同**，指令為 `shanjie-eval --set trap daily moedict --learn-sim`。golden 就是規格；只看 golden 才知道的格式：
  - 每個集合區塊前有一個空行，標頭為 `## <中文集名>  unigram  <dict>`，`<dict>` 與 Python `repr(dict)` 逐字相同（單引號、key 順序 `n, sent_acc, lenient_acc, char_acc, oracle@32`）；
  - 萌典以外的集合在標頭後列出錯句，每行 `   ✗ 正解 → 輸出`（三個空白開頭）；萌典不列；
  - 學習模擬區塊與表格格式照 `eval.py` 的 f-string（欄寬以 code point 計，含行尾空白）。
- `--check-readings`：在其他輸出之後，對每個有讀音欄的集合印 `## 讀音檢查  <中文集名>  {'rows': N, 'mismatch': M}`；沒有這個旗標時不得多印任何東西。
- `--bench`：另外印 decode 每句延遲的 p50／p95（release build、三個集合合計 409 句）；同樣只在帶旗標時印。

## 8. 錯誤處理（安全規則 R2）

核心所有 `Err` 與 panic 訊息只能帶錯誤種類與長度，**不得包含輸入的讀音或文字**。要有一個測試：用一段標記字串觸發錯誤路徑（例如無效音節或空詞庫查詢），斷言錯誤訊息不含該標記。

## 9. 實作限制

- Cargo workspace：`core`（函式庫）、`cli`（`shanjie-eval`）。只用標準函式庫；真的需要外部 crate 時先停下回報（安裝相依需要網路，要另外核准）。
- 不得 `git push`、不得建立遠端、不得碰鑰匙圈、不得開 GUI App、不得修改 §1 的輸入檔與 `reference/`。
- 可以在本機執行 `python3 reference/proto/eval.py` 對照（需要先把它的路徑常數指向本 repo 的檔案，或用暫存複本；不要改 `reference/` 裡的檔案）。

## 10. 驗收（PLAN.md S0）

1. `cargo run --release -p cli -- --set trap daily moedict --learn-sim | diff - eval/golden/unigram.txt` 為空；
2. 把輸出餵給 `reference/proto/summarize.py`，印出 unigram `74/109` 與萌典 `57.3%`；
3. `cargo test` 綠；mutation 抽查一次（破壞同分規則或 beam 截斷）測試會失敗，看 exit code 與失敗斷言，不看編譯錯誤；
4. `--bench`：p95 < 5 ms；
5. R2 測試（§8）；
6. 三欄讀音解析與 `--check-readings` 有單元測試（含一列故意不一致會被抓到），加入後第 1 條仍為空。
