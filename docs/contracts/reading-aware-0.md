## 0. 依據

- 維護者 2026-10-16 問「現在選字機率會因為音調有所不同嗎？」（吧／巴）；查過：語言模型的計數不分讀音，`吧` 在聊天設定 −4.67、`巴` −4.17，和打的是 ㄅㄚ 或 ㄅㄚ˙ 無關。
- Fable 的分析（研究紀錄 2026-10-17「讀音感知 n-gram」）：
  - 解碼時讀音只用在詞庫查表（`core/src/lm.rs` `decode_segment_learned`、`reference/proto/lm.py` `decode`），語言模型的鍵是詞字串；計數（`experiments/s2/build_counts.py` 的 `expected_counts`）也沒有讀音。
  - 詞庫裡同時有輕聲與本調讀音的單字有 97 個；扣掉分數都是最低值 −6.80／−7.90 的列，多數兩個讀音的分數完全相同，是照抄的，不是量的。「巴 ㄅㄚ˙ −3.99」就是這樣贏過「吧」。這一層不用重算模型就能修。
  - 真正會隨前文改讀音的破音字（長、行、重、還、空、得、地、著……）要讓計數分讀音，才需要重建模型；在現有評測集上能救的推論很少。
  - 用一聲打「吧」「啦」的人不能變差：真人打法的集合裡，語尾字單獨成詞時，打輕聲 10 列、打一聲 17 列，兩種都有。
- 維護者 2026-10-17 的選擇題：第一片「四臂一次做完」；降權清單「我列建議，你看一眼」（§3.2 的清單送維護者過目後凍結）。

### 3.4 B：讓計數分讀音

- **單位**：
  - 多字詞：一個詞一個單位，不拆讀音。詞庫裡多字詞的多讀幾乎都是打法差異（比較、我們、為什麼）。
  - 單字：詞庫裡只有一個讀音的字，單位就是字本身；有兩個以上讀音的字，（字, 讀音）一個單位，字串寫成 `字 U+0001 讀音`（音節以 `-` 相接，同詞庫寫法）。
  - 標上的讀音一定是詞庫裡這個字確實有的讀音；規則給出的讀音不在詞庫時，改標主要讀音並計數。
- **標注**：只看原文的字元位置（異體合併之後的文字），不看斷詞路徑；同一個位置在所有切法上得到同一個標注。符號：c＝這個字，p＝前一個字，p2＝前兩個字，n＝後一個字，n2＝後兩個字（不存在時為空）。
  - 主要讀音：同 `tools/readings.py` 的規則 0、1、3、4（人工表 → 「一」「不」本調 → `heterophony1.list` → 詞庫第一名）；不用規則 2（萌典只能用在評測輸入）。
  - 語尾字（§3.3 白名單）有 ˙ 讀音的，標 ˙；沒有 ˙ 讀音的（喔、哦、欸、咧、囉），標主要讀音。
  - 了 → ㄌㄜ˙；的 → ㄉㄜ˙。
  - 得：p ∈ {不 非 總 就 也 都 還} 而且 n ∉ {很 太} → ㄉㄟˇ；其餘 → ㄉㄜ˙。
  - 地：p2 ＝ p（疊字，例如慢慢地）→ ㄉㄜ˙；其餘 → ㄉㄧˋ。
  - 還：n ∈ {錢 給 你 我 他 書 債 款 清} → ㄏㄨㄢˊ；其餘 → ㄏㄞˊ。
  - 重：n ∈ {新 做 來 打 建 組 複} → ㄔㄨㄥˊ；其餘 → 主要讀音。
  - 空：p ∈ {有 沒 抽 撥 得}，或 n ∈ {出 位 缺 檔}，或 n2 ＝ 下來 → ㄎㄨㄥˋ；其餘 → 主要讀音。
  - 長：n ∈ {大 得 出 在 成 高 歪 相} → ㄓㄤˇ；其餘 → 主要讀音。
  - 行：p 是數字（〇 一 二 三 四 五 六 七 八 九 十 百 兩 幾，或 ASCII 數字）或 p ∈ {這 那 每 各 第} → ㄏㄤˊ；其餘 → 主要讀音。
  - 其他字（含和、著、為、好、教、數、種、處、當、應、只）：主要讀音。
  - 規則的來歷：Fable 2026-10-17 的分析（研究紀錄同日一節），每條都只是近似，準不準由下面的人工抽樣量。
- **計數與建模**：
  - 照 model-v6 步驟 1 的配方，在 Colab G4 重算計數（`experiments/derisk-1015/e1/count.py` 的管線）；`expected_counts` 的每條邊從詞字串改成單位。改的是 `experiments/reading-aware/` 裡的包裝，`experiments/s2/build_counts.py` 不動。
  - 異體合併照 B0 的做法以字為鍵（`build_counts.py` 的 MERGE、`tools/build_lm.py` 的 `merge_variants`）：先合併字，再把讀音接上去。
  - 用 `tools/build_lm.py` 建 B0u：不加指紋、不加私有條目。
  - **計數錨點**：同一個包裝用「恆等標注」（每個單位就是詞字串，不接讀音）跑完整條計數與建模，結果必須和 B0（`f7777be3…`，derisk-1015 E1，和 model-v6 的無指紋版逐位元組相同）逐位元組相同。
- **解碼**（`experiments/reading-aware/` 延伸 `lm.py`，不改 `reference/proto/`）：
  - 單字詞條的詞項：lp 照 B0（詞庫分數；疊加層的詞照 B0 封頂，次數用這個字所有單位的總和），不另外封頂。
  - 語言模型的項 P(單位 | 前一個單位)：
    - 單位在模型裡 → 用它。
    - 這個字有單位、但不是這個讀音（語料裡從沒被標成這個讀音）→ P(字 | 前一個) × 占比。P(字 | 前一個) 是這個字所有單位的機率和；占比是這個字在詞庫各讀音的分數換成機率後，這個讀音所佔的比例。不用 `UNSEEN_OVERLAY_PENALTY`。
    - 這個字完全沒有單位 → 和 B0 一樣走詞彙外的路徑。
  - 多字詞照舊。
  - 前文（已送出的字，沒有讀音）取那個字串次數最多的單位。
  - 每個字只有一個單位時，上面的規則和 B0 逐位元相同。
  - 解碼錨點：用 B0 跑延伸版，摘要行與 `top1_sha256` 要和 `lm_eval.py` 逐字相同。
- **兩臂**：兩臂都加 `--no-classes --no-kn --no-tri`；詞類、KN、三元表要跟著單位重建，這一片不做。
  - 對照：B0 加 A1 的表。
  - 候選：B0u，不加 A1 的表。「巴 ㄅㄚ˙」這類讀音在語料裡沒有被標到，語言模型的項會乘上占比，效果和 A1 同方向。
  - 量到的是「讀音分開計數」在 A1 之外多出來的效果。
- **另外單獨報**（只報）：
  - 用一聲打語尾字的列：真人集合裡的這些列，加上 §3.3 的探針列，在 B0u 對 B 的對照上各一行 `--net`。
  - 判讀五集裡改壞的列，有多少列的第一名變化落在「用占比」的單字上。
- **標注錯誤率**：
  - 從維基與口語訓練文字（都是公開語料，已在 `~/.cache/shanjie/sources`）各抽 150 句，句中要有短名單字（得 地 還 重 空 長 行）單獨成詞，固定種子。
  - main 逐句判讀這些位置的標注，報整體錯誤率與每個字的錯誤率。
  - 評測集的第三欄不能拿來量：它們也是 `readings.py` 產生的，一致率必然接近 100%。
