# 選字機率：貝氏選字記憶（實作在測試用設定後面＋量測，不換預設）

使用者 2026-10-10：「選字機率也可以開始進行」。PLAN「貝氏使用者學習（S4）」的第一片。選字記憶的規則在 `docs/contracts/s4-learning.md`（以下稱 S4），這份只寫改了什麼。

## 0. 依據

- **現行規則**（S4 §1.4、§12、§13）：查到權重 ≥ 0.5 的紀錄時，該詞的詞庫分數改成 `max(原分數, 同讀音最高分 + ε × w／(w + 1))`；完整前文與 1 字比對兩層 ε = 6.0（`LEARN_EPS`），全域這一層 ε = 0（`LEARN_EPS_GLOBAL`，關閉）。
- **全域這一層為什麼關**（S4 §13）：詞類項（S2k）之後，ε_global 從 0.1 到 0.5 都至少有一個常用句被改壞（`global_eps_table`）。固定的加分不管證據多少都一樣大，一次改選就足以在任何前文翻掉一個接近平手的常用詞。
- **固定 ε 的另一個問題**：加分和語言模型原本多確定無關。冷僻詞被改選一次，和常用詞被改選一次，加的分一樣。
- **貝氏的做法**（PLAN）：把改選紀錄當成觀測，先驗來自語言模型，用後驗取代固定的 ε。證據少時後驗接近語言模型，證據多時接近使用者的選擇；全域那一層用比較強的先驗，要很多次改選才會動。

## 1. 模型

對一個段落（讀音 r，起點的前文 key），解碼器在某個假設 h 之後，把這個段落的每個候選詞 u 算出原本的詞分數 `t(u) = word_term(λ, prob_c(h.ctx, u, pb), lp)`（現行的值，log10）。只在這個讀音**有學習紀錄**時才做下面的事；沒有紀錄的讀音完全照舊。

1. **語言模型的分布**：`q(u) = 10^t(u) / Σ_v 10^t(v)`，v 跑過這個段落、這個假設之下**能當候選**的所有詞：前 `PER_KEY` 名的詞，加上符合下面「列舉規則」的「不在前 `PER_KEY` 名」的詞（extra）。分母就是這個集合，不含不能當候選的 extra。
   - **列舉規則**（取代 S4 §1.4 與 §13 規則 1 在後驗模式下的寫法）：extra 詞 u 只在 `c_x(u) > 0`，或 α_g 有限而且 `c_g(u) > 0` 時能當候選；其他情況照現行程式跳過（`continue`）。α_g = ∞ 時全域紀錄不讓詞進列舉，等於 S4 §13 規則 1。
2. **全域後驗**：`g(u) = (α_g · q(u) + c_g(u)) / (α_g + C_g)`。`c_g(u)` 是全域紀錄（前文為空，S4 §1.3 的全域化規則照舊：2 種以上完整前文才產生）的衰減後權重，`C_g = Σ c_g`。沒有全域紀錄時 `g = q`。α_g = ∞ 代表全域這一層關閉（`g = q`）。
   - **c_g 的來源**：一律另外查全域紀錄，不管完整前文或 1 字比對那一層有沒有查到。`core/src/learn.rs` 新增 `Learner::lookup_global(reading, today) -> Vec<(&str, f64)>`（權重門檻 `ACTIVE` 與單字規則照 `lookup`：單字沒有全域紀錄），解碼器在後驗模式下對每個（段落, 讀音）呼叫一次。現有的 `lookup` 不改；它回 `Level::Global` 時，那些命中只算進 c_g，**不算** c_x（`c_x = 0`）。
3. **前文後驗**：`p(u) = (α_c · g(u) + c_x(u)) / (α_c + C_x)`。`c_x(u)` 是 `Learner::lookup` 回 `Level::Exact` 或 `Level::LastChar` 時的權重（同一個查詢順序、同一個單字規則：單字只用完整前文、不用「^」），`C_x = Σ c_x`；`lookup` 回 `Level::Global` 或沒有紀錄時 `C_x = 0`、`p = g`。
4. **新的詞分數**：`t'(u) = t(u) + log10(p(u) / q(u))`。
   - **變體 R（只往上提）**：`t'(u) = t(u) + max(0, log10(p(u)/q(u)))`。保留 S4 §1.4「學習只能把詞往上提，不能壓低其他詞」的原則。
   - **變體 D（重新分配）**：照公式，沒被選的同讀音詞會被壓低（這個段落的機率總和不變）。這改變了 S4 §1.4 的原則，只在量測裡比較；要出貨 D 要使用者決定（§5）。
5. 權重門檻（`ACTIVE` = 0.5）、衰減、改選走（舊詞減半）、全域化、修剪、忘記、單字規則、檔案格式：**全部不變**。這一片只改「查到紀錄之後分數怎麼算」與 extra 的列舉規則。
6. **後驗模式下不用 ε**：`LEARN_EPS`、`eps_global` 的加分在後驗模式下完全不作用（不疊加）；現行規則模式下照舊。

說明：
- `c` 用的是現有的衰減後權重，不是整數次數，所以 α 是「相當於幾次改選」的先驗強度。
- 後驗作用在整個詞分數（含 bigram 項），不是只改 `lp`。現行規則只透過 `(1−λ)·lp` 與回退項起作用，所以要很大的 ε（6.0）；這裡的效果由 α 決定，不必再調 ε。
- 計算只在有紀錄的讀音上做，每個（假設, 段落）多一次對候選的加總。

## 2. 參數與選法

- 格點：α_c ∈ {0.5, 1, 2, 4}，α_g ∈ {4, 8, 16, 32, ∞}，兩個變體 R、D。共 40 組，加上現行規則（ε 6.0／0）當基準。
- 依 S4 現有的自動測試量（§3），**選法事先寫死**：
  1. 必要條件：ㄗㄞˋ 污染測試與全域污染測試都 0 退步；鏡像測試學會率 ≥ 基準；A2 同前文學會率 ≥ 基準；空的學習檔逐位元組等於 golden。
  2. 符合必要條件的組裡，全域學會率最高的；同分取 α_g 較大的（全域動得較少）；再同分取 α_c 較大的；再同分取 R。
- **選法用的資料**（CLAUDE.md：調參數用 cvtune、wikitune，不用 dev302）：鏡像與 A2 用 `eval/learn/cases.tsv`；兩個污染測試在選法裡用寫死的三句（另外現在在做、我現在在家、他在學校）加上 **cvtune 與 wikitune**（`31de456d…`、`8dcfe40c…`）裡含教學讀音的列，各帶自己的前文，取代現有測試裡的 dev302 列。調參集不在 repo 裡，所以掃描表是一個 `#[ignore]` 的整合測試，用環境變數 `SHANJIE_TUNE_DIR` 指到兩個檔（先核對 SHA-256，不符就失敗），由 main 在本機跑；CI 照舊跑其他測試。
- **dev302 只報數字**：同一張表另外印 dev302 版本的兩個污染數字，不參與選法；選出的那一組在 dev302 版本有任何污染退步，寫進結論並標成下一片的阻礙（不改選別組）。
- **保留集**：這一片不跑。學習檔是空的時候輸出逐位元組不變（§3 第 5 項），保留集量不到學習的效果；學習效果由上面的教學測試量。

## 3. 驗收

1. **第 0 步**：在 main 上量基準（現行規則）：鏡像測試、A2、ㄗㄞˋ 污染、`global_eps_table` 的全域學會率與全域污染（ε_global = 0）。寫進研究紀錄，之後的比較都用這組數字。
2. **實作**：`core/src/lm.rs` 加後驗的算法，用 `Learn` 裡的參數（變體、α_c、α_g）決定；`Engine` 加一個和 `set_eps_global` 同樣做法的測試用設定。出貨的預設值**照舊是現行規則**（§1.4 的 ε，這一片不換，見第 4 項），所以合併後使用者端行為不變。
3. **掃描表**：40 組 × {鏡像學會率, A2 同前文學會率, ㄗㄞˋ 污染退步數, 全域學會率, 全域污染退步數}（污染用 §2 的調參集列；dev302 版本另列），加上基準列。寫成 `#[ignore]` 的整合測試（§2），印表並斷言：
   - 有組符合 §2 的必要條件時，印出照 §2 選出的那一組（斷言它確實符合）；沒有時印「保留現行規則」，測試照樣通過；
   - **有效性**：至少一組後驗設定在鏡像測試學到東西（learned > 0）；α_g = ∞ 的各組全域學會率都是 0；至少一組 α_g 有限的設定全域學會率 > 0。
4. **選定（不換預設）**：照 §2 選出一組，寫進研究紀錄與 PLAN，當成下一片的建議；沒有任何組符合必要條件就寫「保留現行規則」。**這一片不改出貨的預設**：`Learn` 的預設照舊是現行規則（ε 6.0／0），現有測試（`global_eps_table`、`zero_global_eps_keeps_beyond_per_key_words_out`、`mirror`、A2、ㄗㄞˋ 污染等）照舊在現行規則下跑、照舊通過，不改任何既有的斷言。換預設要另開一片：那一片要寫明哪些只看 ε 的測試改成明確指定現行規則、後驗預設改由哪些檢查守住，並加使用者實機確認。
5. **一般集合不變**：空的學習檔時，dev302、打字測驗、錯字回報的輸出逐位元組不變（golden 測試照舊）。
6. **延遲**：`perf_full_store_per_key_and_enter_with_write` 照舊通過；另外報滿載學習檔時每鍵 p95 的前後對照。
7. **單元測試**（玩具模型與玩具學習紀錄，手算；**透過 `decode_segment_learned` 的分數斷言**，不是只測純函式）：
   - 一個讀音兩個候選、q = (0.9, 0.1)，在完整前文教 0.1 那個詞一次（c = 1），α_c = 1、無全域：p = (0.45, 0.55)。同一條路徑有學習與沒學習的分數差，R 與 D 各等於手算的 `log10(p/q)` 項（R 對 0.9 那個詞差 0）。
   - 同一個讀音同時有前文紀錄與全域紀錄、α_g 有限：p 的手算值同時用到 c_g 與 c_x。
   - α_g = ∞：等於沒有全域；`lookup` 回 `Level::Global` 的命中不算進 c_x。
   - 沒有紀錄的讀音：分數和沒學習時逐位元相同。
   - extra：只有其他前文的紀錄時，解碼輸出和沒學習時相同；α_g = ∞、只有全域紀錄時，extra 詞不出現在任何候選裡。
   - 後驗模式下 ε 沒有貢獻（把 `LEARN_EPS` 改大，後驗模式的分數不變）。
   - **突變**（main 監督、跑完還原）：拿掉解碼器裡的後驗呼叫、後驗模式下保留 ε 加分、讓 α_g 不影響解碼、拿掉 R 的 `max(0, …)`，各自要讓至少一個測試失敗（看結束碼與失敗的斷言，不是編譯錯誤）。
8. `make test` 全綠；fresh verifier 確認 §3 的表與選定（verifier 可以用 `SHANJIE_TUNE_DIR` 重跑掃描表）。
