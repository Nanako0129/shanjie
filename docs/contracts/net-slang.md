# 契約：網路用語進主詞庫（公開列表＋PTT 挖掘＋人工審）

狀態：**草稿，修訂一，待 plan-verifier**（2026-10-24；修訂一：授權改到出貨的 `overlay-add.tsv` 與 App 署名；維護者「好少喔，要不要再多搜集一些」→ 加英文維基詞典兩個分類、鄉民百科展開子分類，PTT 挖掘提前到這一片）。

## 0. 起因、要做到什麼、怎麼看到

- **起因**（維護者 2026-10-24，Discord 開發串）：「開一片研究，網路用語，如高歌離席之類的這種像是成語實際上不是，通常來自KOL、網路實況主、VTuber、PTT，直接做進主詞包」；「髒話也可以收錄，比如常見國罵」；迷因另做選用詞包（另一片）。
- **顧問與選擇題**（Fable、Kimi、Grok 的報告在維護者本機）：
  - Fable 量過：高歌離席、幹你娘、靠北、三小、北七、已知用火 現在都已經打得對（拆成詞庫詞），打錯的是開頭撞姓或撞常用字的慣用語，例如 沒圖沒真相→梅圖、啊不就好棒棒→阿部就。
  - 維護者選：審過的全收（已經打得對的也收，讓通語 SJ-LM-7 把它當一個詞計數）；主詞庫與迷因詞包照顧問的分法；髒話全收、只看用量。原本選兩階段，第一輪公開列表只審出 76 個，維護者要再多，PTT 挖掘併進這一片（§2a）。
- **要做到什麼**：一份人工審過的網路用語表 `data/lexicon/slang-add.tsv`，由 `tools/build_overlay.py` 接進常開的疊加層。通語 SJ-LM-7 計數時這些詞進計數詞表（`docs/contracts/sj-lm-7.md` §2.1 的常開詞庫包含疊加層）。
- **怎麼看到**：網路用語檢查集（§3）在聊天設定打出收錄的寫法；出貨標準不退步；實機打「沒圖沒真相」「啊不就好棒棒」。

## 1. 來源與授權（只取詞的字串，不取解釋文字）

| 來源 | 用法 | 授權 |
|---|---|---|
| 中文維基「台灣網路用語列表」「臺灣閩南語常見流行語」「臺灣閩南語髒話」 | 條列的詞 | CC BY-SA 4.0 |
| 中文維基詞典 `Category:漢語網路用語` | 條目標題，只留台灣也用的（下面的排除規則） | CC BY-SA 4.0 |
| 英文維基詞典 `Category:Chinese_internet_slang`、`Category:Taiwanese_Mandarin` | 條目標題，同上排除 | CC BY-SA 4.0 |
| PTT 鄉民百科（Fandom）`Category:PTT流行用語`（展開兩層子分類）、`Category:PTT基本用語` | 條目標題 | 文字 CC BY-SA 3.0（站內「關於本站」「編寫規則」；Fandom 預設） |
| iTaigi | 只用來核對台語來源詞的寫法 | CC0 |
| Discord 開發串維護者與使用者提的 | 逐條 | 提供者同意（CC0） |
| PTT 公開看板的用量（§2a 挖掘） | 只取詞的字串（統計結果），不含原文 | 維護者決定 PTT 只用於計數與挑詞、不散布原文 |

- 不用：萌娘百科、偽基百科（NC）、街頭字典與梗圖倉庫、Know Your Meme、巴哈姆特、新聞整理文（保留權利；最多當線索，詞要另從上表或 PTT 用量確認）、Dcard（條款）。
- **排除**：只在中國大陸用的（中文維基「中國大陸網路用語列表」裡有、台灣來源沒有的）、人名與網名（名單層、Wikidata 人物）、有明確單一出處的台詞（歸迷因詞包那一片）。
- 抓取：MediaWiki API，每秒 1 次，原始回應放 repo 外；`slang-add.tsv` 第三欄記每個詞的來源（頁名或「Discord」）。

## 2a. PTT 挖掘（併進這一片）

- **語料**：PTT 這一輪抓取（熱門看板 110 個 × 最近 300 頁）跑完後的頁面；內文與推文都用，推文照 SJ-LM-7 §2.4 合併。
- **候選**：2–6 個漢字的字串，計「出現在幾個看板、幾篇文章」（同一篇只算一次）；去掉已在詞庫各層的字串（整串比對，不因可拆成詞庫詞就去掉）；最小點互資訊與左右鄰接熵過門檻（界線清楚的字串）；只留最長的（被更長候選包住、次數幾乎相同的短字串去掉）；去掉名單層、大陸用語列表、人名。
- **門檻**（事先固定）：看板 ≥ 5、文章 ≥ 20；點互資訊與鄰接熵的門檻在挖掘前用公開列表裡已知的 76 個詞校一次（取能留住其中 90% 的值），之後不改。
- **算的地方**：GCP 或 188（每一步用滿核心）；PTT 原始頁可以放那裡，只帶回候選字串與計數。
- **審查**：照 §2 的人工審；依文章數排序，先審前 1,000 個。
- 公開列表的候選也用同一份語料重算看板數，門檻同樣 ≥ 5。

## 2. 收錄規則與建置

- **候選**：§1 來源的詞，去掉已在基底、疊加層、名單、詞包的（它們已經在詞庫裡）。
- **人工審**（main 逐條，維護者抽查）：是固定說法（不是一般詞組）、台灣在用、寫法取最常見的（PTT 試抓語料的出現次數決定；異體寫法照 keep-both 的做法留候選）。髒話照收，只看用量。
- **讀音**：`tools/readings.py`；破音字逐條看（例如「北七」的七、台語借字），讀不出或有疑義的進 CHECK、不收。
- **分數**：照手動詞（同字數 `length_scores` ＋ `MANUAL_BONUS` 0.75）。
- **同音衝突**：每個詞的讀音用出貨 CLI 解碼（聊天、書面，不開詞包與兩個詞包都開），收錄後的第一名若從「詞庫裡的普通詞」換成這個網路用語，而那個讀音更常打的是普通詞（PTT 試抓語料裡普通詞的次數 ≥ 網路用語的 3 倍），這個詞不收；其他情形照收。
- **工具**：`tools/build_overlay.py` 的 `manual_rows` 加來源標籤參數，另讀 `slang-add.tsv`（同樣三欄：詞、讀音、來源），標籤 `slang`；`overlay-manual.tsv` 與它都要檢查不和既有層重複、彼此不重複。沒有 `slang-add.tsv` 時輸出和現在逐位元組相同（測試斷言）。`build_overlay.py --check` 照舊。

## 3. 驗收

- **網路用語檢查集** `eval/dev/net-slang.txt`：每個收錄的詞一列（無前文、讀音同詞表），另加 Fable 量過的已經打得對的 6 個當對照。聊天、書面各報收錄前後的第一名（只報，不設門檻；收錄後聊天應全部打出，打不出的列出原因）。
- **出貨標準**四條對現行出貨（兩個詞包都開）：只加詞的片，第 4 條（錯字回報）在改壞 0 時算過（含 0／0）。
- **回歸**：dev302、打字測驗聊天書面逐列；動漫五集、名單檢查集、資訊詞包檢查集 0 改壞。
- **實機**：繁中虛擬機打「沒圖沒真相」「啊不就好棒棒」與兩個髒話，第一名等於 CLI。
- 記憶體與延遲：詞數小（預估數百），照報。
- 合併關卡：程式改動（`/code-review` ＋ fresh verifier ＋ CI）。

## 4. 順序、停止條件、範圍外

- **順序**：PTT 抓完才挖；合併在通語 SJ-LM-7 的階段 1 計數之前；和 SJ-LM-7 PR 1 都改 `build_overlay.py`，後合併的那個 rebase。
- **停止**：出貨標準任一條不過；回歸集合有改壞且查不出是哪個詞造成；授權查不清楚的來源（那個來源不用，不算停）。
- **預算**：抓取與審查 main 約 2 天（審 1,000 個候選）；挖掘在 GCP ≤ 2 小時或 188；量測在 GCP 一次（出貨標準的私人集合），≤ 1 小時。
- **範圍外**：迷因詞包（另一片）；改核心與 App 的程式（App 署名文字照下一條要改）。
- **授權**（同一個 PR）：
  - `LICENSES/data.md` 的 `overlay-add.tsv` 列：加「`slang` 標籤的列來自 `data/lexicon/slang-add.tsv`」，來源寫 MediaWiki API（中文維基、中英文維基詞典、PTT 鄉民百科）、PTT 公開看板的用量（只取詞，不含原文）、Discord 提供的詞（CC0）；署名加 PTT 鄉民百科 contributors（Fandom）；寫明鄉民百科的 CC BY-SA 3.0 文字依 3.0 的「後續版本」條款以 CC BY-SA 4.0 散布。
  - `LICENSES/data.md` 加 `slang-add.tsv` 一列，標明是建置輸入、不隨 App 內附，授權同上。
  - `scripts/build-app.sh` 署名文字（`CC-BY-SA-4.0-attribution.txt`）的 `overlay-add.tsv` 那一條加 PTT 鄉民百科 contributors；驗收：從分支建的 App 裡 `Resources/LICENSES/CC-BY-SA-4.0-attribution.txt` 的 `overlay-add.tsv` 那一條有「PTT 鄉民百科」。
