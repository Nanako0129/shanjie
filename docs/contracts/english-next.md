  - `E\te\tN(e)`：e 接中文的加權次數（照上表的權重）。

## 2. 核心

### 2.1 什麼時候生效

- 預測列的每一個起點 s：看**單位**，不看顯示的字：s 前面那一個單位是英文 token（讀音 `_punct_` ＋ 2–32 個 ASCII 字母，`learn::english_of`），或前面是一個空白單位、空白單位前面是英文 token，就取那個 token 的字母轉小寫當 e；表裡有 `E` 列的 e 才生效。（詞庫或詞包裡以字母結尾的詞，例如「我OK」，顯示成字母，但它的最後一個單位是音節，不算英文 token。）
- 左文來自殼、只有漢字，所以只有組字區裡的英文 token（和它後面最多一個空白單位）會讓 e 成立。（第二段，`docs/contracts/context-return.md` §2：起點 0 也看 App 裡已送出的前文結尾的英文詞，核心存在 `left_full`。）
- **游標起點 n 也要查**：今天沒有未完成單位又不在數字語境時，游標起點不查（engine.rs 2278 行 `if pending.is_empty() && dv.is_none()`，`query` 裡 2234 行的提早回傳）。這兩處放寬成「或游標前的前文有表裡的 e」；數字語境優先。
- 預測開關（`prediction`）關著時不生效；不另加開關。
- 可見的變化：表裡有這個英文詞時，英文 token 後面就有預測列，Tab 照既有規則進預測列（今天是送出英文、Tab 交給 App）。
- 解碼、候選窗、學習、詞包、語意校正都不經過這張表。

### 2.2 分數與排序（照 `predict_digits` 的做法）

- P(w | e) ＝ (N(e→w) ＋ γ·P(w)) ／ (N(e) ＋ γ)，γ ＝ 1，P(w) 用 `lm.unigram_back`（和數字語境相同）。
- **有未完成單位**：相容的詞照今天的相容規則（`compat_prefix`／縮寫）。第一層是 e 的 `W` 列裡有的詞，分數 `λ·log10 P(w|e) ＋ (1−λ)·lp`；第二層是其他相容的詞，照今天 `predict(…, v = <s>, …)` 的分數與順序。兩層內的同分順序照 `predict`。
- **沒有未完成單位**（游標在英文 token 或它後面的空白單位後面）：只列 e 的 `W` 列裡、詞庫有的詞，依 P(w|e) 排序，最多 `PREDICT_MAX` 個。數字語境（`digits_here`）優先於這條。
- 學習的加權（`learned_weight`）照舊用 `key`。
- 實作上和 `predict_digits` 共用分層與排序的程式（抽出共用函式或直接共用，executor 選較短的）；不改 `predict_digits` 的輸出（golden 逐位元組相同）。

### 2.3 載入

- `Engine` 照 `digits.tsv` 的方式在資料夾裡讀 `english-next.tsv`（選用；沒有這個檔時和今天逐位元組相同）。檔在但讀不懂（列格式錯、次數 0、N(e) 小於它的 W 次數合計）時是錯誤：`Engine::new` 回 `LoadFailed`，量測 CLI 印出哪一行，不悄悄關掉功能。
- 記憶體與時間：用 §3.2 的 `--english-next` 模式（走引擎的 `recompute_pred`、確實讀表），單執行緒、同一台機器，有表與沒表各跑一次量測集：每鍵 p95 差 ≤ 1 ms；表載入前後的 RSS 差 ≤ 4 MiB。兩行 p95 與 RSS 差記進研究紀錄。

## 4. 順序、停止、範圍外

- **順序**：名單增補（`names-creators.md`，含「是要對決」）合併 → 上表每個輸入凍結並記下雜湊（PTT 抓完；其他都是現成的檔，不等 `clean_subs` 或任何清理跑完）→ 建表與量測 → 表的 PR（`data/lexicon/english-next.tsv`、`scripts/build-app.sh`、授權與資料檔列）。核心、量測 CLI 與建表工具的程式（PR #286）先合併：沒有表時逐位元組相同（§3.4），而 `context-return.md` 以它為前提（2026-10-25 改；原本寫核心 PR 排在建表之後）。
- **停止**：量測集不到 500 列；表的 e 不到 200 個；§3.3 照登記不過；照已 commit 的規則建出的表裡沒有 joe 的 `E` 列或沒有 `W joe 是要對決`（停下來報 N(joe)、N(joe→是要對決)、是否被帳號規則擋掉，出選擇題，不自己改門檻或帳號規則）。
- **範圍外**：App 裡已經送出的英文（另一片，見 §0）；解碼用英文語境（E4 (b) 那一類，另一片）；英文詞後接英文；詞包裡的詞當 w；單一字母的 e（C羅、B站這類，引擎的英文 token 至少 2 個字母〔推論，executor 核對 zhen-inline 的觸發規則，不是就記進研究紀錄〕）；改 FFI。
- **限制**：agent 不讀 `~/.cache/shanjie/`（PTT 快照與量測集由 main 處理）、不安裝、不啟動 App、不碰 `~/Library` 與鑰匙圈、不 push；Mac 只跑改到的測試檔。
