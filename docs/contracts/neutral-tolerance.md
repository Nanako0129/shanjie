# 契約：輕聲容錯——打本調也打得出只標輕聲的詞

狀態：草稿（2026-10-26）。

## 0. 起因與要做到什麼

- main 實測（2026-10-26，核心測試工具、出貨設定）：引擎不把本調當輕聲比對。「桌子」的 子 打 ㄗˇ 得「捉子」、打 ㄗ˙ 才是「桌子」；「爸爸」因為基底兩個讀音（ㄅㄚˋ、ㄅㄚ˙）都收，兩種打法都對。維護者：「輕聲容錯可以開」。
- 規模：小麥基底有 4,136 個多字詞的讀音含輕聲，其中 3,220 個詞**只**有含輕聲的讀音（杯子、被子、拔了、背著、白色的⋯），打本調時這些詞進不了候選。
- 要做到：使用者在輕聲的位置打那個字的本調（或一聲），也打得出這些詞；本來就打輕聲的人不受影響。
- 怎麼看到：§3 的輕聲檢查集用本調打，第一名是那個詞的比例上升；出貨標準不退步；實機打「桌子」「杯子」（子 打 ㄗˇ）。

## 1. 做法（加讀音列，不改核心）

- 照「一、不」變調列的先例：`tools/build_sandhi.py` 再產生一類列，標籤 `neutral`，寫進 `data/lexicon/sandhi-add.tsv`（引擎、Python 參考實作與 App 本來就讀這個檔，載入路徑不變）。
- **哪些詞**：只有基底（`mcbpmf-data.txt`）裡兩個字以上、讀音含輕聲（`˙`）的列。`sandhi-add.tsv` 是 MIT（基底的衍生），疊加層（CC BY-SA 4.0）的衍生列照 `s2r2-overlay-readings.md` 的分法留在 `overlay-add.tsv`，所以疊加層、名單層、詞包都不在這一片。
- **補哪個讀音**：每個輕聲位置換成那個字的「本調」：基底裡這個字當單字詞、韻相同（去掉聲調後相同）的非輕聲讀音中分數最高的那個；好幾個同分時每個都寫一列（重複照下面的規則略過）；沒有的話用一聲（不帶聲調）。例（基底實際的讀音，main 2026-10-26 查過）：子（ㄗˇ、ㄗ˙、ㄗㄜˇ）→ ㄗˇ；頭（ㄊㄡˊ、ㄊㄡ˙）→ ㄊㄡˊ；們（ㄇㄣˊ、ㄇㄣ˙）→ ㄇㄣˊ；的（ㄉㄜ˙、ㄉㄧˊ、ㄉㄧˋ）、了（ㄌㄜ˙、ㄌㄧㄠˇ）、著（ㄓㄜ˙、ㄓㄠ、ㄓㄨㄛˊ…）沒有同韻的非輕聲讀音 → ㄉㄜ、ㄌㄜ、ㄓㄜ（一聲）。一個詞有好幾個輕聲位置時全部一起換（一列），不展開組合。
- **分數**：原列分數減 δ；δ 在 §3 的格點選。產生的（讀音, 詞）已經在任何一層時不寫（同詞同讀音重複會讓詞庫載入失敗）。
- **不做的**：單字（了、的、子 單獨打）不補；不改輕聲列本身；不改核心比對規則。

## 2. 改動

- `tools/build_sandhi.py`：加 `neutral` 列的產生（§1），`--check` 照舊比對；`tools/test_build_sandhi.py`（沒有就新增）加合成測試：韻相同的最高分本調、同分時每個都寫、沒有時用一聲、多個輕聲位置一起換、已存在的（讀音, 詞）不寫、單字不補、只在疊加層的輕聲詞不產生 `neutral` 列、δ 照常數扣。
- `data/lexicon/sandhi-add.tsv` 重建；golden（`sp-predict.txt`、數字層等）照例重產並逐項說明變化。
- 文件：`docs/contracts/s3a.md` 不動（按鍵規則沒變）；`LICENSES/data.md` 的 `sandhi-add.tsv` 列加一句「另含基底輕聲詞的本調讀音列（由基底推導）」；研究紀錄、PLAN。
- **和通語 SJ-LM-7 的關係**：`neutral` 列不增加任何新的詞字串，所以 SJ-LM-7 的計數詞表不變；SJ-LM-7 PR 2 改寫 `overlay-add.tsv` 時要重跑 `build_sandhi.py`（它讀疊加層去重），CI 的 `build_sandhi.py --check` 必過。

## 3. 量測、選法與驗收

- **輕聲檢查集** `eval/dev/neutral/words.txt`：從那 3,220 個只有輕聲讀音的詞依文章用量取前 300 個（PTT 2026-10-25 快照，目錄雜湊 `1f1ac2c0…`；`count_usage.py --include-known`；文章數由多到少，同數照詞的 code point 排），讀音照 §1 換成本調（同分有好幾個本調時取 code point 最小的讀音），一列一詞、沒有前文；只用來回報，不調參。詞表、建置指令與輸入雜湊在第一次格點量測**之前** commit。
- **δ 格點**（事先固定）：{0.5, 1.0, 2.0}。每格量 cvtune-clean、wikitune-clean（調參集）與輕聲檢查集；選法：調參集兩個都不退步（改壞 ≤ 改對）的格子裡，輕聲檢查集第一名最多的；同分取較大的 δ。
- **異體類別不變**：基底＋疊加層＋新的 `sandhi-add.tsv`＋名單，`build_lm.variant_classes` 的類別數與內容要和現在完全相同（同 2026-10-14「修訂一的疊加層」的核對），`reference/proto/lm_eval.py` 載入出貨的 `kn.sjkn` 不出 ValueError。
- **出貨標準**（CLAUDE.md 四條，對現行出貨，兩個詞包都開，GCP 每一步用滿核心）＋動漫五集、名單、店家、網路用語兩輪檢查集改壞 ≤ 改對。
- **驗收**：輕聲檢查集用本調打的第一名比例比現在高；出貨標準四條過；實機（維護者）打「桌子」「杯子」子打 ㄗˇ 出現該詞。
- **預算**：GCP ≤ NT$300（三個格子與一次出貨標準，每一步用滿核心）。
- **停止**：沒有任何 δ 格子讓調參集不退步；出貨標準任一條不過；檢查集沒有改善；異體類別有任何不同；超過預算。

## 4. 範圍外

- 疊加層、名單層、詞包、萌典補詞的輕聲：疊加層的由 SJ-LM-7 契約 §2.3 修訂四處理（還在分支 `exp/sj7-stage0b` 審查中：疊加層的新讀音含輕聲時本調列一起寫進 `overlay-add.tsv`）；名單層與詞包之後另開。
- 改核心的比對（把輕聲當萬用聲調）：這次用資料列解決，核心不動。
