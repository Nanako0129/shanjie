# 契約：輕聲容錯——打本調也打得出只標輕聲的詞

狀態：草稿（2026-10-26）。

## 0. 起因與要做到什麼

- main 實測（2026-10-26，核心測試工具、出貨設定）：引擎不把本調當輕聲比對。「桌子」的 子 打 ㄗˇ 得「捉子」、打 ㄗ˙ 才是「桌子」；「爸爸」因為基底兩個讀音（ㄅㄚˋ、ㄅㄚ˙）都收，兩種打法都對。維護者：「輕聲容錯可以開」。
- 規模：小麥基底有 4,136 個多字詞的讀音含輕聲，其中 3,220 個詞**只**有含輕聲的讀音（杯子、被子、拔了、背著、白色的⋯），打本調時這些詞進不了候選。
- 要做到：使用者在輕聲的位置打那個字的本調（或一聲），也打得出這些詞；本來就打輕聲的人不受影響。
- 怎麼看到：§3 的輕聲檢查集用本調打，第一名是那個詞的比例上升；出貨標準不退步；實機打「桌子」「杯子」（子 打 ㄗˇ）。

## 1. 做法（加讀音列，不改核心）

- 照「一、不」變調列的先例：`tools/build_sandhi.py` 再產生一類列，標籤 `neutral`，寫進 `data/lexicon/sandhi-add.tsv`（引擎、Python 參考實作與 App 本來就讀這個檔，載入路徑不變）。
- **哪些詞**：基底（`mcbpmf-data.txt`）與疊加層（`overlay-add.tsv`）裡，兩個字以上、讀音含輕聲（`˙`）的列。名單層、詞包不動（它們的讀音由各自的工具決定）。
- **補哪個讀音**：每個輕聲位置換成那個字的「本調」：基底裡這個字當單字詞、韻相同（去掉聲調後相同）的非輕聲讀音中分數最高的那個；沒有的話用一聲（不帶聲調）。例：子 ㄗ˙ → ㄗˇ；的 ㄉㄜ˙ → 基底有 ㄉㄜˊ、ㄉㄧˋ…，韻相同的是 ㄉㄜˊ → ㄉㄜˊ；了 ㄌㄜ˙ → 基底沒有韻 ㄌㄜ 的非輕聲讀音 → ㄌㄜ（一聲）。一個詞有好幾個輕聲位置時全部一起換（一列），不展開組合。
- **分數**：原列分數減 δ；δ 在 §3 的格點選。產生的（讀音, 詞）已經在任何一層時不寫（同詞同讀音重複會讓詞庫載入失敗）。
- **不做的**：單字（了、的、子 單獨打）不補；不改輕聲列本身；不改核心比對規則。

## 2. 改動

- `tools/build_sandhi.py`：加 `neutral` 列的產生（§1），`--check` 照舊比對；`tools/test_build_sandhi.py`（沒有就新增）加合成測試：韻相同的最高分本調、沒有時用一聲、多個輕聲位置一起換、已存在的（讀音, 詞）不寫、單字不補、δ 照常數扣。
- `data/lexicon/sandhi-add.tsv` 重建；golden（`sp-predict.txt`、數字層等）照例重產並逐項說明變化。
- 文件：`docs/contracts/s3a.md` 不動（按鍵規則沒變）；`LICENSES/data.md` 的 `sandhi-add.tsv` 列加一句「另含輕聲詞的本調讀音列（由基底推導）」；研究紀錄、PLAN。

## 3. 量測、選法與驗收

- **輕聲檢查集** `eval/dev/neutral/words.txt`：從那 3,220 個只有輕聲讀音的詞依文章用量（PTT 2026-10-25 快照，`count_usage.py`）取前 300 個，讀音照 §1 換成本調，一列一詞、沒有前文；只用來回報，不調參。
- **δ 格點**（事先固定）：{0.5, 1.0, 2.0}。每格量 cvtune-clean、wikitune-clean（調參集）與輕聲檢查集；選法：調參集兩個都不退步（改壞 ≤ 改對）的格子裡，輕聲檢查集第一名最多的；同分取較大的 δ。
- **出貨標準**（CLAUDE.md 四條，對現行出貨，兩個詞包都開，GCP 每一步用滿核心）＋動漫五集、名單、店家、網路用語兩輪檢查集改壞 ≤ 改對。
- **驗收**：輕聲檢查集用本調打的第一名比例比現在高；出貨標準四條過；實機（維護者）打「桌子」「杯子」子打 ㄗˇ 出現該詞。
- **停止**：沒有任何 δ 格子讓調參集不退步；出貨標準任一條不過；檢查集沒有改善。

## 4. 範圍外

- 單字的輕聲（了、的、著 單獨打）。
- 名單層、詞包、萌典補詞的輕聲（SJ-LM-7 修訂四另有規則：疊加層的新讀音含輕聲時本調列一起寫）。
- 改核心的比對（把輕聲當萬用聲調）：這次用資料列解決，核心不動。
