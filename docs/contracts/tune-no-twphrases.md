# 調參集的正解不套 TWPhrases（TW0 版）

狀態：草稿（2026-11-04，任何新版的分數之前）。

## 0. 起因

- 會意 SJ-SR-7-15M 的訓練文字與調參集的正解，都是 `build_counts.convert` 預設 `trad_tw_phrases=True` 轉出來的：繁體句也套 OpenCC `TWPhrases.txt`，例如「權限 → 許可權」「局部 → 區域性」「分區 → 分割槽」（研究紀錄 2026-11-04「TWPhrases 盤點」）。
- 調參集的正解裡因此留著錯誤轉換的寫法：wikitune-clean 有「區域性」1、「分割槽」3、「型別」1、「釋出」1 處，cvtune-clean 有「型別」2、「釋出」1、「檢視」1 處；原文的鍵只剩 11、8 處。修好的會意在這些列反而會被算成改壞，量尺偏向舊模型。
- 維護者 2026-11-04 選「重建不套的新版」：之後的出貨標準與選值改用新版，舊版留著，只拿來對照過去的數字。

## 1. 要做到什麼

1. 新的兩份集合 `cvtune-clean-tw0`、`wikitune-clean-tw0`：**列與順序和現行 clean 版一一對應**，只把正解句子換成「繁體句不套 TWPhrases」的寫法，讀音照新句子重算。其他列逐位元組不變。
2. 對應的方法（事先固定）：
   - 從同一份來源重新抽句：cvtune 用 `build_tune.py` 的 Common Voice／Tatoeba 檔與同一個雜湊切分（`is_tune`），wikitune 用同一份維基 dump 的第 300,000～304,999 篇與同一套標記清除。
   - 每一個原始句子各轉兩次：現行轉換 A（`trad_tw_phrases=True`）與新轉換 B（`False`），再各自用 `HAN`（4～30 字的漢字段）切成子句。TWPhrases 的鍵與值都是漢字，所以 A、B 的子句數相同時逐個配對；不同時（長度跨過 4 或 30 字的邊界）這個句子的子句都不配對，記數。
   - 得到「A 子句 → B 子句」的對照。同一個 A 對到兩個以上不同的 B（例如原文「許可權」與「權限」都轉成「許可權」）時，那個 A 不換，記數並列出。
   - clean 版每一列：正解是 A 而且對照裡有唯一的 B、B 和 A 不同 → 換成 B，讀音用 `tools/readings.py` 重算（同 `build_tune.py`）；B 含 CHECK 或讀不出 → 這一列丟掉，記數。其餘列照原樣。前文欄照原樣（兩份集合的前文都是空的；不空就停下回報）。
3. 工具放 `experiments/s2/detw_tune.py`，只讀來源與 clean 檔、寫新檔與一份報告（換掉幾列、沒配對幾句、多重對照幾個、丟掉幾列、每份的 SHA-256），不改 `build_tune.py` 的既有輸出。
4. 同一片把 `build_counts.convert`、`prep.py`、`build_tune.py` 的 `trad_tw_phrases` 預設改成 False（繁體句不套；簡體句照舊套，簡轉台灣用詞是對的），舊行為改成要明寫旗標才有。〔這一條是防再犯；改預設不影響已建好的任何檔案。〕

## 2. 怎麼看到它有效（驗收）

- 單元測試（`make test-python`）：
  - 配對：一個含「權限」的繁體句，A 是「許可權」、B 是「權限」，對照正確；一個不含任何鍵的句子 A＝B、不換；子句數不同的句子不配對；多重對照不換。
  - 預設：不帶旗標呼叫 `convert` 時，繁體句「權限設定」原樣保留；簡體句「软件」照舊轉成「軟體」。
- 實際輸出（Mac，格式轉換，單程序、幾分鐘內）：
  - 兩份新檔的列數等於 clean 版減掉「丟掉」的列數；換掉的列裡，舊正解都含 TWPhrases 的值、新正解都含對應的鍵。
  - 新檔裡「區域性」「分割槽」「擴充套件」「指令碼」「許可權」的出現次數是 0，或每一處都列在報告的「多重對照」或「沒配對」裡。
  - 沒換的列和 clean 版逐位元組相同。
- 研究紀錄寫兩份的列數、換掉的列數、SHA-256；`eval/README.md` 加兩列。

## 3. 之後怎麼用

- 出貨標準第 3 條（cvtune-clean 非劣性）與選值改用 `cvtune-clean-tw0`；書面調參用 `wikitune-clean-tw0`。舊版照舊保留，報過去的數字時寫明用哪一版，跨版本的 KPI 不混用。
- 這兩份是調參層（之前都看過），不是判讀集。

## 4. 停止條件

- 配對不起來的句子超過該集合來源句子的 1%，或換掉的列裡有任何一列舊正解不含 TWPhrases 的值：停下回報，不調整方法再跑。
