# S3d 契約：標點進組字區（使用者 2026-10-04）

使用者實測 v0.1.1 時要求：「標點符號要算在組字的底線當中，不然打字習慣會不小心 Enter 送出」。現行 s3a 規則 2 是「送出組字區，再送出標點」：打完「你好，」組字就已經送出，之後順手按 Enter，在聊天 App 裡就把訊息送出去了。使用者說明 macOS 內建注音是把標點放進組字區、按 Enter 才一起送出（使用者描述；小麥注音是否相同未在本機核對）。

本契約修改 s3a §2 規則 2、§3.1 候選範圍與重算、§2 的組字上限，以及 S2c 的分段解碼；其餘規則不變。只改核心（`core/src/engine.rs`），殼只吃 `ShanjieOutput`，不用改。

**怎麼算做到**：使用者打「你好，我是」（`ㄋㄧˇ ㄏㄠˇ` Shift+, `ㄨㄛˇ ㄕˋ`），看到整段「你好，我是」都有底線，按 Enter 才一起送出。由使用者在本機建置或下一版實測。

## 1. 規則

| # | 狀態 | 按鍵 | 行為（新） |
|---|---|---|---|
| 2 | 任何 | Shift＋§4 標點鍵、Ctrl+\ | 丟掉未完成音節、關閉候選，**把標點插入組字區的游標處**，游標移到它右邊；不送出任何東西（`handled = 1`、`commit` 空） |

- 組字區原本是空的也一樣：標點自己成為組字區（有底線），按 Enter 才送出。
- 標點在組字區裡是一個**記號**（token），佔一格，和音節同一個陣列：
  - ←→、Home、End 把它當一格跳過；Backspace／Delete 刪掉整個標點。
  - Enter 送出整段（含標點）；Esc 清空；`reset(mode 1)` 回傳的字串含標點。
  - 組字上限 40 改成「40 個記號」（音節加標點）：插入第 40 個記號（不論音節或標點）後立刻送出整段，`handled = 1`。
- 規則 21（其他鍵送出組字區後直通）不變；`Shift＋非標點` 仍屬規則 21。

## 2. 內部表示

- `syls` 裡的標點用保留讀音 `_punct_<標點字>`（例 `_punct_，`），詞庫不會有這個讀音。
- 每個標點同時是一個長度 1 的固定詞（`Fixed { start: i, end: i + 1, word: 標點 }`），所以既有的「固定詞隨編輯調整」規則照樣適用；標點固定詞**不會被選字移除**（§3 保證候選範圍不碰到它）。
- 判斷是否為標點：只看 `syls[i]` 是否以 `_punct_` 開頭。
- 插入標點固定詞後，`fixed` 仍要依 `start` 排序（`refresh` 與 `refresh_lm` 都依賴這個順序；`choose` 會排序，新的插入路徑也要）。

## 3. 候選範圍（s3a §3.1 修改）

- 設 a＝游標。可用來列候選的音節，是游標左邊**連續、不含標點**的那一段；a 為 0 時改用游標右邊、從 0 開始連續不含標點的那一段（同 s3a 的「從位置 0 開始」）。
- 那一段長度為 0（游標左邊緊鄰標點，或 a 為 0 而第一個記號是標點）→ 空白鍵、↓ 是「已處理、忽略」（不開候選、不改狀態）。
- 其餘照 s3a §3.1（L 由長到短、詞庫順序、去重、每頁 9 個）。
- 標點本身不提供候選（例如 `{` 的 『《〔】 等替代標點），列為範圍外。

## 4. 解碼（S2c 分段解碼修改）

- 標點是**句子邊界**，和語言模型的訓練方式一致：`experiments/s2/build_counts.py` 在每個非漢字字元處切段（`HAN = [一-鿿]+`），每段當成一句，前接 `<s>`、後接 `</s>`。
- 因此 `refresh_lm` 的每個空白區間：
  - 左邊緊鄰的固定詞是標點 → 前文用 `<s>`（不是標點字）；
  - 右邊緊鄰的固定詞是標點 → 用 `End::Eos` 結束（不是轉移到標點）。
  - 標點固定詞不呼叫 `capped.best_lp`（會找不到讀音而回 Internal）；它在 `path` 裡的分數記 0.0，只用來保持 path 與顯示字串對齊。
- unigram 路徑（沒有載入 LM 時的 `refresh`）只要照順序串接固定詞即可，不需特別處理。
- 結果：`A，B` 的顯示字串等於「A 單獨解碼」＋「，」＋「B 單獨解碼」（兩段各自以 `<s>`…`</s>` 解碼）。
- `total_score`（整句分數）是各段分數的和：遇到標點時，前一段加上 `eos(該段最後一個詞)`，下一段的前文重設為 `<s>`，標點本身不計分；全部都是標點（沒有任何詞）時回 `None`，和空組字區相同。
- 標點不在語言模型的詞彙裡（兩個計數腳本都在非漢字處切段），所以錯把標點當前文或當轉移目標**不會**讓核心回錯誤，只會改用回退分數；驗收 4 因此要用預先算好、確定會分出差別的句子。

## 5. 驗收

1. `core/tests/engine.rs` 改寫 `row2_punctuation_commits_composition_then_punct`，改名並斷言：
   - 對 §4 表的每個鍵與 Ctrl+\：組字中按下後 `handled`、`commit` 為空、`preedit` 以該標點結尾、候選關閉；未完成音節被丟掉。
   - 組字區空時按標點：`preedit` 就是那個標點；Enter 後 `commit` 是那個標點。
   - 「你好，我是」：Enter 的 `commit` 等於整段含標點。
2. 編輯：←、Backspace 在標點上一次一格；Delete 刪掉游標右邊的標點；Home／End 正常。
3. 候選：游標緊鄰標點右邊時，空白鍵與 ↓ 不開候選、輸出不變；游標在「，」後面再打兩個音節，開候選時的範圍不跨過標點（候選清單和只打那兩個音節時相同）。注意：詞庫查不到 `_punct_…` 讀音，現有的候選邏輯本來就不會跨過標點，所以這項是回歸檢查，不證明新寫的程式。
4. 解碼（有 LM，chat 設定）：`X，Y` 的顯示字串等於分別只打 X 與只打 Y 時的顯示字串以「，」串接。X、Y 用搜尋挑選（從 dev302 的讀音片段裡找），挑定後寫進測試並記在本契約，測試裡先直接用 `decode_segment` 斷言前提：
   - 對 X：結尾用 `End::Eos` 的第一名 ≠ 結尾用 `End::Next { word: "，", lp: 0.0 }` 的第一名；
   - 對 Y：前文 `"<s>"` 的第一名 ≠ 前文 `"，"` 的第一名（兩者都以 `End::Eos` 結束）。
   - 另外直接斷言組字結果的字面值是「他長，在換」（同 `right_fixed_word_transition_changes_left_choice` 的做法），免得整個引擎一起退步時兩邊仍然相等。
   - 2026-10-04 用 dev302 搜尋（暫時的測試程式，未 commit；chat 設定、beam 64）挑定：**X = `ㄊㄚ ㄔㄤˊ`**（`End::Eos` →「他長」，`End::Next{"，",0.0}` →「他常」）、**Y = `ㄗㄞˋ ㄏㄨㄢˋ`**（前文 `<s>` →「在換」，前文「，」→「再換」）。正確的組字結果是「他長，在換」。
   - 兩個突變都必須讓驗收 4 至少一個斷言失敗（看結束碼與斷言數，不只看 FAIL 字樣）：(a) 標點前一段的結尾改成 `End::Next { word: 標點, lp: 0.0 }`；(b) 標點後一段的前文改成標點字而不是 `<s>`。
5. 上限：39 個音節後插入標點 → 立刻送出整段（含標點），組字區清空。
6. `cargo test --release`、`make test` 全綠；C ABI 冒煙測試（s3a §7.4）不變；dev302 的 top-1 不變（開發集沒有標點，作為回歸檢查）。
7. 殼的測試若有假設「標點直接送出」的，照新規則更新。

## 6. 範圍外

標點的替代候選（`{` → 『《〔…）；全形／半形切換；英文模式下的標點；Shift 單按切中英（已由 Caps Lock 取代）；學習（S4）。

## 7. 停止條件、預算與回滾

- 預算：實作加審查最多三輪（修改 → `/code-review` → verifier）。

- 停止：找不到能分出差別的 X 或 Y（驗收 4 的前提）；dev302 top-1 變動；任一驗收的突變存活；改動需要碰到 C ABI（`shanjie.h`）。
- 回滾：revert 本片的 merge commit。
