# SW 第一片：非標準讀音的降權機制

使用者 2026-10-07 回報：打 ㄍㄠˇ ㄨㄢˊ ㄓㄜˋ ㄅㄛ 想要「搞完這波」，第一名卻是「睪丸這波」，並建議「敏感的字詞建議下調機率」。設計經 Fable 5.1 研究與量測，使用者同日選定照它做、進 v0.3.0。

設計拆成兩片交付：
- **這一片**：降權機制，加上「非標準讀音」這一類，先修好使用者回報的這句。
- **第二片**：粗話與歧視用語類（英文維基詞典快照）、候選窗依降權後的分數排序、選字記憶優先（學過就不扣），以及即時預測排除。

## 1. 量到的原因（2026-10-07，模型 E）

- 基底詞庫（小麥資料）把「睪丸」同時收在 ㄍㄠ-ㄨㄢˊ 和 ㄍㄠˇ-ㄨㄢˊ，分數都是 −5.92；「搞完」只在 ㄍㄠˇ-ㄨㄢˊ，分數 −6.87。教育部《重編國語辭典》的「睪」只有 ㄍㄠ、ㄧˋ 兩讀，沒有 ㄍㄠˇ；小麥收這個讀音是為了容錯常見的誤讀。
- 模型裡有「睪丸」的二元組條目，「搞完」只能走回退。第一名與第二名的分差：聊天 1.52、書面 1.39，比詞庫分數差（0.95）還大。所以只降詞庫分數無效：降到 3.0，仍是「睪丸這波」。要扣在最終的詞分數上。
- 基底詞庫裡「詞在教育部辭典、但這個讀音不在」的多字條目有 5,817 個，大多是輕聲、變調（巴掌 ㄅㄚ ㄓㄤˇ、芭蕾舞 ㄌㄟˊ），是使用者實際的打法，不能整批降權。

## 2. 資料：`data/lexicon/demote.tsv`

- 每行 `讀音<TAB>詞<TAB>δ<TAB>類別<TAB>來源`。讀音用詞庫的寫法，音節以 `-` 相接。`*` 表示這個詞的所有讀音，載入程式要支援，這一片用不到。同一個（讀音, 詞）只能出現一次；查表時特定讀音優先於 `*`。
- **這一片只有一行**：`ㄍㄠˇ-ㄨㄢˊ	睪丸	2.0	reading	user-report-2026-10-07`。自己寫的，和專案其他資料一樣以 CC BY-SA 4.0 釋出。
- `reading` 類的收錄條件（寫進檔頭與 PLAN）。三個條件都成立才收：
  - 教育部辭典有這個詞，但沒有這個讀音。
  - 差別不是輕聲或變調。
  - 有使用者回報或探針證據，顯示它擋到同音的一般詞。
- 載入失敗（格式錯、δ 不是有限正數、重複的鍵，或某一列在詞庫裡找不到這個讀音下的這個詞）時，引擎建立失敗，回傳碼 3，和其他詞庫檔一樣。Python 與 Rust 用同一套嚴格的格式規則。

## 3. 行為

- **解碼的詞項分數**（Python `reference/proto/lm.py` 的 `decode`、Rust `core/src/lm.rs` 的 `decode_segment_learned`）：
  - 每個（讀音, 詞）的詞項分數 = λ·log10 P(w|v) + (1−λ)·lp − δ。lp 與回退機率不變。
  - 每個讀音要試哪些詞條（前 `PER_KEY` 個與學習帶進來的詞），仍依原本的 capped 分數決定，不依 lp − δ。
  - 學習加分的基準 `best` 是該讀音最高的 capped 分數，不扣 δ。學習加分後仍扣 δ。
  - 這一片沒有「學過就不扣」。學習加分作用在 lp 上，只經過 (1−λ)·lp 與回退項進入分數，能不能蓋過 δ 沒有量過（修正：原本寫「大於 δ」是錯的推論）。這一片在引擎上量一次：在「切除」與沒有前文兩種情況下，以 ㄍㄠˇ ㄨㄢˊ 改選「睪丸」一次後，聊天與書面兩種設定的第一名，寫進研究紀錄。這只是記錄，不是驗收門檻；「學過就不扣」在第二片處理。
- **固定詞**：使用者選定的詞，在接續項（`End::Next`）與 `Engine::total_score` 裡同樣扣它的 δ。固定詞的讀音就是它所在的音節。這只改變總分，不改變那一段的排序；`total_score` 與解碼第一名的分數仍要一致，`engine_lm.rs` 那條測試要通過。
- **沒有語言模型的解碼**（unigram 路徑 `decode_beam`）：不變。
- **候選窗**：不變，仍是 s3a §3.1 的詞庫順序。第二片才改，並同步修訂 s3a 與 S4 契約。
- **設定**：
  - 核心加 `shanjie_engine_set_demote(engine, 0|1, out)`，預設 1；不是 0 或 1 回傳 2。比照 `set_profile`：重算目前的組字並回傳快照，選單切換時畫面立刻反映。設為 0 時所有 δ 視為 0，結果和這一片之前逐位元相同。
  - 殼層在輸入法選單加「避免把敏感字詞排在前面」，預設開，存在 UserDefaults，啟動與切換時呼叫上面的函式。
  - `core/include/shanjie.h`、`docs/contracts/s3b.md` §13.2（選單）同步更新。
- **評測工具**：`lm_eval.py` 與 `shanjie-eval` 各加 `--no-demote`；不加時降權開啟。

   - **第 2–5 列**（同一個非標準讀音，一般詞應該贏）：報開、關兩種結果。
   - **第 6–11 列**（標準讀音的醫學詞，以及「切除」之後用非標準讀音打的醫學詞）：降權開、關的第一名逐列相同，兩種設定都要。這是硬條件。

   - `set_demote(0)` 不生效，(b) 要失敗。

## 5. 不在這一片

- 粗話、歧視用語類與它的資料來源。
- 候選窗排序。
- 學過就不扣。
- 即時預測排除。
- 解剖、醫學詞的降權（Fable 量到 δ ≥ 1.5 會把「左側睪丸」打成「左側高玩」，不做）。
- PLAN 的「讀音條件權重」：罕用讀音拿到常用讀音的語料加分，例如「雀」。「雀」唸 ㄑㄧㄠˇ 是教育部收錄的語音，不屬於 `reading` 類，是另一個機制。
- 政治審查詞表一律不用。
