# 合法寫法分數（forms）

狀態：READY（2026-10-31，plan-verifier 兩次 REVISE 逐項處置後，收尾審查 READY）。第一次 plan-verifier REVISE 的四項照改（規則對詞典資料實跑過、驗收寫成固定事實；正則與讀音拆法寫死；表只在加旗標時才讀；兩個分數的定義）；第二次 REVISE 的四項逐項處置：輕聲符號轉成列檔的寫法、單字對的鏈解到底、兩道替換的順序、併表突變指向必失敗的測試。

## 0. 起因與維護者的決定

- 維護者看到一支講「姊／姐」「溼／濕」的影片，問：「我們能分辨得出來差別嗎？然後還有沒有更多類似的」。
- 實測（v0.6.1 出貨設定、沒有前文）：「姊姊」聊天選姊、書面選姐；「潮溼」聊天選濕、書面選溼；「溼地」選溼、「濕度」選濕。選字照語料裡每個詞的寫法走，評分也把這些當成選錯。
- 研究顧問 Astra 查了教育部《重編國語辭典修訂本》與《異體字字典》（研究紀錄 2026-10-31）：「姊姊」的釋義寫「也作『姐姐』」；「濕」讀 ㄕ 時「同溼」，讀 ㄒㄧˊ 另有「低溼的地方」；「姐」當姊妹義時註「通『姊』」，「小姐」不能寫「小姊」。
- 現行的寬鬆對照（S2v，`docs/PLAN.md` §S2v）只收「也作／亦作」、兩邊都是詞條、等長、讀音相同的詞，單字異體在範圍外。「姊姊／姐姐」沒收，是因為「姊姊」的讀音欄把讀音與語音寫成一串（`ㄗˇ　˙ㄗ　（語音）ㄐㄧㄝˇ　˙ㄐㄧㄝ`），整串比對對不上。
- 維護者選擇題「先開評分政策片（推薦）」：現行分數照報，另加「合法寫法」分數；同字異形放寬，有分工的字只收辭典有記載的詞，人名照舊嚴格；政策加版號，舊結論不倒改。

## 1. 要做到什麼

### 1.1 兩個分數的定義

- **現行分數**：評測 CLI 現在的 `--rowstats` 判斷：候選與正解各自套現行寬鬆對照（單字對照 `她妳它牠嘗周臺裏 → 他你他他嚐週台裡`，再套 `eval/variants.tsv` 的最長匹配）之後相等。出貨標準、判讀、已登記的實驗都只用它；這一片不改它的任何一位元組。
- **合法寫法分數（forms）**：先做現行的寬鬆對照，再套 `eval/forms.tsv`（§1.2 的詞對與單字規則，§1.3 的套法）之後相等。報告裡「現行錯、forms 對」的列，就是只靠 forms.tsv 才算對的列。

### 1.2 `eval/forms.tsv`（第一版 `forms-v1`）

由 `tools/build_forms.py` 從同一份萌典資料（`build_variants.py` 的 `dict-revised_bkup.json`，同一個 commit 與 SHA-256）產生，規則全寫在程式裡，不手寫任何一對。2026-10-31 main 在這份資料上試算過下列規則，數字寫在各條後面。

1. **讀音拆法**（用在本表所有讀音比對）：一個 heteronym 的 `bopomofo` 字串，以正則 `（(?:讀音|語音|又音)）` 切開；每段把連續空白（含全形空白 U+3000）換成一個半形空格、去掉頭尾空白；丟掉空段。寫進 `char` 行的讀音條件再轉成列檔的寫法：每個音節開頭的輕聲符號 `˙` 移到音節結尾（辭典 `˙ㄗ` → 列檔 `ㄗ˙`）；`--check` 遇到以 `˙` 開頭的條件就失敗。試算：目前單字對的條件裡沒有輕聲，轉換由單元測試保證。一個詞條的讀音集合是所有 heteronym 切出的段的聯集；`bopomofo` 是空的 heteronym 不貢獻讀音。
2. **詞對規則**（S2v 的規則，只改讀音比對）：詞條標題 T（≥ 2 字、不含 `{`）的任一個 `definitions[].def` 用正則 `(?:也作|亦作)「([^」]+)」` 找到的 Y（引號內以 `」、「` 分隔），Y 與 T 等長、Y ≠ T、不含 `{`、Y 也是詞條，而且兩者依 1. 的讀音集合有交集。S2v 原本整串比對時已收的對不重複寫；試算：只因讀音拆開而多收 35 對，含「姊姊／姐姐」「家姊／家姐」「混水／渾水」「角色／腳色」。
3. **單字規則**：標題是單一字 X，看它的**第一個** heteronym；它的 `definitions` 只有一條，而且符合下面任一種，就收 X→Y，Y 必須也是單字詞條：
   - (a) `def` 整句符合 `「(.)」的異體字。`（例：牀→床、唇→脣、峯→峰）；
   - (b) `def` 是空字串，而且 `link` 剛好一項、整句符合 `同「(.)」。`（例：濕→溼、秘→祕、沈→沉）。
   - 「通「Y」」不收（「佈」的 link 是「通「布」」，「布／佈」不會進表；「姐」的釋義有正文，也不會進表）。
   - 每一條單字對記下**讀音條件**：X 第一個 heteronym 有讀音時，用它依 1. 切出的讀音；沒有讀音（(a) 的異體字條目）時，用 Y 的讀音集合。
   - 試算：621 對，其中有詞典標成異體的簡化字（万、个）。這個分數只報不判，照收；報告另列這類字對的影響（§1.4）。
4. **正規化**：詞對照 S2v：先套現行單字對照與 `variants.tsv`，丟掉套完兩邊相同的，聯集分組，標準形取 `min()`；單字對：X 先套現行單字對照，套完等於 Y 或已被現行對照涵蓋的丟掉。單字對的鏈（X→Y 而 Y 也是某一對的 X）一路解到不再變的字，讀音條件用第一段 X→Y 的；有環就建表失敗。`--check` 斷言沒有任何 `char` 行的 Y 又出現在另一行的 X。試算：3 條鏈（揔→摠→總、机→几→幾、腭→齶→顎），0 個環。
5. **檔案格式**：`#` 說明行（來源 commit 與 SHA-256、規則版本 `forms-v1`、詞對數、單字對數），接著兩種資料行：`word\t寫法\t標準形`、`char\tX\tY\t讀音1,讀音2…`，依類別與寫法排序。`--check` 重建後逐位元組相同。`--explain 寫法` 印出這一行由哪條規則、哪個詞條的哪一句原文產生。

### 1.3 評分怎麼套

- 評測 CLI 加 `--forms-rowstats FILE`：每列一行，格式同 `--rowstats`，判斷用 §1.1 的 forms。
- **只在加了這個旗標時**才讀 `forms.tsv`（路徑讀 `SHANJIE_FORMS`，沒設時用 repo 的 `eval/forms.tsv`；加了旗標而檔案不存在或格式錯就報錯結束）。沒加旗標時完全不讀、不檢查這個檔。
- 它是一張**獨立的表**，在現行寬鬆對照之後才套，不併進現行的表、不改 `Lenient` 物件。
- 順序固定：先套現行寬鬆對照，再套 forms 的詞對（最長匹配，語意同 S2v），最後套單字對。每一道替換都等長，所以位置不變。
- 單字對：只在該位置的讀音（列檔第三欄依空白切成音節，和句子逐字對齊）在這條的讀音條件裡時才換。候選與正解用同一列的讀音（同一次輸入）。某一列的音節數和句子字數不同（例如含英文）時，這一列只套詞對、不套單字對，並計數。

### 1.4 報告

在公開集合（dev302、打字測驗、錯字回報、fw、probe、cvtune、wikitune）兩種設定上，跑出貨設定的 CLI，同時寫 `--rowstats` 與 `--forms-rowstats`，報：

- 每個集合的現行分數與 forms 分數；
- 「現行錯、forms 對」的列，依寫法對分組的數量（只列 forms.tsv 的對；現行對照已涵蓋的不會出現）；簡化字對另列；
- 音節數對不上而沒套單字對的列數。

私人集合只報數字。結果寫進研究紀錄，不改任何既有結論。

### 1.5 文件

`docs/methodology.md` 加 forms 的定義與「和現行分數並列、不取代」；`LICENSES/data.md` 加一列（同 S2v，只用於評測，CC BY-ND 3.0 TW）；`eval/README.md` 加表的雜湊；`docs/PLAN.md` 的 S2v 節加一行指向本契約。

## 2. 怎麼看到它有效（誰看）

main 在公開集合上跑出 §1.4 的報告；「現行錯、forms 對」的每一組寫法對，都能用 `build_forms.py --explain` 指出它來自哪條規則與哪一句辭典原文。維護者看這份清單，決定哪些要進出貨標準（另一個決定，不在這片）。

## 3. 驗收

1. `python3 tools/build_forms.py --check` 通過；說明行的兩個計數等於兩種資料行的行數。
2. **一定要有**（測試寫死，不帶條件）：
   - 詞對規則（只因讀音拆開才收）：`姊姊`／`姐姐` 同一組。
   - 單字規則 (a)：`牀`→`床`。
   - 單字規則 (b)：`濕`→`溼`，讀音條件是 `ㄕ`；`沈`→`沉`，讀音條件是 `ㄔㄣˊ`。
3. **一定不能有**：單字 `姐`／`姊`、`布`／`佈`；詞 `小姐`／`小姊`；`濕` 的讀音條件裡不能有 `ㄒㄧˊ`；`沈` 的讀音條件裡不能有 `ㄕㄣˇ`。
4. **評分**（CLI 測試）：
   - 句子「潮濕」讀 `ㄔㄠˊ ㄕ` 與正解「潮溼」：同一次執行同時寫 `--rowstats` 與 `--forms-rowstats`，前者 0、後者 1；
   - 「濕」在讀 `ㄒㄧˊ` 的位置不換；「沈」在讀 `ㄕㄣˇ` 的位置不換（姓氏照舊嚴格）；
   - 「姐姐」與「姊姊」在 forms 下相等；「小姐」與「小姊」不相等。
5. **突變**（各讓一個具名的測試失敗）：拿掉讀音拆開 → 姊姊／姐姐的測試；拿掉單字規則 (a) → 牀的測試；拿掉 (b) → 濕的測試；拿掉讀音條件（單字對在任何位置都換）→ 沈讀 ㄕㄣˇ 的測試；把 forms 表併進現行的表 → §3.4 的「潮濕」測試（它在同一次執行裡同時寫 `--rowstats` 與 `--forms-rowstats`，斷言前者 0、後者 1）；把兩道替換的順序對調 → 一個用合成表、兩種順序結果不同的單元測試；拿掉輕聲轉換 → 轉換的單元測試。
6. **不動現行分數**：dev302、打字測驗、錯字回報兩種設定，下面三種跑法的 `--rowstats` 與摘要行都和 main 逐位元組相同：不加旗標；加 `--forms-rowstats`；不加旗標但 `SHANJIE_FORMS` 指向不存在的檔。
7. 報告照 §1.4 寫進研究紀錄。
8. 測試：改到的 Rust 測試檔與 `make test-python` 在 Mac；完整 Rust 測試在另一台機器；CI 全綠；`/code-review`＋fresh verifier。

## 4. 停止條件

- 隨機抽 30 對（詞對與單字對各 15），有超過 3 對不是辭典意義上的同一個詞或同一個字：停下來回報，不手修表。
- 現行分數任何一位元組改變：停。

## 5. 範圍外

- 改出貨標準或任何判讀規則；改既有實驗結論。
- 改模型、詞庫或建模的合併表（S2f 的 MERGE）。
- 人名、地名另外放寬（表只來自辭典，單字對有讀音條件）。
- 「通「Y」」關係與有分工的單字（布佈、周週、了瞭等）；辭典裡「同「Y」」寫在正文、不是整句的單字。

## 6. 預算

一個 PR；executor 實作（Python 建表、Rust 旗標與讀音條件、測試、文件），main 寫報告。
