## 2. 收錄規則與建置

- **用量**（事先固定，數之前 commit）：2026-10-25 的 PTT 快照（目錄雜湊 `1f1ac2c0…`）裡，`experiments/names-creators/count_usage.py` 數出的看板 ≥ 3、文章 ≥ 10（和 `names-creators.md` 相同）。
- **只留打錯的**：先在 GCP 用出貨 CLI 解碼全部候選的讀音（聊天，動漫、資訊詞包開；迷因詞包合併後加上；`--threads` 用滿核心），得到每個候選的原本第一名 X；聊天第一名已經是它的不收（已經打得出來）。解碼在計數之前。
- **讓不讓第一名**：第二次計數數「原本的第一名」字串的文章數（同一個工具、同一份快照）；名字的文章數要多於它才收（例：「築間」對解碼器拼出的「竹間」）。被擋的名字連同對手與兩邊的文章數記進研究紀錄。
- **讀音**：`tools/readings.py`；CHECK 與多音字由 main 逐條看（例：「樂」「行」「長」「重」照名單層既有的 POLY 規則）。
- **名單層內的同讀音**（`build_names.py` 現在遇到和非 creator 列同讀音就中止，要照下面改）：
  - 新名字（人名或店家）和名單層既有列（標籤 `names`）同讀音：不收（既有列不能移動，兩邊加分相同、先後不可靠）。
  - 店家和 creator 列同讀音：不收（creator 已出貨）。
  - 新的人名和新的人名、新的店家和新的店家同讀音：照 PTT 文章數排，後面的扣 `SLANG_BEHIND`（第 k 個扣 k 倍），只當候選（同 `names-creators.md`）。
  - 新的人名和新的店家同讀音：照文章數排，後面的扣分。
  - 每一種組合在測試裡各有一個例子；被擋的名字與原因記進研究紀錄。
- **建置（只在檔尾追加）**：照 `names-creators.md` §2；店家放新的來源檔 `data/lexicon/names-stores.tsv`（欄位同 `names-creators.tsv`），標籤 `store`；人名照舊放 `names-creators.tsv`（標籤 `creator`）。`tools/build_names.py --append-creators` 改成：
  - 檔尾順序固定為 既有列（`names`）→ `creator` → `store`；
  - 不變式：拿掉 `creator` 與 `store` 列後的 `names-add.tsv` SHA-256 仍是 `77f70524…`；main 上現有 `creator` 列（119 個詞、123 列）逐位元組不變（新人名接在它們後面）；
  - 重跑時換掉的是兩種標籤的列（照兩個來源檔重產）；某一個來源檔不存在或是空的，就不產生那種標籤的列，另一種照舊；兩個都沒有時輸出和追加前相同；
  - 完整重建（不帶 `--append-creators`、`--out` 是詞庫資料夾）也重新追加兩種標籤的列；`names.json` 的 `sources` 分別計 `creator` 與 `store`；標籤排序不再寫死成兩個值。
  - `taken`（已在詞庫的字串）與重複檢查在 `data/packs/meme-add.tsv` 存在時也納入迷因詞包的詞（現在只看基底、疊加層、sandhi、動漫、資訊）；
  - 測試：上面的不變式 SHA、標籤順序、只有 store 檔、只有 creator 檔、完整重建後 store 列還在、新列不和任何一層重複、`meme-add.tsv` 裡已有某個店家字串時 `--append-creators` 不收它。

## 4. 順序、停止、預算、回滾、範圍外

- **和迷因詞包 #293 的先後**：兩個 PR 後合併的那一個，先 merge main、對先合併的那一個重新去重並重新建置，再量測。
- **順序**：這份契約過審 → GCP 解碼全部候選得到 X → 兩次計數（候選、X；可以和網路用語第二輪同一趟開機，但分開計時）→ 建置 → 量測 → PR。
- **停止**：出貨標準任一條不過、回歸集合有改壞而且二分 4 輪找不出是哪個名字；檢查集聊天 < 90%（停下來回報原因再問維護者）；GCP 或量測超出下面的預算。
- **預算**（本片自己的，不含網路用語第二輪的挖掘）：GCP 解碼與兩次計數 ≤ 1 小時；量測一次 ≤ 1 小時，二分每次 ≤ 30 分鐘、最多 4 次；Muse 用維護者的 CLI（不另花錢）。
- **回滾**：revert 這個 PR 的 merge commit；`names-add.tsv` 回到只有既有列與 `creator` 列的內容。
- **範圍外**：中信、誠品、星宇、爭鮮、這一鍋（已在詞庫，見 §0）；重建既有名單；改核心或 App；英文店名；分店名（「XX 信義店」）。
- **授權**：`LICENSES/data.md` 的 `names-add.tsv` 列加 `store` 來源（Muse 建議的名稱字串與 PTT 用量確認、維護者提供；只取名稱，不需另外署名）；`names-stores.tsv` 一列，標明是建置輸入；`eval/dev/names/stores.txt` 一列（CC BY-SA 4.0，同 `creators.txt`）。
