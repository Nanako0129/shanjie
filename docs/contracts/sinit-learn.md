# 句首單字的選字記憶（產品片 SINIT）

狀態：修訂九（2026-11-03）。這份只寫現行規則；修訂二到六之二的審查、掃檔與實作紀錄在 `docs/research-log.md`「SINIT 契約的歷史」與 2026-11-02、11-03 各節，修訂六之二以前的全文在 commit `e2841252`，修訂七的全文在 `c13d0022`，修訂八的全文在 `36e615aa`。修訂八的確認一發照登記不過（「帶我出去玩」和教學句「代我出席會議」前三個音節相同，common 由對變錯 2 列）；第三輪三位顧問的離線投影都指向第四個音節，維護者選「三層前綴」開探索片，第三份確認組照三位的並集事先規定（研究紀錄 2026-11-03）。契約沿用修訂七「不再送審」：照這份直接實作；遠端腳本送審；PR 走兩個 fresh verifier。

## 0. 起因

- 錯字回報第 16 列「照建議」：句首打 ㄓㄠˋ ㄐㄧㄢˋ ㄧˋ 得到「趙建議」，改選「照」之後下次照樣是「趙」。原因是 `Learner::teach` 不學「單字配句首合成鍵」（`docs/contracts/s4-learning.md` §14、`learn-single-ctx.md`）。
- 只看下一個音節的鍵分不出「再加一個」和「在家睡覺」；修訂七量到同鍵的 common 列被拉走（「在寫報告」「在找鑰匙」）。修訂八的兩音節細鍵分不出「代我出席會議」和「帶我出去玩」（第四個音節才分）。看得出差別的有兩樣：同一個開頭多看幾個音節，以及看整句的會意（短的鍵只在會意也同意時生效）。

## 1. 機制

1. **學習（規則 10）**：單字在句首時最多記三個鍵：粗鍵 `^>`＋下一個注音音節（修訂七的鍵）、中鍵 `^>`＋下兩個注音音節（修訂八的細鍵）、細鍵 `^>`＋下三個注音音節；句子在第一個字之後剛好只有兩個音節時，細鍵是那兩個音節加句尾記號 `$`（「照建議」記成 ㄐㄧㄢˋ、ㄧˋ、`$`）。音節之間的寫法由實作定，`learn::single_key_ok` 與 `learn_store::valid` 收它；舊程式載入時被 `valid` 丟掉不認得的鍵。句子在下一個音節就結束時只記粗鍵；`^>$`、`ENGLISH_NEXT`、`DIGIT_NEXT`、單獨 `^`、一字鍵不學；英文、空白與數字讓每一層都不記（粗鍵是 `ENGLISH_NEXT`、`DIGIT_NEXT` 就不學；中鍵與細鍵的音節是英文、空白或數字，就不記那個鍵和比它長的鍵）；標點只讓中鍵與細鍵不記：下一個是標點時，粗鍵 `^>` ＋標點的讀音（例如 `^>_punct_，`）照記，和修訂七的粗鍵一樣（「嗯，」「好，」前的單字值得學；粗鍵只抬，又有會意模型把關），標點在第二或第三個音節的位置則只記到它前面那一層。忘記（⌘⌫）三個鍵一起拿掉。檔案格式不變。
2. **不抬升的池**（修訂七照舊）：一段帶著重排工作（語意校正開、會意已載入）、從句首開始、而且第一個音節有規則 10 紀錄（任何一層）時，候選池、每條候選的 n-gram 分數、錨點（池的第一條）、重排之前的顯示與學習守門都照不抬升的解碼（`Sinit::Off`，含 R1 的讀音項）；抬升的解碼（`Sinit::Lift`）只找「含學到的字」的最好路徑，照不抬升的計分重算後換進池。
3. **進候選池**（修訂七照舊）：候選的第一個字等於紀錄的字，紀錄在那個字打的讀音與句首鍵之下；不在池的前 `TOPK`（8）條就換掉最後一條；n-best 裡沒有就不補；模糊音路徑不算。
4. **融合分數的學習項**：一段只用命中的最長一層（那一段的開頭在那一層的鍵有任何字的紀錄就算命中），三層不相加：
   - 細鍵：`EPS_SINIT_FINE · (b_i − b_0)`，`EPS_SINIT_FINE` ＝ 4，正負兩向都算（學到的字是錨點時，別的候選要贏過它也要多付這一項）。
   - 中鍵：`EPS_SINIT_MID · max(b_i − b_0, 0)`，`EPS_SINIT_MID` ＝ 4，只在會意也偏向這條候選時算（`ll_i > ll_0`），否則 0。
   - 粗鍵：`EPS_SINIT_COARSE · max(b_i − b_0, 0)`，`EPS_SINIT_COARSE` ＝ 2，同樣只在 `ll_i > ll_0` 時算。
   - `b = w/(w+1)`，`w` 是那一層鍵、那一條候選第一個字的紀錄權重（第 3 點的字面認法），沒有就是 0。三個常數具名、註解寫出處（2026-11-03 三位顧問第三輪的離線投影與這份契約）。`pick_masked`、`fused_pick`、`guarded_pick` 三條路都加，手動詞遮罩照舊；三檔共用。
5. **τ**：`ng[0] − ng[1] ≥ τ` 而且有候選的學習項 > 0 時，只有學習項 > 0 的候選可以換掉錨點，要贏過錨點至少 δ；`ng[0] − ng[1] < τ` 時所有候選照現在一樣比。三條路同一個規則。
6. **沒有重排工作時沒有作用**（修訂七照舊）。
7. **不變**：2 個字以上的詞與其他規則的查法、`LEARN_EPS`、`context_key`、學習開關、其他規則的紀錄照舊觸發守門、新詞 B。

## 2. 測試（核心與 CLI；Mac 跑改到的測試檔，完整 `make test-rust` 在 188）

- 選字函式：`b` 全 0 時三條路和現在逐一相同（隨機分數，照 `tinylm.rs` 的 LCG）。細鍵：學習項對第一條相對、正負兩向（學到的字是錨點時，會意分數高一點的未學候選換不掉它）。中鍵與粗鍵：`ll_i ≤ ll_0` 時學習項是 0；`ll_i > ll_0` 時各是 `4·max(b_i − b_0, 0)` 與 `2·max(b_i − b_0, 0)`；錨點學過、候選沒學時是 0（只抬不壓）。同一段有好幾層紀錄時只用最長的一層。τ 的三條路各一例。
- 學習鍵：句首單選一個字、後面還有三個音節以上時，learner 有細鍵、中鍵、粗鍵三筆；剛好兩個音節時細鍵帶 `$`；只剩一個音節時只有粗鍵；中鍵與細鍵的音節有英文、空白、數字或標點時那一層與更長的不記，下一個是英文、空白或數字時連粗鍵也不記，下一個是標點時粗鍵 `^>_punct_，` 照記；`valid` 收三種鍵、丟掉格式不對的；⌘⌫ 三筆都拿掉。修訂八的「代我出席會議」教一次之後，ㄉㄞˋ ㄨㄛˇ ㄔㄨ ㄑㄩˋ ㄨㄢˊ 在聊天與書面都不是「代」開頭（第四個音節不同，掉到中鍵，會意不同意就沒有學習項）。
- 修訂七 §2 的不抬升池、守門與總分、字面認法、會意關、守門的測試照舊（改用新的學習項）。
- `shanjie-replay --strict` 照舊。
- 出貨模型（同步 main 之後，沒有 `#[ignore]`）：錯字回報第 31 列「再測一次」與第 163 列「變一樣了」在書面、「代你保管」在聊天，各自先斷言沒學之前錯，在第一個音節單選正確的字、Enter（斷言 learner 有細鍵那一筆），再打同一串斷言對；不污染：在 ㄗㄞˋ ㄐㄧㄚ（只記粗鍵）與 ㄗㄞˋ ㄐㄧㄚ ㄧˋ（出貨模型顯示「在嘉義」，兩層都記）各教一次「再」之後，ㄗㄞˋ ㄐㄧㄚ ㄒㄧㄡ ㄒㄧˊ 在聊天與書面都是「在家休息」（出貨模型打 ㄗㄞˋ ㄐㄧㄚ ㄧ 本來就是「再加一」，沒有改選可教）；偏好類改回：在 teach 那一句教「她」、再改回「他」一次之後，該組五句都是「他」（細鍵只在同一開頭生效，中鍵與粗鍵受會意門檻，其他句本來就是「他」）。

### 3.2 確認一發（探索過了才做；GCP 主跑、188 第二份）

- 新檔 `eval/learn/sinit-confirm-3.tsv`：6 組語意類，五欄格式，main 新寫的公開句子；每組的（第一音節、第二音節）不和 `sinit-cases.tsv`、`sinit-confirm.tsv`、`sinit-confirm-2.tsv` 任何一組相同。事先規定（三位顧問的並集，維護者 2026-11-03 選）：
  - 至少一組的 teach 列和一列 common 前四個音節相同、第五個音節才分（測細鍵）；
  - 至少一組的 teach 列第二、三音節是常見的雙字詞（例如「今天」「一下」「一次」），而且那組有一列 common 也用同一個詞開頭（測中鍵的會意門檻）；
  - 至少一組的 teach 字是會意反對的字（例如代、牠、祂），兩列 rare 一列和 teach 列前四個音節相同、一列第四個音節不同（測跨句的學習損失）；
  - 另加第 7 組只報、不算進判讀：teach 列剛好三個音節（「照建議」那一型），兩列 rare 是把它接長的句子（量帶 `$` 的細鍵不泛化的損失）。
- 前提（不是結果；main 臂、`--learn off --strict`，聊天與書面）：(a) teach 列至少一種設定錯，而且只錯第一個字；(b) 那種設定兩列 rare 至少一列錯；(c) 兩列 common 兩種設定都對。不合的組換掉；確認檔與前提結果在任何學習數字之前一起 commit。
- 一發：新版對 main 臂，`--learn on --correct --strict`，聊天與書面。通過＝語意類 common 由對變錯合計 ≤ 1 列，而且淨值 > 0。這一發代替出貨標準第 4 條（維護者 2026-11-02 同意）。
