## 2. 前處理與共同規則

- **對錯**：一律用 `experiments/s5-judges/s5.py` 的 `lenient_fn()`（和 S5j、S5k 相同）。「正解在候選內」也用它判斷。
- **判斷器分數**：
  - Q8-ll：直接用 `scores`。
  - Jev：正反序依上表對回候選後平均 p̄(c) = (p_fwd + p_rev) / 2；分數 = log(max(p̄, 0.005))（兩位小數量化的半步）。
  - Laya：正反序依名次逐位平均 p̄，分數 = log(max(p̄, 0.005))。
  - 另報平均後剩下的順序敏感性：正序第 1 名和反序第 1 名不同的列的比例（Jev、Laya）。
- **判斷器推薦**：判斷器分數最高的候選。
- **同分**：任何選擇遇到同分，取 n-gram 名次較前的候選。參數格點同分取較小的值。
- **分位數**：沿用 S5k 的索引規則 `ms[min(n−1, int(n·q/10))]`，q = 1..9，再加上無限大。
- **參數來源**：每個集合的參數只從該集合自己的 A 半選，套到同一集合的 B 半。dev302、typing76 的 A 半很小，只報 B 半、標「小樣本」。

## 3. 組別（同一批候選、同一批分數）

1. **n-gram**：候選第 1 名。
2. **判斷器單獨**：判斷器推薦。
3. **τ 門檻**：n-gram 第 1、2 名分差 `margin` < τ 時採判斷器推薦，否則第 1 名。τ 的格點是 **A 半**的 `margin` 分位數；在 A 半選「修好 − 弄壞」最大的。
4. **加權融合**：每個候選的分數 = n-gram 分數 + w × 判斷器分數，取最高。w 從 {0, 0.02, 0.03, 0.05, 0.07, 0.1, 0.15, 0.2, 0.3, 0.5, 1, 2, 5} 在 A 半選正確率最高的。
5. **單參數 Bayes（只報告）**：先驗 softmax(n-gram 分數 / T)，似然 P(J = j | H_i) = a（i = j）或 (1 − a)/7。T 從 {0.25, 0.5, 1, 2, 4} 在 A 半選（正解在候選內的列，正解先驗的對數機率總和最大）；a = A 半正解在候選內的列裡，判斷器推薦正解的比例。後驗最大的候選。這一組在代數上等於「第 1 名與推薦者的分差 < T·ln(7a/(1−a)) 就採用推薦」，報告時寫出這個等效 τ。

## 4. 評測

- **主要檢定（預先寫死）**：discordtune 的 B 半、判斷器 Q8-ll+ctxall，第 4 組對第 3 組的對錯，McNemar 精確檢定（雙尾）。
- **預先登記的描述統計**（discordtune B 半、Q8-ll+ctxall）：
  - 判斷器對、第 1 名錯、第 3 組沒採用的列數（門檻漏掉的）。
  - 判斷器錯、第 1 名對、第 3 組卻採用的列數（門檻多採的）。
  - 這兩個數字是任何融合能改善的上限。
- **次要**（各自報 p 值，沒有校正，只報告）：每個集合、每個判斷器，第 2–5 組各自對第 1 組與第 3 組的 McNemar。
- **校準**：第 5 組的後驗，在 B 半報可靠度曲線（10 格）與 ECE。分兩種：「正解在候選內的列」與「全部列」（後者把正解不在候選內的列算成錯）。
- **檢定力**：分歧率約 6% 時，B 半 500 列能分辨的差距有限（PLAN 估算約需 1,100 列）。主要檢定不顯著要寫成「這個樣本量下看不出差別」，不寫成「沒有差別」。這一片不加抽樣、不重跑判斷器。
- **報告**：每組在 A、B 半的正確率、修好／弄壞的列數、選出的參數（τ、w、T、a、等效 τ）。
