## 2. 建置工具 `tools/build_it_pack.py`

照動漫詞包的機制（`tools/build_acg_pack.py` 的分數、讀音、排序、衝突偵測，能共用的直接 import）：

- **只收 2–10 個漢字的詞**；含英文、數字、標點的不收，數量列在報告。
- **去重**：詞庫（基底、`overlay-add.tsv`、`sandhi-add.tsv`、`names-add.tsv`）或動漫詞包在任何讀音下已有的字串不收（`CappedLexicon` 依字串封頂，同動漫詞包 A.1）。
- **大陸寫法**（只擋「加進來」，不刪既有詞）：
  - 清單＝15275 的「中國大陸譯名」欄（用維基 API 轉成 zh-hant）∪ CGroup/IT 與 CGroup/Electronics 的 zh-cn 值（轉 zh-hant）。字串在清單裡就不收，**但**字串也出現在任何台灣來源（15275 的中文名稱、15416 的中文名稱、CGroup 的 zh-tw 值、手寫清單）就放行。
  - 子字串標記（事先固定，只用在 15416 與維基 AI 標題）：含「網絡、信息、算法、軟件、硬件、數據庫、默認、視頻、鼠標、內存、緩存、服務器、文件夾、激活、兼容」任一個就不收。比對前先把台灣寫法的「演算法」遮掉（「排序演算法」通過、「排序算法」被擋）；其他標記沒有包含它的常用台灣詞（main 2026-10-23 逐一檢查）。報告列出每個標記擋下的數量。
- **頻率門檻**（只用在 15416 與維基 AI 標題；15275、CGroup、手寫清單照收）：至少 **50** 次才收（49 次不收）。原本訂 20，第一次 GCP 建置的檢查集聊天只有 22／60；維護者 2026-10-23 看過門檻×加分的探索格點後改成 50（研究紀錄同日）。
  - **語料**：`zhwiki-20261001-pages-articles.xml.bz2`（SHA-256 `5db9052efe9ca97aa3da05ffe5b2f12c8ffe5e040f0a9d1ced82ec2fda5d7e2f`，model-v6 與 digits 用的同一份），`experiments/s2/build_counts.py` 的 `articles(10**9)` 取**全部** ns0 條目（上限遠大於條目數；不是前 200,000 篇）。
  - **正文**：`article_sentences(raw, conv, mw, mwconv)`，`mw`／`mwconv` 用 MediaWiki 的 zh-tw 轉換（`s2w-mediawiki-zhtw.md`），`conv` 給**恆等函式**（不套 `convert()` 的 TWPhrases，免得台灣用詞被改寫）。
  - **計數**：每個候選字串在每個句子裡的不重疊出現次數（Python `str.count`），全部條目加總。
  - **候選字串**（不靠建置工具就能產生）：15416 每一列的「中文名稱」先去掉全形與半形括號裡的部分，再依「；」「，」「、」切開（先切會把「甲（乙、丙）」的甲弄丟；2026-10-23 實作時改），留下 2–10 個漢字的字串；加上維基 AI 分類標題的 zh-tw 字串（§2a 的快取）中 2–10 個漢字的。排序、去重、一行一個。建置工具用**同一個切法**（共用一個函式，測試斷言兩邊相同）。

- **專有名詞**（只用在維基 AI 標題）：條目的 Wikidata P31 是人（Q5）、組織（Q43229）、公司（Q4830453，含子類）、作品（Q17537576，含子類）就不收。

- **分數**：照動漫詞包的規則（同字數第 25 百分位），再**加 3**（log10；建置工具的 `BONUS`）。加分之前詞包的列多半贏不了句子解碼；加 3 是維護者 2026-10-23 依同一份格點選的。仍受 `CappedLexicon` 封頂。

  - (c)（詞包詞把既有詞擠下第一名）：既有詞勝，自動丟，列在報告。
  - **參考名單**（(b) 用）：所有來源在任何過濾之前的 2–10 漢字字串（含被頻率門檻、大陸寫法、專有名詞擋下的），報告輸出這份名單。
  - (a)、(b)：列出來由維護者決定（選擇題，推薦在前；超過 50 組先問怎麼分批），決定寫進 `data/packs/it-collisions.tsv`（格式同 `acg-collisions.tsv`）。

## 2a. 抓取與限制

- **主機**：`data.gov.tw` 與國教院的檔案主機 `opendata.naer.edu.tw`（只下載 15416、15275 兩個 CSV）、`zh.wikipedia.org/w/api.php`（CGroup 模組、分類成員、zh-tw 標題、把大陸清單轉成 zh-hant 的 `action=parse` 轉換）、`query.wikidata.org`（P31 與子類查詢）。每秒 ≤ 1 個請求、帶工具的 User-Agent、維基加 `maxlag=5`。
- **AI 分類「往下兩層」**：8 個根分類本身＋它們的子分類＋子分類的子分類，每個分類的成員頁（ns0）都算。
- **快取**：`~/.cache/shanjie/sources/it/`（外接碟），每個請求一個檔；`--offline` 只用快取，缺檔就中止。**抓取由 main 做一次**，之後的建置與測試一律 `--offline`；單元測試只用夾具、不連網。
- **executor 不可以**：連網（只用快取 `--offline`）、讀 `eval/holdout/` 與私人資料、安裝軟體、啟動或安裝 App、push 或開 PR、碰其他 worktree、開 GCP。

## 3. 引擎、App 與評測

1. **引擎**：`PACK_IT = 4`（位元 2；台詞詞包 PR #272 用位元 1），`PACK_FILES` 加 `it-add.tsv`，`PACK_ALL` 跟著改。C ABI 的遮罩說明、`core/include/shanjie.h`、`docs/contracts/s3a.md` 一起改。載入、封頂、檔案不存在時的行為照動漫詞包 A.2。CLI `--packs` 接受 `it`（可以和 `acg` 一起）。
2. **App**：設定與輸入選單加「資訊與 AI 詞」開關，偏好鍵 `itPack`，**沒設過當成開**。切換時照動漫詞包重建引擎。`scripts/build-app.sh` 打包 `it-add.tsv`，`check-app.sh` 核對雜湊。selftest 加這個檔（預設開）。
3. **關掉時**：沒有詞包、只開動漫詞包兩組，聊天與書面，dev302、打字測驗、錯字回報的 `top1_sha256` 和 main 相同；golden 不變。
4. **開著時**，對 main 的出貨（動漫開、資訊關），照出貨標準四條（原文）：
   1. discordtune 聊天：不顯著變差（精確 McNemar p ≥ 0.05 或淨值 ≥ 0），而且改壞 ≤ 26 或改壞÷改對 ≤ 0.6。
   2. 回歸層：打字測驗（聊天、書面）與 dev302 書面，逐列相同或改壞 ≤ 2 且淨值 ≥ 0；dev302 聊天照報、逐列標類別，不擋。
   3. cvtune-clean 聊天：Δtop1 的 90% 配對 bootstrap 下界 ≥ −1.0 個百分點。
   4. 錯字回報（全部列，兩種設定合計）：淨值 > 0 且改壞÷改對 ≤ 0.6。**只加詞的詞包，改壞 0 時算過（含 0／0）**（維護者 2026-10-23 的通用規則，記在 decisions）。
   - 每一列不同都列出來（公開集合寫句子，私人集合只寫數字）。私人集合在 GCP（main 跑）。
   - **動漫集**：`eval/dev/acg/` 的五個集合（works、characters、charparts、recent、interpunct），聊天與書面，基準＝只開動漫，新的＝動漫加資訊：**0 改壞**，有就停；附 `evalstats compare` 表。
5. **詞包本身的檢查集** `eval/dev/it/words.txt`：從詞包用固定種子 **20261024** 抽 60 個詞（每個來源依比例；20261023 那一份在探索門檻與加分時看過了，不再當確認用），一列一詞、沒有前文，讀音照建置用的讀音。報開與關的第一名正確數；**門檻**：開詞包時聊天**與書面**各至少 45 個第一名正確（確認登記：門檻 50、加分 3、13 組撞音照「既有常用寫法勝」處置後重建，種子 20261024 這一份在量之前 commit；同一次也要 §3.3 相同、§3.4 公開集合與動漫集 0 改壞），達不到先回報每個沒對的原因，再問維護者。
6. **實機**（維護者）：開著詞包打「提示詞」「檢索增強生成」「合併請求」「正規表示式」，都是組字區直接出現的第一名；關掉後回到原本的選字。
7. **記憶體與延遲**（這台 Mac、release、閒置窗）：
   - 記憶體：`/usr/bin/time -l` 量 CLI 跑 dev302 聊天的最大常駐記憶體，`--packs acg` 對 `--packs acg,it`，多 ≤ 40 MiB。
   - 延遲：`core/tests/engine_predict.rs` 的 `timing_typing76_keys` 加一個讀遮罩的環境變數（例如 `PACKS=acg,it`，照現有的 `ACG_PACK` 做法），開頭斷言載入的詞庫列數等於「基底＋兩個詞包」的列數；p95 ≤ 16 ms，和只開動漫的值一起報。

## 6. 實作註記（2026-10-23，第一階段；契約文字沒有改，這裡記實作時定的細節）

- **來源的字串**：15275 的「中文名稱」用和 15416 同一個切法（`it_sources.split_names`）；CGroup 的 zh-tw 值用 `build_acg_pack.tw_values`（沒有 zh-tw 才退回 zh-hant，it-sources.tsv 的備註欄標 `zh-hant`）；大陸寫法清單的 CGroup 值用 zh-cn（沒有才用 zh-hans），15275 大陸欄與它們都轉 zh-hant 後，去掉【詞性】與（備註），`[可省略的字]` 有無各算一個。
- **篩選的單位**：子字串標記、大陸寫法、頻率門檻、專有名詞是對「（詞，來源）」各別判斷，一個詞只要有一個來源活下來就收；報告同時列「擋下的來源數」與「因此整個消失的詞數」。大陸寫法清單只能擋到沒有任何台灣來源（含 15416）的詞，實際上只會擋 AI 標題。
- **手寫清單的讀音欄**：第四欄＝另外的讀音（同 `acg-manual.tsv`），詞同時有工具選的讀音和這一個；`it-manual.tsv` 目前沒有這一欄。
- **「已經打得對」**：對所有來源的詞都做（含手寫清單）；用主要讀音、不加變調列。
- **參考名單**（(b) 用）：各台灣來源（15416、15275、CGroup zh-tw、AI 標題、手寫清單）過濾前的字串；大陸寫法清單本身不是名字，不算。
