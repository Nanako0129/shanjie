- **和維護者原話的對照**：這一片只做詞包，不重建模型（維護者選的）；比原話窄的地方列在 §5「範圍外」。

## 2. 建置工具 `tools/build_it_pack.py`

照動漫詞包的機制（`tools/build_acg_pack.py` 的分數、讀音、排序、衝突偵測，能共用的直接 import）：

- **只收 2–10 個漢字的詞**；含英文、數字、標點的不收，數量列在報告。
- **去重**：詞庫（基底、`overlay-add.tsv`、`sandhi-add.tsv`、`names-add.tsv`）或動漫詞包在任何讀音下已有的字串不收（`CappedLexicon` 依字串封頂，同動漫詞包 A.1）。
- **大陸寫法**（只擋「加進來」，不刪既有詞）：
  - 清單＝15275 的「中國大陸譯名」欄（用維基 API 轉成 zh-hant）∪ CGroup/IT 與 CGroup/Electronics 的 zh-cn 值（轉 zh-hant）。字串在清單裡就不收，**但**字串也出現在任何台灣來源（15275 的中文名稱、15416 的中文名稱、CGroup 的 zh-tw 值、手寫清單）就放行。
  - 子字串標記（事先固定，只用在 15416 與維基 AI 標題）：含「網絡、信息、算法、軟件、硬件、數據庫、默認、視頻、鼠標、內存、緩存、服務器、文件夾、激活、兼容」任一個就不收。
- **頻率門檻**（只用在 15416 與維基 AI 標題；15275、CGroup、手寫清單照收）：
  - 在中文維基 `zhwiki-20261001` 全部條目的正文（轉 zh-tw）裡，以字串出現次數計，**至少 20 次**才收。
  - 計數在 GCP 或 Colab 跑（維基已經在那裡用過），只帶回每個候選字串的次數（數字），不帶回正文。
- **專有名詞**（只用在維基 AI 標題）：條目的 Wikidata P31 是人（Q5）、組織（Q43229）、公司（Q4830453，含子類）、作品（Q17537576，含子類）就不收。
- **「已經打得對」的詞不收**：用出貨的 CLI（`data/lm`，雜湊寫成具名常數、開始前核對；開動漫詞包，照出貨），對每個候選詞以讀音工具的讀音單獨解碼（沒有前文），聊天與書面的第一名**都**已經是這個詞，就不收。
- **讀音**：`tools/readings.py`；手寫清單可以給讀音覆寫欄（同動漫詞包 manual）。CHECK 列報告給維護者。
- **「一」「不」的變調列**：照 `build_overlay.py`，同動漫詞包。
- **分數**：照動漫詞包的規則（同字數第 25 百分位）。
- **衝突**（照動漫詞包 A.1、A2 的 (a)(b)(c)）：
  - 解碼用出貨的 `data/lm`（照出貨設定、開動漫詞包），雜湊同上。
  - (c)（詞包詞把既有詞擠下第一名）：既有詞勝，自動丟，列在報告。
  - (a)、(b)：列出來由維護者決定（選擇題，推薦在前；超過 50 組先問怎麼分批），決定寫進 `data/packs/it-collisions.tsv`（格式同 `acg-collisions.tsv`）。
  - 和動漫詞包同讀音的也列出來（這兩包都預設開）。
- **輸出**：`data/packs/it-add.tsv`（疊加層格式，標籤 `it`）、`it-sources.tsv`（每詞的來源）、`it.json`（版本、各來源的筆數與雜湊、被各條規則擋下的數量）；報告放 `build/it-pack/`。同一份輸入建兩次，輸出逐位元組相同。

## 3. 引擎、App 與評測

1. **引擎**：`PACK_IT = 4`（位元 2；台詞詞包 PR #272 用位元 1），`PACK_FILES` 加 `it-add.tsv`，`PACK_ALL` 跟著改。C ABI 的遮罩說明、`core/include/shanjie.h`、`docs/contracts/s3a.md` 一起改。載入、封頂、檔案不存在時的行為照動漫詞包 A.2。CLI `--packs` 接受 `it`（可以和 `acg` 一起）。
2. **App**：設定與輸入選單加「資訊與 AI 詞」開關，偏好鍵 `itPack`，**沒設過當成開**。切換時照動漫詞包重建引擎。`scripts/build-app.sh` 打包 `it-add.tsv`，`check-app.sh` 核對雜湊。selftest 加這個檔（預設開）。
3. **關掉時**：沒有詞包、只開動漫詞包兩組，聊天與書面，dev302、打字測驗、錯字回報的 `top1_sha256` 和 main 相同；golden 不變。
4. **開著時**（對 main 的出貨：動漫開、資訊關）照出貨標準四條判：discordtune（條件 1）、打字測驗與 dev302 書面（2a）、cvtune-clean（2b，聊天與書面）、錯字回報合計（3）。每一列不同都列出來（公開集合寫句子，私人集合只寫數字）。私人集合在 GCP。
5. **詞包本身的檢查集** `eval/dev/it/words.txt`：從詞包用固定種子 20261023 抽 60 個詞（每個來源依比例），一列一詞、沒有前文，讀音照建置用的讀音。報開與關的第一名正確數；**門檻**：開詞包時聊天至少 45 個第一名正確，達不到先回報每個沒對的原因，再問維護者。
6. **實機**（維護者）：開著詞包打「提示詞」「檢索增強生成」「合併請求」「正規表示式」，都是組字區直接出現的第一名；關掉後回到原本的選字。
7. **記憶體與延遲**：開詞包比不開多 ≤ 40 MiB（量法同動漫詞包 A 片）；每鍵延遲 `timing_typing76_keys` p95 ≤ 16 ms。

## 5. 停止條件、預算、回滾、範圍外

- **停止**：關掉時有任何不同；§3.4 四條任一不過；§3.5 門檻不過；記憶體或延遲超過；詞包詞數超過 60,000（先回報各來源的數量再問）。
- **預算**：頻率計數 GCP 或 Colab ≤ 2 小時；§3.4 的私人集合 GCP ≤ 1 小時。
- **回滾**：revert 本片的 merge commit。
- **範圍外**（比原話窄的地方）：
  - **模型重建**（詞進斷詞詞表、加領域語料重算 n-gram）：第二片。前提是先修 `build_counts.py` 對繁體句也套用 `TWPhrases` 的問題。
  - **含英文或數字的詞**（ChatGPT、GPT-4、Web3）：這套流程不處理。
  - **電機工程名詞（15418）**：不用（大多是電機、化學、物理名詞；電子類由 CGroup/Electronics 涵蓋）。
  - 醫藥、法律詞包：PLAN 的下一片。
