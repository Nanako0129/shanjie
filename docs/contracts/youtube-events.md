## 1. A：事件索引 → 候選詞

- **索引**：
  - 峰哥Fege 全部影片的標題、說明欄（含章節時間戳）、標籤、發布日期（Data API，配額每次 < 100 單位；原始回應放 repo 外）。
  - 中文維基「2021年臺灣」到「2026年臺灣」的大事記（MediaWiki API，每秒 1 次；CC BY-SA 4.0）。
  - 事件＝影片標題或章節裡的一件事，或大事記的一列；記日期。
- **候選字串**：
  - 從影片標題、章節、標籤與大事記，切出 2–8 個漢字的字串（人名、綽號、事件名、說法）；
  - 每個事件用新聞標題補（Google News 台灣版 RSS，影片發布日前後 7 天），只取標題裡的字串，不存新聞內容。
- **驗證**（PTT 這一輪抓取是熱門看板 × 最近 300 頁，涵蓋不到 2021 年起的舊事件，所以事件詞不靠它判）：
  - **事件詞**：Google News 台灣版 RSS 在影片發布日（或大事記日期）前後 7 天內，標題含這個字串的新聞 ≥ 3 則、來自 ≥ 2 個媒體。
  - **長期在用**（決定進主詞庫或熱詞清單）：PTT 這一輪抓取裡，含這個字串的文章，時間戳（文章 ID `M.<unix 秒>.A` 的秒數）最早與最晚相差 ≥ 180 天，而且只採計「抓到的頁面本身就跨 ≥ 180 天」的看板；另外要看板 ≥ 5、文章 ≥ 20（net-slang 的門檻）。
  - 這兩項都只讀既有的 PTT 快照，不另外抓，不改 SJ-LM-7 的快照。
  - 去掉已在詞庫各層的字串。
  - **同讀音**（照 `docs/contracts/net-slang.md` §2，PR #281 合併後的版本）：收錄後的第一名若從原本的寫法換成這個詞，而原本的寫法在 PTT 語料的文章數 ≥ 這個詞，這個詞不搶第一；同讀音的新詞照 PTT 文章數排序。
- **分流**：
  - 人名、網名、團體名 → 名單層（`names-add.tsv`，名單增補那一片；維護者 2026-10-24 選實況主名字放名單層）。
  - 長期在用的說法（上面的「長期在用」）→ 網路用語（`slang-add.tsv`，網路用語的後續 PR）。
  - 其他（只紅一陣子的事件詞）→ 熱詞清單 `data/hotwords/hotwords.tsv`（詞、讀音、事件、日期、來源；**不載入、不隨 App 內附**；之後可以做成詞包或給通語當候選）。
  - 有明確出處的台詞 → 迷因詞包那一片的候選。
- **人工審**：main 逐條看分流結果，維護者抽查；讀音照 net-slang 的做法。
- **授權**：詞串來自影片標題（只取名稱）、維基（CC BY-SA 4.0）、新聞標題（只取名稱）、PTT 用量；熱詞清單照 `slang-add.tsv` 的方式標示，`LICENSES/data.md` 加一列。

## 2. B：YODAS v3 篩台灣繁體

- 只下載 `espnet/yodas3` 的中文文字（ASR 稿與上傳者字幕），不下載音訊；記 SHA-256。
- 清理照 `experiments/sj-lm-7/clean_subs.py`（含簡體專用字、假名、亂碼、中英並列過濾）；再判台灣繁體（繁體專用字比例、台灣用語）。
- 報：影片數、句數、漢字數、上傳者字幕與 ASR 稿各多少；Moore–Lewis 的 `cut`（和 C 同一次 `score` 執行，見 §3）。
- **只量、不進語料**：要進通語或會意，另寫一段契約修訂（SJ-LM-7 的語料快照在 PTT 抓完就凍結）。
- 授權：CC BY 3.0，研究語料列加一列。

## 3. C：語音辨識試點

- **工具**：在維護者的 Mac 裝 yt-dlp（Python venv，不動系統）；先不帶登入資料試；被擋才用瀏覽器的登入 cookie，那一步先問維護者。下載的音訊放外接碟 hermit，轉完文字就刪。
- **比較樣本（約 2 小時）**：挑有創作者上傳繁體字幕的台灣影片 12 部（實況、談話、時事評論、VTuber 各 3 部，每部取約 10 分鐘的一段），字幕當參考答案：
  - **逐字抽查**：維護者每部聽約 1 分鐘對照字幕，字幕刪掉贅詞或改寫成書面語的影片換掉；每部的結果記進研究紀錄，全部通過之後才算 CER（約 15 分鐘）。
  - **切段**：參考字幕照時間戳取和音訊同一段（字幕的開始時間落在段內的才算）。
  - **CER 的正規化**：所有系統的輸出與參考字幕都先用同一份 OpenCC `s2twp` 轉成台灣繁體（各系統轉換前的繁體比例另外報），只留漢字（標點、數字、英文都去掉，數字與英文的錯另外抽看，不進 CER）。
- **比較的系統**：TEA-ASR-1.1、Breeze-ASR-25、Whisper large-v3（Colab G4）、ElevenLabs Scribe（送之前先估點數、給維護者看、同意才送）。報字錯率（CER，去標點）、即時率、繁體比例、每小時清理後的句數。
- **50 小時試點**（只用比較出來最好的一個）：從 4 類頻道各取，單部影片最多 50 句、單一頻道最多 40 部。擴大的門檻（三項都要過）：
  - 清理後、**套每部 50 句上限之前**的句數 ÷ 音訊總時數 ≥ 400 句／小時；
  - 從試點裡通過逐字抽查的影片抽 100 句，對照字幕、照上面的正規化算 CER ≤ 5%；
  - Moore–Lewis：在 188 上同一次 `moore_lewis.py score` 執行，逐字稿、YODAS v3（B）與 PTT 推文都用 `--source` 給，打分集合照 SJ-LM-7 §2.4；逐字稿的 `cut` ≤ PTT 推文的 `cut`（分數是 H_in − H_out，越低越像聊天）。這次的輸出放另一個資料夾，不取代 SJ-LM-7 的挑句結果。
- **用途**：只用於計數與訓練、不散布原文、不進常談的公開署名池；要進通語或會意另寫契約修訂（第二階段或下一版通語）。
- **清理**：照 `clean_subs.py`，加語音辨識特有的過濾：同一句連續重複 ≥ 3 次、片尾套話（訂閱、按讚）、音效括號；髒話保留；對所有評測集與保留桶去重（`dedupe_eval.py`）。

## 4. 驗收、停止、預算、範圍外

- **驗收**：A 產出分流好的候選表（主詞庫、名單層、熱詞、迷因各多少）與熱詞清單檔；B、C 的數字寫進研究紀錄。
- **停止**：yt-dlp 不帶 cookie 被擋（停下來問）；C 的比較樣本裡沒有一個系統 CER ≤ 10%；任何一步要動到私人資料或評測集原文，**例外**是照 SJ-LM-7 §2.4 的兩步：對評測集與保留桶去重（`dedupe_eval.py`／清理的守門，只用比對器、只印命中數；私人集合在 188 上做）與在 188 上的 Moore–Lewis 打分（只回 `cut` 與挑句結果）。
- **預算**：Data API 免費額度；Colab G4 ≤ 10 GPU 小時；ElevenLabs 依估算另問；GCP 不用（逐字稿在 Mac 下載、Colab 轉）。
- **範圍外**：把 B、C 的語料放進通語或會意（另寫契約修訂）；把熱詞清單做成詞包；改核心或 App。
