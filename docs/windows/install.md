# 善解 Windows 版：安裝與解除安裝

Windows 版現在是測試版，安裝檔沒有數位簽章，所以 Windows 會多出幾道警告，下面逐一說明。需要 Windows 11（x64）；Windows 10 沒測過。

## 先確認拿到的是真的檔

和安裝檔分開的另一個地方會公布這個檔的 SHA-256。在 PowerShell 算出你手上這個檔的：

```powershell
Get-FileHash .\shanjie-<版本>-x64.msi -Algorithm SHA256
```

輸出的 `Hash` 要和公布的那一串完全相同（大小寫不計）。對不上就不要裝。

## 安裝

需要系統管理員的密碼：善解裝在 `C:\Program Files\Shanjie\`，這台電腦的所有使用者都能用。UAC（使用者帳戶控制）不能關掉。

1. 在檔案總管按兩下 `shanjie-<版本>-x64.msi`。從瀏覽器下載的檔，會看到 SmartScreen 的攔阻：按「其他資訊」，再按「仍要執行」。
2. 歡迎頁按「下一步」，確認頁按「安裝」。
3. 跳出 UAC，上面寫「發行者: 未知」（因為沒有簽章）。確認這是你剛才開的安裝檔，按「是」。
4. 等進度跑完。完成頁寫著「善解已經裝好。已經開著的 App 切一次輸入法就能用。」按「完成」。

按「完成」時善解的常駐程序會一起啟動，不用登出。裝完 Windows 會跳出一則通知，寫著「現在已設定 … 以在您登入時執行」，這是正常的：善解每次登入都會啟動常駐程序（見下面）。

## 開始使用

- 按 Win+Space，選「善解」。已經開著的 App，切一次輸入法就能用。
- 清單裡沒有「善解」：善解登記在「繁體中文（台灣）」底下。到「設定 → 時間與語言 → 語言與地區」，確認有「繁體中文（台灣）」，按它旁邊的「…」→「語言選項」→「新增鍵盤」，選「善解」。
- 剛啟動常駐程序、載入模型的前幾秒，打的字母會先以英文出現，之後恢復。Windows 11 的記事本這類封裝 App 自己不會啟動常駐程序，第一次要有一個一般的桌面程式（例如「執行」對話框）先打過字，或登出再登入一次。
- 怎麼打英文：待 VM 驗收量測，量完補在這裡。

### 登入時啟動的常駐程序

- 輸入法清單裡有善解的每個帳號，每次登入都會啟動一支常駐程序（`shanjie-host.exe`，沒有視窗），載入模型，約占 300 MB 記憶體。
- 不用善解的帳號，把善解從那個帳號的輸入法清單拿掉，登入時就不會啟動：常駐程序一啟動，發現清單裡沒有善解，就直接結束。
- 用 `/qn` 這類沒有完成頁的方式裝的，不會立刻啟動；下次登入才會啟動，所以要登出再登入一次。

### 隱私

Windows 版不學習、不連網、不記錄打的字。

## 升級

執行新版的 `.msi`，直接蓋過舊版，不會問要不要保留設定，設定照樣保留。裝了較新的版本時不能降版，會顯示「這台電腦已經裝了較新版本的善解。」

已經開著的 App 在重開之前還是用舊版；新開的 App 用新版。

## 解除安裝

設定 → 應用程式 → 已安裝的應用程式 → 善解 → 「…」→ 解除安裝。UAC 之後會出現一個問題：

- 「要解除安裝善解嗎？」，下面有一個勾「保留設定」（預設勾著）和兩個按鈕「解除安裝」「取消」。按「取消」什麼都不會變。

從同一個地方選「修改」→「移除」也可以：「要保留什麼」那一頁有同一個勾。

**「保留設定」**：善解的設定存在這個帳號的 `HKCU\Software\Shanjie`（現在只有按鍵習慣這一個值，還沒有設定頁）。勾著就留下，沒勾就刪掉。只動執行解除安裝的這個帳號，其他帳號的設定不會碰。

不論勾不勾，一律清掉：安裝資料夾裡的檔案、輸入法的註冊、登入時啟動的項目，以及正在跑的善解常駐程序。還開著、正在用善解的 App，要等它們重開之後，善解才會完全移除。解除安裝不關任何 App，也不會自己重開機。

### 用命令列安裝與解除安裝

在以系統管理員身分開啟的命令列：

```text
msiexec /i shanjie-<版本>-x64.msi /qn
msiexec /x shanjie-<版本>-x64.msi /qn
msiexec /x shanjie-<版本>-x64.msi /qn KEEPSETTINGS=0
```

- `/qn` 不顯示任何畫面。解除安裝時不問問題：沒給 `KEEPSETTINGS` 就保留設定；`KEEPSETTINGS=0` 刪掉設定，`KEEPSETTINGS=1` 保留，其他值當作保留。
- `/passive` 解除安裝一樣會跳出上面那個問題，而且對話框拿不到鍵盤焦點，要用滑鼠點。要無人值守，用 `/qn`。
- 解除安裝時，如果有 App 還開著、占著善解的檔案，結束碼仍是 0（不是 3010），也沒有重開機提示。占著的檔案不用重開機就能重裝。

## 已知限制

- UAC 關掉的機器不能用。
- 開著 Smart App Control 或公司的應用程式控制（WDAC）的機器，可能擋下未簽章的安裝檔或 DLL；防毒軟體也可能把載進每個 App 的未簽章 DLL 當成可疑。這兩種都還沒測過。
- 沒有繁體中文語言的帳號還沒測過。用另一個管理員帳號的密碼過 UAC 安裝或解除安裝，結果（誰的輸入法清單有善解、誰的設定被刪）也還沒測過。
- 目前沒有自動更新；要新版就下載新的 `.msi` 執行。
