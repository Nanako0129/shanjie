選字品質：看前文、新的語言模型、即時預測。

- **看前文選字**：讀取游標前已經送出的文字（按過 Enter、已經在文件裡的字），接著它選這一段的第一個詞；分好幾次送出的句子，選字仍接得上前面。
- **新的語言模型（`model-v4`）**：
  - 台灣常用的字形（床、秘、灶、粽…）不再被當成簡體字轉成異體字，「起牀」「祕密」回到「起床」「秘密」。
  - 語料轉換後留下的「最后」「由于」「哪里」這類簡體寫法清掉；「十分鐘後到」「好吧」這類搭配也選對了。
  - 同讀音的不同寫法合併計數。
  - 模型含有少量用來辨識來源的指紋條目，不影響選字。
- **詞類回退**：兩個詞沒在語料裡一起出現過時，用「哪一類詞後面常接哪一類詞」補估計（詞類表 `classes-v2`）。
- **容易誤觸的詞往後排**：詞庫為了容錯收錄的非標準讀音，不再擋住同音的一般詞（例如打「搞完這波」）。
- **即時預測**：打下一個詞的第一個注音，候選窗就列出接得上前文的詞；按 Tab 進入選取，不會自動替換你打的字。從預測列選過的詞會記住。選單可以關掉「即時預測」。
- **候選窗**：跟著 App 的淺色或深色外觀切換；候選列高度改成和蘋果注音相同。
- 其餘是文件、評測資料與研究紀錄的更新。
