聊天設定更會選口語的用字，書面設定的語意校正也調過；輸入法改在 App 沙盒裡執行，更新交給另一個小程式；安裝程式可以裝給這台 Mac 的每個帳號。

- **聊天更懂口語**：聊天設定的語意校正多參考兩樣東西（只在聊天設定）：
  - 口語詞頻表「常談」（SJ-CL-1-68K，詞彙 68,055）。它只有詞與詞對的次數、不含句子；來源與授權列在 `LICENSES/data.md` 與 Release `sj-cl-1-68k` 的署名清單。
  - 單字的讀音：打的讀音不是那個字最常見的讀法時，比較不會選它。
  - 例如「桌腳的螺絲鬆掉了」「是不是很雷啊」「變快」，用同樣的條件重播，上一版的設定選成「羅斯松」「很累」「便會」，這一版都選對。
  - 已知：「長歪了」會選成「掌歪了」，詞庫裡「長」讀ㄓㄤˇ的分數有誤，之後修。
- **書面設定的語意校正換參數**：會意換成 SJ-SR-6-14M，權重和上一版相同，只重選書面設定的融合參數（α 0.7、τ 2、δ 1）。聊天設定的參數不變。
- **安裝程式多了「這台 Mac」**：歡迎頁有兩個並列的選項，沒有預設。
  - **這台 Mac**：裝到 `/Library/Input Methods`，檔案由系統保護，這台 Mac 的每個帳號都能用。有程式開著安全輸入時（密碼管理器、終端機的「加密的鍵盤輸入」），善解不再反灰，照常能用（學習暫停、不讀前文）。代價是安裝與每次更新各要輸入一次管理員密碼。
  - **只有我的帳號**：和之前一樣，不需要密碼；有程式開著安全輸入時，系統仍會暫時停用善解。
  - 自動更新上來的人仍在自己的帳號裡；要搬到「這台 Mac」，重新打開這一版的安裝程式選它。學習資料與設定不受影響。
  - 換了位置之後要登出再登入一次，安裝程式最後一頁會提醒；第一次裝給這台 Mac 時，登入後還要到「系統設定 → 鍵盤」把善解加入，最後一頁會寫步驟。系統設定跳出來蓋住安裝程式時，安裝程式會自己回到前面。
  - Homebrew 只裝在你的帳號。
- **App 沙盒與「善解更新」**：輸入法本體在 App 沙盒裡執行（活動監視器的「沙盒」欄位是「是」），只開三個權限：沙盒本身、對外連線（只為了檢查更新）、註冊輸入法的連線。
  - 第一次啟動這一版時，學習資料與偏好設定會搬進沙盒的資料夾；學過的選字、新詞、倚天排列與各項設定都還在。
  - 按「更新到 X」之後，由 App 裡另一個不在沙盒裡的小程式「善解更新」下載、驗證並安裝，它只會更新已安裝的那一份善解。裝在「這台 Mac」時，系統會跳出密碼框，文字是「善解更新 wants permission to update 善解輸入法.」。Sparkle 升到 2.10.0。
  - 沙盒擋不住輸入法把輸入內容送出去；它限制的是程式被攻破時碰得到的檔案與程式。
- **中英文之間自動加空格**（設定 → 選字，預設關）：在漢字和半形英文、數字之間自動加一個空格（俗稱「盤古之白」），例如「我用claude寫」送出成「我用 claude 寫」。只改善解送出的文字，標點旁邊不加。
- **關於頁列出內附的模型**：設定的「關於」頁多一節「模型」，列出這一版內附的六個模型（中文名與對外名稱）。
- **跨版本比較**（v0.4.7 → v0.5.0，出貨設定，`docs/benchmark.md`）：兩種設定都沒有集合顯著變差。
  - 聊天：Discord 聊天評測集（4,958 句）86.81% → 87.90%（改對 88／改壞 34，p 1.1e-6）、cvtune（3,791 句）90.95% → 91.93%（53／16，p 9.1e-6）、lytune（4,811 句）83.91% → 87.32%（191／27）、錯字回報（80 句）28 → 33 句（7／2，p 0.18，不顯著）。wikitune（2,827 句）77.57% → 77.26%（37／46，p 0.38，不顯著）。
  - 書面：wikitune 78.95% → 80.16%（39／5，p 1.4e-7）、Discord 聊天評測集 85.07% → 86.06%（69／20）、cvtune 90.74% → 91.80%（42／2）、lytune 84.81% → 85.68%（74／32）、錯字回報 24 → 29 句（6／1，p 0.13，不顯著）。
  - 打字測驗（76 句）：兩種設定都是改對 0／改壞 0。
  - 保留集（shard-1，300 句）：聊天 234 → 237 句（7／4，p 0.55）、書面 233 → 241 句（8／0，p 0.0078）。口語那一半用聊天設定 116 → 115（3／4），新聞那一半用書面設定 116 → 120（4／0）。
  - 速度與記憶體（兩版在同一台機器、同一場輪流跑，load avg 約 4）：每鍵 p95 2.00 → 2.05 ms，引擎載入 752 → 905 ms，記憶體（RSS）430 → 441 MB。
