- **安裝程式多了「這台 Mac」**（`docs/contracts/system-install.md`）：歡迎頁有兩個並列的選項，沒有預設。
  - 這台 Mac：裝到 `/Library/Input Methods`，檔案由系統保護，這台 Mac 的每個帳號都能用。有程式開著安全輸入時（密碼管理器、終端機的「加密的鍵盤輸入」），善解不再反灰，照常能用（學習暫停、不讀前文）。代價是安裝與每次更新各要輸入一次管理員密碼。
  - 只有我的帳號：和之前一樣，不需要密碼、一鍵更新；有程式開著安全輸入時，系統仍會暫時停用善解。
  - 自動更新上來的人仍在自己的帳號裡；要搬到「這台 Mac」，重新打開這一版的安裝程式選它。學習資料與設定不受影響。
  - 換了位置之後要登出再登入一次，安裝程式最後一頁會提醒；第一次裝給這台 Mac 時，登入後還要到「系統設定 → 鍵盤」把善解加入，最後一頁會寫步驟。
  - Homebrew 只裝在你的帳號。
