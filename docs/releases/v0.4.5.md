中英混打可以不按空白直接打英文，選了的英文會留在組字區，和中文一起送出。

- **英文的顯示**（設定的「選字」，中英混打開關下面）：預設「打字時就顯示」。打英文單字時，打到 3 個字母以上、而且看得出是單字表裡某個字的開頭（有按鍵把注音的同一欄取代掉），組字區就直接顯示字母，不用按空白；短的字、或按鍵剛好拼成正常注音的字，打的當下仍是注音，按空白照 v0.4.4 開英文窗。改成「按空白才顯示」時，打字當下一律顯示注音、按空白才開英文窗，和 v0.4.4 相同；下面「英文留在組字區」的第一點、Shift 英文段與逐字母刪除，兩種設定都有。
- **英文留在組字區**：
  - 從英文窗選了英文，英文留在組字區，可以接著打中文，Enter 一次送出（例如「我在用rust編譯」）；以前選了英文會立刻送出。兩種顯示設定都一樣。
  - 「打字時就顯示」時，字母顯示著、打完一個完整的單字之後直接接著打注音，英文會自動留下，不必按空白。
- **Shift＋字母打一段英文**：中英混打開著時，按住 Shift 打的第一個字母開始一段英文（例如 `Windows`、`iPhone`），粗底線標出這段，旁邊有一行提示。按一下空白結束這段英文，再按一下才是空白。
- **英文可以改寫法**：游標緊接在英文後面時按 ↓，可以換成小寫、首字大寫、全大寫；打完英文直接接中文而自動留下的英文，清單最後還有同一串按鍵打出的中文字（詞庫裡有那個音才有），想打的其實是中文時可以換回來。
- **英文逐字母刪除**：Backspace 一次刪一個字母，剩下的字母可以接著打。「打字時就顯示」時，如果英文剛好是個完整的字、打錯的下一個字母讓它自動留下並開始一個注音（例如 `rusr`：`rus` 是字，最後的 `r` 變成 ㄐ），按 Backspace 刪掉那個注音，英文會回到可以接著打的樣子；從英文窗選的英文、Shift 打的英文段不會這樣，刪掉後面的注音之後照舊打注音。
- 中英混打仍是實驗功能，預設關；只支援標準鍵盤排列。
- **跨版本比較**（v0.4.4 → v0.4.5，出貨設定，`docs/benchmark.md`）：
  - 選字結果沒有變：十個評測集合在聊天與書面兩種設定都是改對 0、改壞 0，保留集聊天 191／227、書面 186／227 也和 v0.4.4 相同。評測時中英混打是關的（和預設一樣），所以這些數字不涵蓋中英混打開著時的情況。
  - 速度（dev302 重播，兩版同一場、中英混打關）：每鍵 p95 2.42 → 2.34 ms；語意校正每次重排的 p50／p95 6.80／8.71 → 8.08／12.16 ms，變慢的原因沒有查。中英混打開著時每鍵多做的字首查詢沒有量過。
