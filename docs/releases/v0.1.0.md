善解的第一個公開版本：macOS 的注音輸入法，用語言模型整句選字。

- **輸入法本體**：InputMethodKit 殼層＋Rust 核心；輸入法選單只有一個「善解輸入法」，可在選單切換標準與倚天鍵盤排列。
- **整句選字**：bigram 語言模型（`model-v1`）解碼整句，聊天與書面兩種設定依前景 App 自動切換。
- **候選窗**：空白鍵或 ↓ 開候選，數字鍵選字，Enter 送出整句。
- **安裝**：`shanjie-0.1.0.zip` 內是簽章、公證過的 `善解輸入法.app`；同時發佈 Homebrew cask（Nanako0129/homebrew-tap）。安裝步驟見 README。
- 詞庫來自小麥注音（MIT），語言模型以 CC BY-SA 4.0 釋出；授權細節見 `LICENSES/`。
