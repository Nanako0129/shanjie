書面設定的選字改看前兩個詞（連文模型），設定裡多了「關於」頁與自動更新，輸入法也有了自己的圖示。

- **這一版要手動更新一次**：v0.4.6 以前沒有自動更新。用 Homebrew 裝的請執行 `brew upgrade --cask nanako0129/tap/shanjie`，其他人下載這一頁的安裝程式。從 v0.4.7 起，之後的版本可以在輸入法裡直接更新。
- **書面設定看前兩個詞**：書面設定在解碼時加上三元表「連文」（SJ-CX-1-7.7M，7,700,964 條，跟著通語 SJ-LM-6-9.1M），這時不用 KN 平滑；聊天設定與預測列不變。
  - 三元表用唯讀映射載入：活動監視器看到的記憶體（peak footprint）只多約 2 MB；安裝檔多約 44 MB。
- **「關於」頁與自動更新**（設定→關於）：
  - 顯示版本，有「自動檢查更新」開關（預設開）與「立即檢查」。
  - 自動檢查每天最多一次，只查有沒有新版、不跳視窗；有新版時關於頁與輸入選單出現「更新到 X」，按下才下載安裝（Sparkle 2.9.3）。
  - 連線內容：讀 GitHub 上的 `appcast.xml`，GitHub 看得到你的 IP 與請求標頭；不送任何輸入內容、選字記憶或系統資訊。更新檔安裝前驗證 EdDSA 簽章。關掉開關就不做背景檢查。
- **App 圖示**：朱紅印章「解」，框與字是兩層玻璃；Finder 與安裝程式都看得到，之後的更新視窗也會用這個圖示。字形取自 Noto Serif CJK TC（SIL Open Font License 1.1）。
- **跨版本比較**（v0.4.6 → v0.4.7，出貨設定，`docs/benchmark.md`）：
  - 聊天設定：每個評測集合的結果都和 v0.4.6 相同。
  - 書面設定：四個集合顯著變好，沒有集合顯著變差。

    - cvtune（3,791 句）：90.11% → 90.74%（75／51，p 0.04）
    - 錯字回報（80 句）：26 → 24 句（5／7，p 0.77），不顯著。
  - 保留集（換新後的 shard-1，300 句）：聊天 234 → 234 句（0／0）、書面 230 → 233 句（7／4，p 0.55）。
