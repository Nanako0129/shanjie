# P4d：口語項放回小模型那一層，n-gram 第一名當錨點（探索；2026-10-20 登記）

P4c（`experiments/p4c-colloquial/README.md`）照登記不過：discordtune 129／78，淨值 +51（p 0.0005），但改壞÷改對 0.60，打字測驗淨值 −1。**這條線沒有結案**（維護者 2026-10-20：「以後真正結案要我准許」，目標是改進到能出貨）。維護者請兩位研究顧問分析，再請 Argon 想「有沒有更好的評分方式」，看完後選了這一片的做法（同日選擇題）。這一頁在任何 P4d 的數字之前 commit。

Argon 的診斷（分析全文在 repo 外；dev302 上的數字 main 獨立重算過）：
- **錨點被搶走**：P4b、P4c 把口語表放在融合之前，先依 s 重排，再把 s 的第一名當融合的錨點（`pick` 的第 0 名）。口語表換掉 n-gram 第一名時沒有任何門檻；換上來的字反而受 δ 保護，原本對的字要多贏 2δ 才換得回來。〔推論〕P4c 選到 δ 0 可能就是在拆這個保護；那一格在 discordtune 有 35 列「s 第一名對、融合改錯」的改壞，但那一格同時把 α 調到 0.5，兩者各佔多少沒有分開量。
- **選格和判讀的目標不一致**：選格取 1:1 淨值最大，判讀卻看 2:1（改壞÷改對 ≤ 0.5），選格就容易貼在比例的邊上（P4c 選中的格在 chatclause 是 0.45，到 discordtune 是 0.60）。改壞÷改對 ≤ 0.5 和「改對 − 2×改壞 ≥ 0」是同一條標準。

探索片：只用調參層（chatclause、cvtune-clean）、開發層（discordtune）與回歸層集合，不碰判讀集與保留集；不改核心與 App，不出貨。

## 做法

- 每個集合用 CLI 的出貨設定跑一次（`--profile chat --context --packs acg --tinylm data/lm/tinylm.sjtl`，加 `--dump --dump-words --rowstats --tinylm-scores`）。不需要 `--colloquial` 的重跑：口語項只在前 8 名上算。
- **口語項**：候選 i 的 col_i = lc_i − 0.5·k_i（P4 的 T2 表 `2984eeb5…` 的 lc，疊加層與詞包詞數 k；γ = μ/2，等於 P4c μ 0.5 那幾格的比例）。程式重用 `experiments/p4-colloquial/p4.py` 的 `Table`、`precompute` 與 `d23` 的讀列與一致性檢查。
- **評分**：前 8 名照 n-gram 的順序，第 0 名（n-gram 第一名）是錨點。
  - ll_eff_i = ll_i + g_i·(μ/α)·(col_i − col_0)；g_i = 1（不加閘門），或 1 / (1 + exp(−(ll_i − ll_0)/T))（軟閘門：小模型越不贊成，口語項壓得越低）。
  - 再照出貨的 `pick`（`core/src/tinylm.rs`，`tools/triage.py` 逐行相同）用這一格的 α、τ 2、δ 0.25 選字。融合分數等於 ng_i + α·ll_i + g_i·μ·(col_i − col_0)：口語項只能透過融合的差距起作用，換第一名仍要贏過 δ，n-gram 分差 ≥ τ 的列照舊不看。
- **格點**（事先固定，24 格）：μ ∈ {0.15, 0.25, 0.35, 0.5} × α ∈ {0.3, 0.5} × 閘門 ∈ {無, T 1.0, T 0.5}；δ 0.25、τ 2 固定。
- **對照**（不參與選格）：μ 0、α 0.3 就是出貨設定，**錨點**：每一列的選字要等於 CLI 的 `c`、對錯要等於 rowstats，不等就停；μ 0、α 0.5 是「只調強融合、不加口語表」那一臂，把口語表本身的貢獻和融合調強的貢獻分開（dev302 上只調 α 就是 8／0，口語表只多 1 列）。
- 程式：`experiments/p4d-colloquial/p4d.py`＋單元測試 `test_p4d.py`，走 `/code-review`（探索片，不送 verifier）。

## 選格（只在 chatclause，n 5,761）

- 在「改對 − 2×改壞 ≥ 0」的格裡，取「改對 − 2×改壞」最大的一格（Argon 的建議，維護者同日選定）；同分取淨值大的，再取 μ 小的，再依閘門「無、T 1.0、T 0.5」的順序，最後取 α 0.3。
- 沒有任何一格合格 → 停下來報告，和維護者討論下一步（不結案），discordtune 不跑。
