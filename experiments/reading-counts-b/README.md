# 讀音計數 B，第 0 步：診斷＋零成本的新表（探索；2026-10-23 登記，在任何數字之前）

## 起因與決定

- R1e（讀音項進解碼器）四條全過、產品片進行中。讀音項 t(r, w) 用的是 R1c 的 B-f 表（lexf：詞庫分數的相對值，底分 −6.8 改用 mc，「一」「不」的變調免扣）。
- 兩位研究顧問（Fable、Argon，報告在維護者本機）與 main 在詞庫上核對：單字破音字 3,584 個裡 **3,061 個所有讀音同分**（t 全是 0，讀音項不起作用）；其餘 523 個字的 617 個次要讀音裡 539 個是底分、63 個是固定打折 −0.69、14 個 −1.39，還誤罰「波 ㄅㄛ」「嗎 ㄇㄚ˙」「和 ㄏㄜˊ」等常用讀音。評測讀音由 `tools/readings.py` 產生（主讀音），量不到「次要讀音被扣」的改壞。
- 維護者 2026-10-23 選「診斷＋零成本的新表一起做」：兩位顧問都同意的零成本診斷，加 Argon 的 mc-split 表當第一臂，對 R1e 的現行表判。語料計數、LLM 標注是第二步，另外登記。

## 臂（事先固定，不選格）

- **T0**：R1e 現行的 B-f 表（`core/src/reading.rs`）。
- **T1（mc-split）**，從 T0 起，只改三處：
  1. **同分字拉開**：單字 w 在合併後詞庫的所有讀音分數都相同時，改用多字詞的質量：m(r) ＝ Σ 10^{s(r, u)}，u 是 `mcbpmf-data.txt` 裡至少兩字、而且某個位置是 w 讀 r 的詞條（同一個（讀音, 詞）取最大一列；就是 P5 `mc_logp` 的質量）。t(r) ＝ log10((m(r) + ε) ／ (max m + ε))，ε ＝ 10^−9。所有 m 都是 0 的字維持 t ＝ 0。
  2. **免扣清單**（t ＝ 0，事先固定）：語尾字「嗎 啦 嘛 吧 啊 呀」的一聲與輕聲讀音；（波, ㄅㄛ）、（癌, ㄞˊ）、（和, ㄏㄜˊ）、（麼, ㄇㄛ˙）；以及 B-f 原本的變調免扣。
  3. **A1 的 44 個字**（`docs/contracts/reading-aware-0.md` §3.2「降」那一組）：單字的 ˙ 讀音 t ＝ min(t, −1.0)。
  - 讀音項照舊 λ 2.0、c 4，只換表。

- **實作註記（2026-10-23，在任何數字之前）**：
  - 「改變選字的列數」＝每一列實際選出的字串不同（不是對錯或編輯距離不同）。每一跑另帶 `--tinylm-scores` 與 `--dump`（語意校正開的設定）或 `--dump`（關的設定），選字＝傾印裡 `c` 那一名（關的設定是第 1 名）。

- **停止規則**：chatclause 改變選字 14 列、wikitune 16 列，都 ≥ 5，沒有觸發「表的形狀已經不是瓶頸」。
- **診斷**（點火表，聊天標準 discordtune）：T1 新扣的「個 ㄍㄜˋ」（t −0.77）出現在 49 個正解候選、716 個錯誤候選；「欸 ㄟˋ」（−1.19）在 13 個正解候選。〔推論〕第 1 條規則用多字詞的質量（「一個」等的輕聲）去估單字「個」的讀音，正是顧問提醒的「詞內≠單獨」；聊天裡單獨的「個」大多打四聲。T1 對 T0 |Δt| ≥ 0.5 的對共 272 個。
