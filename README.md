# 善解 shanjie

以「選字正確」為第一優先的開源 macOS 注音輸入法（開發中）。

- 計畫：`docs/PLAN.md`
- 授權：程式碼 Apache-2.0（`LICENSE`）；資料見 `LICENSES/data.md`
- 想參與開發：見 [`CONTRIBUTING.md`](CONTRIBUTING.md)

## 進度

最新發佈是 [v0.3.0](https://github.com/Nanako0129/shanjie/releases)：可以安裝使用的注音輸入法。
- 標準與倚天鍵盤；整句轉換（詞庫＋bigram 語言模型＋詞類回退）；教育部「一／不／法」讀音變體。
- 看前文選字：讀取游標前已經送出的字，接著它選這一段的第一個詞。
- 即時預測：打下一個詞的第一個注音，候選窗就列出接得上前文的詞（Tab 進入選取，選單可關）。
- 選字記憶：從候選窗的改選與預測列的選取學習，依前文分開記；單字只在前文完全相同時套用；清除前會跳確認視窗。
- 自建的 Liquid Glass 候選列，跟著 App 的深淺色；標點附上和蘋果相同的名稱；按 ↓ 往下疊出更多候選列，每列 9 個。
- `[`、`]`、`\`、`` ` `` 不按 Shift 也打出標點，標準鍵盤的 `'`、`=` 也是（比照蘋果注音；倚天鍵盤這兩個鍵是注音）；組字區是空的時候按聲調鍵，打出聲調符號。

**下一版**：
- 動漫與遊戲詞包：約 3 萬個作品名與角色名（例如「愛蜜莉雅」「進擊的巨人」「乙骨憂太」），選單「動漫與遊戲詞」，預設開、可關，下方灰字標示資料更新到哪一天。來源是中文維基百科的公共轉換組與作品條目的人物（作品清單來自 Wikidata 的前 400 部，加上維基百科「日本動畫列表」最近 7 年的年度清單），以 CC BY-SA 4.0 釋出，署名 Wikipedia 貢獻者；建置時逐一檢查詞包詞，同樣的讀音原本會打出詞庫裡的詞時，就丟掉這個詞包詞；
- 新詞：從改選記住新的詞組（例如「版控」這類口語縮寫），之後是從語料自動找新詞與手動加詞；
- 改選後其他字不動：暫停，等新詞做完再照蘋果的實測重新評估；
- 即時預測的「可省略韻母」設定、App 沙盒。

細節見 `docs/PLAN.md` §2「版本對應」。

## 安裝

需要 macOS 26（Tahoe）以上、Apple 晶片。下面兩種方式擇一；要換方式時，先刪掉 `~/Library/Input Methods/善解輸入法.app`。

**Homebrew**

```sh
brew install --cask nanako0129/tap/shanjie
"$HOME/Library/Input Methods/善解輸入法.app/Contents/MacOS/shanjie" install
```

第二行在系統還不認得善解時註冊並啟用輸入方式；已經啟用的話什麼都不改。結束碼是 3 時，表示系統還沒接受：到「系統設定 → 鍵盤 → 輸入方式」按「+」，選「繁體中文」裡的「善解輸入法」，按「加入」。

升級用 `brew upgrade --cask nanako0129/tap/shanjie`（`brew update` 只更新清單，不會換掉輸入法）。升級到 0.3.0 之後的版本時，brew 會在新版放好後結束舊的輸入法，系統下次啟動的就是新版。升級到 0.3.0 或更早的版本時，舊的還會繼續跑，要再執行：

```sh
pkill -f '^[^ ]*/Library/Input Methods/(善解輸入法|shanjie)\.app/Contents/MacOS/shanjie$'
```

升級後如果選單裡找不到善解，到「系統設定 → 鍵盤 → 輸入方式」把它加回來（升級時系統偶爾會把它移出已啟用清單）。

**手動**

從 [Releases](https://github.com/Nanako0129/shanjie/releases) 下載 `shanjie-<版本>.zip`（`v` 開頭的那幾個；`model-v…`、`classes-v…` 是語言模型與詞類表，已經包在 App 裡，不用另外下載，說明見 `docs/data-files.md`），用 Finder 解壓，然後在這個 repo 的根目錄執行：

```sh
scripts/install-ime.sh <解壓出來的 善解輸入法.app 路徑>
```

也可以從 Releases 下載 `shanjie-installer-<版本>.zip`，解壓後點兩下「安裝善解輸入法」（測試中）。

裝好後在選單列的輸入法選單選「善解輸入法」；標準／倚天鍵盤在它自己的選單裡切換。選單裡的「善解設定…」會開一個設定視窗，選單上的各項設定都能在裡面改，另外有候選窗的方向（橫排或直排）與玻璃深淺。
