# 善解輸入法 shanjie

以「選字正確」為第一優先的開源 macOS 注音輸入法（持續開發中）。網站：https://shanjie.nyanako.com （介紹、安裝與更新紀錄）

- 規格：`docs/spec/`（現在的行為）
- 授權：程式碼 Apache-2.0（`LICENSE`）；App 內含的 Sparkle（自動更新）是 MIT（`LICENSES/Sparkle-MIT.txt`，含它附帶的第三方授權）；資料見 `LICENSES/data.md`
- 想參與開發：見 [`CONTRIBUTING.md`](CONTRIBUTING.md)

目前有的功能（括號是出貨的版本）：
- 標準與倚天鍵盤（v0.1.0）；整句轉換：詞庫＋bigram 語言模型（v0.1.0），詞類回退（v0.3.0），同樣的字依最後一個詞分開保留斷法（v0.4.3）；教育部「一／不／法」讀音變體（v0.1.2）。
- 看前文選字：讀取游標前已經送出的字，接著它選這一段的第一個詞（v0.3.0）。
- 即時預測：打下一個詞的第一個注音，候選窗就列出接得上前文的詞，Tab 進入選取，選單可關（v0.3.0）；起點往回找 5 個音節（v0.4.0）。在 Chrome、Edge 等瀏覽器裡，第一個字不顯示預測（Google 文件會把它擺到視窗左上角；設定可關，v0.6.1）。
- 選字記憶：從候選窗的改選與預測列的選取學習，依前文分開記；單字只在前文完全相同時套用；清除前會跳確認視窗（v0.2.0；預測列的選取也會學：v0.3.0）；句首學到的詞要後面接的音相同才加分，單字只在緊接兩個漢字的前文後面記（v0.4.2）。
- 自建的 Liquid Glass 候選列、標點附上和蘋果相同的名稱、按 ↓ 往下疊出更多候選列，每列 9 個（v0.2.0）；候選窗跟著 App 的深淺色（v0.3.0）；候選窗可選直排（v0.4.0）。
- `[`、`]`、`\`、`` ` `` 不按 Shift 也打出標點，標準鍵盤的 `'`、`=` 也是（比照蘋果注音；倚天鍵盤這兩個鍵是注音）；組字區是空的時候按聲調鍵，打出聲調符號（v0.2.0）。
- 動漫與遊戲詞包、設定視窗、新的安裝程式（v0.4.0）；動漫詞包補上含間隔號的名字，約 4.5 萬詞（v0.4.1）。
- 語意校正：小型字元語言模型在背景重排整句的前 8 名，不產生新字，預設開，選單或設定視窗可關（v0.4.1）；聊天／書面可在設定視窗自己選（v0.4.1）；聊天設定多參考口語詞頻表「常談」與讀音通道項（v0.5.0），三種強度都生效（v0.6.0）；讀音通道項之後改成解碼器本身的讀音項（所有設定都生效，尚未出貨，`docs/spec/decoder.md` §5）。
- 書面設定看前兩個詞（三元表「連文」，v0.4.7）；設定的「關於」頁與自動更新（v0.4.7）；關於頁列出內附的模型（v0.5.0）。
- 中英混打（實驗，v0.4.4）：打英文留在組字區和中文一起送出、Shift＋字母打一段英文（v0.4.5）；v0.5.0 起預設開；標準排列下數字列直接打數字，數字後的預測列看前文（v0.5.0）；中英文之間自動加空格（預設關，v0.5.0）。單按一下 Shift 在中文和英文之間切換（每個 App 各自記，游標旁短暫顯示「英」或「中」，換 App 或停打一陣子後打第一個字時也會顯示；組字區有字時保留，之後打的字母接在後面當英文；設定可關，v0.6.1 預設開，下一版起預設關；v0.6.1）。打的鍵不可能是注音時直接回退成原始按鍵（`ok`、`so`、`gta6`；快打時同一個字的注音鍵先後顛倒照注音處理，預設開，關掉後 `ls` 這類字也會回退），英文留在組字區；立刻按 Esc 變回注音（空白鍵之後才發現音節不存在、已成英文 token 的例外，要用 Backspace 修）；不再查英文單字表（v0.6.1）。下一版起，「重打同一個位置算英文」（`ok`、`rust`、`gta6` 這類字要靠它）和單按 Shift 都預設關：打錯注音後不刪、直接接著打下一個注音的習慣，會被前者當成英文；從舊版更新的人，這兩個設定一次重設為關，第一次打字時跳出一個說明視窗（`docs/spec/english-mixed.md` §10）。
- 改選後其他字不動；預測列與 ↓ 的候選一致、未進入的預測列前面有 ⇥ 提示；逐字改選拼出的 2–4 字詞學成新詞（v0.5.0）。
- 安裝程式可選「這台 Mac」或「只有我的帳號」；輸入法在 App 沙盒裡執行，更新交給「善解更新」（v0.5.0）。
- 詞包的名字不再被通語的統計壓過：開著動漫詞包時，詞包裡的詞照詞包自己的分數排（例如打 ㄧ ㄌㄧˋ ㄙ 出「伊莉絲」）（v0.6.0）。
- 資訊與 AI 詞包（預設開，設定→選字→「詞包」可以關；輸入選單只列出已開啟的詞包）：1,016 個詞，來源是國教院的資訊名詞、維基百科的 CGroup 轉換表與 AI 分類條目、手寫清單；大陸用語不收，同音撞到既有常用寫法時既有的勝（v0.6.0）。
- 美妝與保養詞包（開發中，尚未發版；預設開，設定→選字→「詞包」可以關，輸入選單只列出已開啟的詞包）：保養、彩妝、香水、美髮的成分、質地、膚質、功效、產品俗稱與品牌中文名；只收出貨設定現在打不對的詞，539 個。
- 動漫詞包更新到 2026-10-22 的來源（44,552 詞）：「麗」在名字裡改讀 ㄌㄧˋ，同音寫法的順序先查作品與台灣譯名再定（v0.6.0）。
- 模糊輸入（預設全關）：ㄣ／ㄥ、ㄓ／ㄗ、ㄔ／ㄘ、ㄕ／ㄙ 四組模糊音與「鄰鍵打錯」（只適用標準排列）（v0.6.0）。
- 輕聲容錯（一律生效，沒有開關）：只有輕聲讀音的詞打成本調也打得出來；「紮」的口語讀音 ㄓㄚ，ㄐㄧㄝˊ ㄓㄚ 打得出「結紮」（v0.6.0）。
- 組字區最多留 128 個單位才把前段送出（之前 40，預設如此，不是開關）（v0.6.0）。
- 依按鍵順序判斷英文（v0.6.0 預設關，v0.6.1 起預設開）：打了聲調鍵才發現音節不存在時，整段變成英文。另有「快打時鍵序顛倒不當英文」（預設開，v0.6.1）：快打時同一個字的注音鍵先後顛倒（例如 ㄍㄜˋ 打成 ㄜㄍˋ）照注音處理、不變成英文；關掉之後 ls、mv 這類字不用按 Shift，但快打容易誤觸。
- 前文：輸入法讀取同一行、游標前最多 64 個字（預設如此），會意仍只用最後 2 個字（v0.6.0）。
- 經典台詞詞包（預設關，設定→選字→「詞包」）：208 列電影台詞（原句和常打的說法都收），每列對照過文字出處（v0.6.1）。
- 設定視窗固定 620 pt 高，螢幕放不下時縮到可見範圍、內容捲動（v0.6.1）。

## 安裝

需要 macOS 26（Tahoe）以上、Apple 晶片。下面兩種方式擇一；換方式時：從 Homebrew 換成安裝程式，先執行 `brew uninstall --cask nanako0129/tap/shanjie`；從安裝程式換成 Homebrew，先刪掉 `~/Library/Input Methods/善解輸入法.app`（裝給「這台 Mac」的那份，見下面的「解除安裝」）。Homebrew 只裝在你的帳號。

**Homebrew**

```sh
brew install --cask nanako0129/tap/shanjie
"$HOME/Library/Input Methods/善解輸入法.app/Contents/MacOS/shanjie" install
```

第二行在系統還不認得善解時註冊並啟用輸入方式；已經啟用的話什麼都不改。結束碼是 3 時，表示系統還沒接受：到「系統設定 → 鍵盤 → 輸入方式」按「+」，選「繁體中文」裡的「善解輸入法」，按「加入」。

v0.4.7 起善解會自己更新（見下面的「更新」），cask 標成 `auto_updates true`。**v0.4.6 以前用 Homebrew 裝的人要先手動升級一次**，之後交給善解自己更新：

```sh
brew upgrade --cask nanako0129/tap/shanjie
```

一般的 `brew upgrade` 可能略過標成 `auto_updates` 的 cask，所以要指名。之後想用 brew 升級，也一樣指名（`brew update` 只更新清單，不會換掉輸入法）。升級到 0.3.0 之後的版本時，brew 會在新版放好後結束舊的輸入法，系統下次啟動的就是新版。升級到 0.3.0 或更早的版本時，舊的還會繼續跑，要再執行：

```sh
pkill -f '^[^ ]*/Library/Input Methods/(善解輸入法|shanjie)\.app/Contents/MacOS/shanjie$'
```

升級後如果選單裡找不到善解，到「系統設定 → 鍵盤 → 輸入方式」把它加回來（升級時系統偶爾會把它移出已啟用清單）。

**手動**

從 [Releases](https://github.com/Nanako0129/shanjie/releases) 下載 `shanjie-<版本>.zip`（`v` 開頭的那幾個；`model-v…`、`classes-v…`、`kn-v…`、`tinylm-v…` 與之後改用新名稱的 `sj-…`（例如 `sj-cx-…`、`sj-sr-…`）是語言模型、詞類表、平滑側檔、三元表與語意校正用的小模型，已經包在 App 裡（`tinylm-v…` 從語意校正上線的版本起），不用另外下載，說明見 `docs/spec/models.md`），用 Finder 解壓，然後在這個 repo 的根目錄執行：

```sh
scripts/install-ime.sh <解壓出來的 善解輸入法.app 路徑>
```

也可以從 Releases 下載 `shanjie-installer-<版本>.zip`，解壓後點兩下「安裝善解輸入法」。v0.5.0 起歡迎頁有兩個並列的選項，沒有預設：

| | 這台 Mac | 只有我的帳號 |
|---|---|---|
| 位置 | `/Library/Input Methods`，檔案由系統保護 | `~/Library/Input Methods`（之前的方式） |
| 安全輸入 | 有程式開著安全輸入時（密碼管理器、終端機的「加密的鍵盤輸入」），善解照常能用 | 系統會暫時停用善解 |
| 安裝與更新 | 各要輸入一次管理員密碼 | 不需要密碼、一鍵更新 |
| 其他帳號 | 都能用 | 看不到 |

兩種之間可以重新打開安裝程式切換，學習資料與設定不受影響；換了位置之後要登出再登入一次（第一次裝給這台 Mac 時，登入後還要到系統設定加入，安裝程式最後一頁會寫步驟）。`scripts/install-ime.sh` 只裝在你的帳號；這台 Mac 已經有一份時，它會停下來並印出移除指令。

**解除安裝**：

- 只有我的帳號：`rm -rf "$HOME/Library/Input Methods/善解輸入法.app" "$HOME/Library/Input Methods/.shanjie-previous"`。
- 這台 Mac（要管理員）：`sudo rm -rf "/Library/Input Methods/善解輸入法.app" "/Library/Input Methods/.shanjie-previous"`。
- 學習資料與設定在每個帳號自己的 container，用過善解的每個帳號各自刪：`rm -rf "$HOME/Library/Containers/com.nyanako.inputmethod.shanjie"`。
- 最後到「系統設定 → 鍵盤 → 輸入方式」把善解移除，登出再登入一次。

裝好後在選單列的輸入法選單選「善解輸入法」；標準／倚天鍵盤在它自己的選單裡切換。選單裡的「善解設定…」會開一個設定視窗，選單上的各項設定都能在裡面改，另外有候選窗的方向（橫排或直排）與玻璃深淺。聊天／書面的切換方式（依 App 自動、一律聊天、一律書面）與選單裡「這個 App 用聊天設定」從 v0.4.1 起有；選單的「語意校正」（v0.4.1 起預設開）也可以在這裡關掉。

**更新**（v0.4.7 起）：設定的「關於」頁有版本、內附模型的列表（「模型」一節，v0.5.0 起）、「自動檢查更新」（預設開）與「立即檢查」。開著時善解每天最多連線一次，到 GitHub 讀取有沒有新版本（只讀一個更新清單，不送出任何輸入內容）；有新版本時，「關於」頁多一顆「更新到 X」、輸入選單多一項「有新版本 X，按此更新…」，按下才下載，安裝前驗證簽章。善解不會自己跳出視窗，也不會沒經過你按下就安裝。關掉「自動檢查更新」之後，只有按「立即檢查」才會連線。
