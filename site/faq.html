安裝與切換

選單裡找不到善解

到「系統設定 → 鍵盤 → 輸入方式」按「+」，選「繁體中文」裡的「善解輸入法」，按「加入」。升級時系統偶爾會把它移出已啟用清單，照同樣步驟加回來。第一次裝給「這台 Mac」時，要先登出再登入一次，才加得進去。

善解反灰、只剩 ABC 能用

有程式開著「安全輸入」時（密碼欄、密碼管理器、終端機的「加密的鍵盤輸入」），macOS 會暫時停用裝在個人帳號的輸入法。離開密碼欄、或結束開著安全輸入的程式之後就會恢復。不想再遇到的話，用安裝程式重裝並選「這台 Mac」，有安全輸入時善解照常能用（見安裝）。

Caps Lock 切換不了任何輸入法

到「系統設定 → 輔助使用 → 鍵盤」打開「慢速按鍵」，按一次 Caps Lock，再關掉「慢速按鍵」。

更新後某個 App 打不出字

把那個 App 完全結束（⌘Q）再打開。

打字與選字

改選過一次，那個字之後一直跑出來

選字記憶依前文分開記，單一個字只在前文相同時才套用。不想要某個記住的詞時，在候選窗選到它按 ⌘⌫ 忘記它；輸入選單的「清除選字記憶…」會全部刪掉，刪之前會先確認。見選字記憶。

想打注音卻變成英文，或想打英文卻變成注音

  • 打的鍵不可能是注音時，善解會直接變回原本打的英文（ok、gta6）。變錯了就立刻按 Esc，變回注音。
  • 快打時同一個字的注音鍵先後顛倒（例如 ㄍㄜˋ 打成 ㄜㄍˋ），「快打時鍵序顛倒不當英文」開著時照注音處理；這時 ls、mv 這類字要按 Shift 打。
  • 這幾個開關在設定 → 選字；單按 Shift 切換中英也可以在設定裡關掉。見中英混打。

在 Google 文件裡，預測列或「英／中」提示跑到視窗左上角

Chrome 156 以前的 Google 文件會把第一個字的預測列擺到左上角；Chrome 157 起位置正確。還在用舊版 Chrome（或同代的 Edge、Brave 等）的話，到設定 → 選字打開「在瀏覽器裡，第一個字不顯示預測」，組字區只有一個字時就不顯示預測列。v0.6.1 這個開關預設開，v0.7.0 起預設關。組字區空著或只有一個字時的「英／中」提示在 Chrome 157 還沒量過，列在已知問題。

想關掉即時預測或語意校正

兩個都可以在輸入選單或設定視窗關掉；語意校正另有保守、標準、積極三段強度。見即時預測與語意校正。

回報

選錯的字、當掉或其他問題，到 GitHub Issues 開一個 issue；選錯的字用「選字錯誤」範本。請附上：

  1. 善解的版本（設定 → 關於）與 macOS 的版本。
  2. 在哪個 App 裡、用標準還是倚天鍵盤。
  3. 實際按的鍵（例如 su3cl3）與前一句（如果有；整句轉換會看前文）。
  4. 想打的句子，和善解給的結果。

issue 是公開的：不要貼密碼、私人訊息或不想公開的內容，換成意思相同的句子就好。
