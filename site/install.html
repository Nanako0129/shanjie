安裝善解輸入法

需要 macOS 26（Tahoe）以上、Apple 晶片。善解是開源軟體（Apache-2.0），除了檢查更新不連網。

安裝程式（推薦）

到 GitHub Releases 下載 shanjie-installer 開頭的 zip，解壓縮後打開「安裝善解輸入法」，照四個步驟：歡迎、安裝、到系統設定加入、試打。

到 GitHub Releases 下載最新版

歡迎頁有兩個並列的選項，沒有預設：

這台 Mac只有我的帳號
位置/Library/Input Methods，檔案由系統保護~/Library/Input Methods
安全輸入有程式開著安全輸入時（密碼管理器、終端機的「加密的鍵盤輸入」），善解照常能用系統會暫時停用善解
安裝與更新各要輸入一次管理員密碼不需要密碼、一鍵更新
其他帳號都能用看不到

兩種之間可以重新打開安裝程式切換，學習資料與設定不受影響；換了位置之後要登出再登入一次。第一次裝給這台 Mac 時，登入後還要到系統設定加入，安裝程式最後一頁會寫步驟。

Homebrew

Homebrew 只裝在你的帳號。

brew install --cask nanako0129/tap/shanjie
"$HOME/Library/Input Methods/善解輸入法.app/Contents/MacOS/shanjie" install

第二行在系統還不認得善解時註冊並啟用輸入方式；已經啟用的話什麼都不改。結束碼是 3 時，表示系統還沒接受：到「系統設定 → 鍵盤 → 輸入方式」按「+」，選「繁體中文」裡的「善解輸入法」，按「加入」。

第一次使用

  • 在選單列的輸入法選單選「善解輸入法」。選單裡找不到時，到「系統設定 → 鍵盤 → 輸入方式」按「+」，在「繁體中文」裡加入「善解輸入法」。
  • 標準／倚天鍵盤在善解自己的選單裡切換。
  • 選單裡的「善解設定…」打開設定視窗：選單上的各項設定都能在裡面改，另外有候選窗的方向（橫排或直排）與玻璃深淺。
  • 怎麼打字、每個功能的預設值與開關，見使用說明。

更新

設定的「關於」頁有版本、內附模型的列表、「自動檢查更新」（預設開）與「立即檢查」。開著時善解每天最多連線一次，到 GitHub 讀取有沒有新版本；有新版本時，「關於」頁多一顆「更新到 X」、輸入選單多一項「有新版本 X，按此更新…」，按下才下載，安裝前驗證簽章。下一版起，有新版本時也會發一則系統通知提醒（每天最多一則，可以在「關於」頁關掉）。善解不會自己跳出視窗，也不會沒經過你按下就安裝。連線的細節見隱私與資料。

  • v0.4.6 以前的版本還沒有自動更新，要照當初安裝的方式手動升級一次：安裝程式重新裝，或 brew upgrade --cask nanako0129/tap/shanjie（要指名，一般的 brew upgrade 可能略過這個 cask）。
  • 選字記憶和設定放在 App 外面，升級不會動到。
  • 升級後選單裡找不到善解時，到「系統設定 → 鍵盤 → 輸入方式」把它加回來。
  • 更新後如果某個 App 打不出字，把那個 App 完全結束（⌘Q）再打開。

換安裝方式

兩種方式不要混用。從 Homebrew 換成安裝程式，先執行：

brew uninstall --cask nanako0129/tap/shanjie

從安裝程式換成 Homebrew，先刪掉 ~/Library/Input Methods/善解輸入法.app；裝給「這台 Mac」的那份要用管理員刪（見下面的解除安裝）。

解除安裝與資料位置

只有我的帳號：

rm -rf "$HOME/Library/Input Methods/善解輸入法.app" "$HOME/Library/Input Methods/.shanjie-previous"

這台 Mac（要管理員）：

sudo rm -rf "/Library/Input Methods/善解輸入法.app" "/Library/Input Methods/.shanjie-previous"

學習資料與設定在每個帳號自己的沙盒資料夾，用過善解的每個帳號各自刪：

rm -rf "$HOME/Library/Containers/com.nyanako.inputmethod.shanjie"

最後到「系統設定 → 鍵盤 → 輸入方式」把善解移除，登出再登入一次。
