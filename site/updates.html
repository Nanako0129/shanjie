每週一段，新的在上面。標「已發佈」的可以從 Releases 或 Homebrew 更新；「已合併」的已進主線，不在 App 裡或還沒出新版本。

2026-10-30～10-31

v0.6.1：中英混打接回、單按 Shift、經典台詞詞包 已發佈

2026-10-31 發佈（說明：v0.6.1）。中英混打打得出 ok、gta6：打的鍵不可能是注音時直接變回原本打的英文，英文留在組字區；新開關「快打時鍵序顛倒不當英文」（預設開）讓快打時同一個字的注音鍵先後顛倒照注音處理，不會變成英文；「依按鍵順序判斷英文」改成預設開（PR #336）。單按一下 Shift 在中文和英文之間切換，游標上方短暫顯示「英」或「中」，每個 App 各自記；換 App 或同一個 App 停打 30 秒以上之後，開始打字的第一個鍵也會提示一次（預設開，設定可關，PR #336）。

經典台詞詞包（預設關，設定 → 選字 →「詞包」）：208 列電影台詞（電影原句和網友常打的說法都收），每列對照過文字出處（PR #272）。在 Chrome、Edge 等瀏覽器裡，組字區只有一個字時不顯示預測列，因為 Google 文件會把它擺到視窗左上角（預設開，設定可關，PR #334）。設定視窗固定 620 pt 高，螢幕放不下時縮到可見範圍、內容捲動（PR #337）。

跨版本基準測試（v0.6.0 → v0.6.1，出貨設定）：十個集合在聊天與書面兩種設定下，每一句的選字都和 v0.6.0 相同；保留集口語半邊 124 → 124、新聞半邊 128 → 128。已知問題：Google 文件裡，組字區空著或只有一個字時，「英／中」的提示可能出現在視窗左上角。

瀏覽器清單加上 Crest 與 Aside 已合併

v0.6.1 之後唯一進 App 的改動（PR #341，2026-10-31）：使用者回報 Crest、Aside 裡第一個音節的預測列也跑到左上角，兩個 App 加進瀏覽器清單，和 Chrome 一樣第一個音節不顯示預測列。還沒出新版本；這兩個 App 實際的行為還沒有人看過，發版後請回報者確認。

2026-10-23～10-29

v0.6.0：新模型、資訊與 AI 詞包、模糊輸入 已發佈

2026-10-29 發佈（說明：v0.6.0）。換上一整組新模型：通語 SJ-LM-7-9.7M、辨類 SJ-WC-6-512C、承接 SJ-KN-2-397K、會意 SJ-SR-7-15M、常談 SJ-CL-2-69K；連文分成兩張，書面 SJ-CX-2-7.7M、聊天 SJ-CX-2-950K（聊天設定第一次用到前兩個詞）（PR #324）。錯字回報（出貨設定，80 句）：聊天 33 → 70 句、書面 29 → 61 句。語意校正不會再把你手動加進詞庫的詞換掉，例如書面設定的「米雅歌」不再被改成「米亞哥」。

詞庫與詞包：資訊與 AI 詞包（預設開）1,016 個詞，例如「圖像生成」（PR #275），開關搬到設定 → 選字 →「詞包」；動漫詞包更新到 2026-10-22 的來源，共 44,552 詞（PR #274）；網路用語 507 條常用說法與第二輪 910 個詞直接收進詞庫（PR #281、#303）；補了 119 個實況主、YouTuber、節目與頻道名、店家餐廳飯店企業 225 個、台灣以外的中文圈人名 14 個（PR #295、#302、#305）。

打字的改進：模糊輸入（設定 → 選字，預設全關）有 ㄣ／ㄥ、ㄓ／ㄗ、ㄔ／ㄘ、ㄕ／ㄙ 四組模糊音與「鄰鍵打錯」，鄰鍵只適用標準排列（PR #273）；只有輕聲讀音的詞打成本調也打得出來（PR #309）；ㄐㄧㄝˊ ㄓㄚ 打得出「結紮」（PR #269）；組字區最多留 128 個單位才把前段送出，51 字的長句整句留在組字區（PR #268）；聊天設定的保守、積極兩檔也用上常談與讀音項（PR #271）；輸入法讀取同一行、游標前最多 64 個字當前文，會意仍只用最後 2 個字（PR #294）；依按鍵順序判斷英文（預設關，快打時鍵序顛倒的情況還沒量過，PR #311）；密碼框的說明改成描述用途（PR #267）。

跨版本基準測試（v0.5.0 → v0.6.0，出貨設定）：聊天的 Discord 聊天評測集（4,958 句）87.90% → 93.69%（改對 336、改壞 49）、cvtune（3,791 句）91.93% → 93.12%（95／50）、dev302 89.07% → 92.72%（14／3，p 0.013）；書面的 Discord 聊天評測集 86.06% → 92.54%（396／75）、cvtune 91.80% → 92.96%（104／60）、dev302 87.75% → 89.74%（15／9，p 0.31，不顯著）。打字測驗（76 句）：聊天 72 → 74（2／0）、書面 69 → 74（5／0）。維基段落（wikitune）兩種設定各少約 24 句（聊天 77.26% → 76.41%，80／104，p 0.09；書面 80.16% → 79.34%，78／101，p 0.10，都不顯著）。保留集（發版前量一次，兩個半邊是新換的集合）：口語半邊（聊天，150 句）115 → 124（10／1，p 0.012）、新聞半邊（書面，150 句）125 → 128（3／0，p 0.25，不顯著）。速度與記憶體（同一場輪流跑，開跑時 load avg 5.8，不是閒置窗，只能看兩版的差距）：每鍵 p95 2.06 → 2.23 毫秒，引擎載入 892 → 945 毫秒，記憶體 441 → 480 MB，語意校正 p95 8.3 → 8.6 ms。各集合的完整數字在 docs/benchmark.md。

已知問題：資訊與 AI 詞的檢查集聊天 46 → 36、書面 39 → 27；開著 ㄓ／ㄗ 時「ㄗ ㄉㄠˋ ㄌㄜ˙」仍是「資到了」；聊天設定「長歪了」仍選成「掌歪了」（書面設定是對的），原因是讀音通道項對「長」讀ㄓㄤˇ扣了分，下一版修。更新後如果某個 App 打不出字，請把那個 App 完全結束（⌘Q）再打開。

2026-10-19～10-22

v0.5.0：聊天更懂口語、這台 Mac、App 沙盒 已發佈

PR #250、#251（常談、讀音通道項）、#240（這台 Mac）、#225、#238（App 沙盒、善解更新）、#201（數字列）等，2026-10-22 發佈（說明：#258）。聊天設定的語意校正多參考口語詞頻表「常談」（SJ-CL-1-68K），也看打的讀音是不是那個字常見的讀法：「桌腳的螺絲鬆掉了」「是不是很雷啊」「變快」上一版選成「羅斯松」「很累」「便會」，這一版都選對（這一版的常談與讀音在語意校正強度保守、積極時沒有生效，之後的版本補上，三種強度都生效）。書面設定的語意校正重選融合參數（會意 SJ-SR-6-14M，權重和上一版相同，聊天的參數不變）。

安裝程式可以選「這台 Mac」（裝到 /Library/Input Methods，每個帳號都能用，有程式開著安全輸入時照常能用，安裝與更新各要一次管理員密碼）或「只有我的帳號」。輸入法本體在 App 沙盒裡執行，更新由不在沙盒裡、只會更新善解的「善解更新」完成。

打字的改進：標準排列、中英混打開著時數字列直接打數字（「2026年1月15日」「3.14」，「下午3」之後預測列接「點」）；中英混打（實驗）改成預設開；改選後其他字不動；預測列與 ↓ 的候選一致；逐字改選拼出的 2–4 字詞會學成新詞；中英文之間自動加空格（預設關）；「關於」頁列出內附的六個模型。

跨版本基準測試（v0.4.7 → v0.5.0）：兩種設定都沒有集合顯著變差；聊天的 Discord 聊天評測集 +88／−34、書面的 wikitune +39／−5。保留集（300 句）：聊天 234 → 237、書面 233 → 241。

v0.4.2：選字記憶的修正 已發佈

語意校正預設開 已發佈

PR #129、#130，2026-10-13 合併，v0.4.1 發佈（2026-10-13）。模型是 tinylm-v3（1,440 萬參數，本機執行，只在前 8 名候選之間挑，不產生新字）。

聊天設定的參數用維護者自己的聊天訊息選，計分是「改對 − 改壞」，改壞率上限 0.5%。選值時沒用到的月份（2026-08，6,559 個子句）：改對 125、改壞 16。保留的評測句（227 句）聊天設定：改對 11、改壞 0。

例子：我等一下在過去 → 我等一下再過去。語意校正要「避免把敏感字詞排在前面」開著才作用。

聊天／書面可以自己選 已發佈

PR #121，2026-10-12 合併，v0.4.1 發佈（2026-10-13）。設定視窗可選「依 App 自動」（預設）、「一律聊天」、「一律書面」；依 App 自動時，選單可替目前的 App 切換，設定視窗列出改過的 App、可以移除。

動漫詞包 已發佈

PR #111，2026-10-13 合併，v0.4.1 發佈（2026-10-13）。含間隔號的名字（例如「洛琪希·米格路迪亞」）把名和姓分開收；新增「獄門疆」、補上「虎杖悠仁」的讀音；名字裡的「唯」改讀 ㄨㄟˊ。

詞包從約 3 萬詞增加到約 4.5 萬詞。

錯字回報與解碼器的合併問題

這週加了第 73–87 列，共 15 句（2026-10-12～13；PR #127、#128、#131、#133、#135、#136）。這些句子只用來評測，不拿來訓練。

從「夏來分析」（應為「下來分析」）找到解碼器的合併問題：每個位置同一個字串只留一條路徑，會丟掉接下去更好的拆法。試驗在公開調參集上淨改對 +3 到 +7 句。原本排成 v0.4.2 的第一片，2026-10-14 改跟 v0.4.3 出（v0.4.2 先單獨發選字記憶的修正），同日發佈。
