善解輸入法

善解，所以選對。

一個開源的 macOS 注音輸入法，專心把同音字選對：看懂你前面寫了什麼，選出你真正要打的那個字。

macOS 26 以上・Apple 晶片・開源 Apache-2.0

看前文，選對同音字

注音輸入最常見的困擾不是打不出字，而是打出了「同音的另一個字」。

怎麼做到

每一鍵：整句解碼

詞庫與語言模型在本機列出候選，也看每個字的讀音對不對得上你打的音，接著前文選出整句。

停頓時：語意校正

小模型看前文，在背景從前 8 名裡挑最通順的一句，不產生新字。

改選時：記住

你改選的字依前文記住，只存在這台 Mac。

善解怎麼選字 →

現在有的

  • 看前文選字：接著游標前已經送出的字選。
  • 即時預測：打第一個注音就列出接得上的詞，按 Tab 選。
  • 選字記憶：依前文記住你的改選，可以逐詞忘記。
  • 聊天與書面：依 App 自動切換，也可以自己選。
  • 語意校正：保守、標準、積極三段，可以關。
  • 中英混打：打英文不用切換輸入法；ok、gta6 這類字與單按 Shift 切換中英，在設定裡打開。
  • 詞包：動漫與遊戲、資訊與 AI、美妝與保養、迷因、口頭禪與實況用語、經典台詞。
  • 模糊輸入：ㄣ／ㄥ、ㄓ／ㄗ 等四組，預設關。

安裝

需要 macOS 26（Tahoe）以上、Apple 晶片。兩種方式擇一。

安裝程式

從 GitHub Releases 下載 shanjie-installer 開頭的 zip，打開「安裝善解輸入法」照四個步驟。

推薦

Homebrew

brew install --cask nanako0129/tap/shanjie

留在這台 Mac

除了檢查更新，善解不連網。你打的字不寫進任何日誌。選字記憶只存在這台 Mac，可以忘記一個詞或全部清除。
