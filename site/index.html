善解

善解，所以選對。

一個開源的 macOS 注音輸入法，專心把同音字選對：看懂你前面寫了什麼，選出你真正要打的那個字。
開放下載

為什麼要做

注音輸入最常見的困擾不是打不出字，而是打出了「同音的另一個字」。

ㄔㄤˊ ㄔㄤˊ
常常嚐嚐
改選過一次「嚐嚐」，之後每句都被搶走
ㄋㄚˋ ㄅㄧㄢ
那邊納編
詞頻來自新聞語料，口語反而排在後面
ㄕˋ ㄐㄧㄥˋ ㄅㄨˋ
拭鏡布是竟不
詞庫沒收的日常用語，只能一字一字湊

怎麼做

三層分工：每一次按鍵都在本機即時完成，語意判斷只在需要時加入，而且只能從本機的候選裡挑。

候選生成

詞庫與語言模型在本機產生前 64 名候選，每一鍵都要在 16 毫秒內完成。

每次按鍵・本機

本機重排

小型語言模型看你前面寫的內容，從候選中挑出最合理的一句；在背景執行，不拖慢打字。

停頓或送出前・本機

雲端校正（選用）

打完按一下快速鍵，請雲端模型再看一次。預設關閉；雲端只能回傳候選的編號，不能自己寫字。

你按下快速鍵時・雲端

第 2 層從 v0.4.1 起出貨：約 1,465 萬參數的小模型（會意，v0.6.0 是 SJ-SR-7-15M）重排前 8 名，輸入法的「語意校正」沒設過時是開的。v0.5.0 起，聊天設定的這一層另外參考口語詞頻表「常談」與單字的讀音：v0.5.0 只在強度「標準」生效，v0.6.0 起保守與積極也生效，各用自己量過的值。現成的本機大模型研究結論是暫不進輸入法。第 3 層還沒做，排在路線圖的「未排定」。

這些數字怎麼量的

評測分成開發集與保留集。開發集用來調整；保留集由另一個流程撰寫、開發過程中不看內容，只在每個階段結束時量一次，用來確認進步不是因為「背了題目」。前 64 名含正解的比例用寬鬆對照：「她／他」「臺／台」這類寫法視為相同；保留集的 99.6% 是用 model-v2 在舊保留集（227 句）上量的，之後沒有重新量；只有詞庫、還沒有語言模型時，舊保留集是 97.8%（完全相符）。保留集用多了等於間接調參，所以 2026-10-16 換成新的一份（300 句，新聞與口語各半，來源見「開源與授權」），舊的那份改當開發用的挑戰集。2026-10-29 起新聞那一半改成不公開的報社新聞與維基新聞（只在本機驗證），repo 裡的保留集只剩口語的 150 句。新舊幾份的句子不同，數字不能直接比。

判斷器比較了本機模型與多家雲端服務的三十多組設定；所有判斷器都卡在同一個上限：正解根本不在候選裡的句子，誰也救不回來。所以目前的重點是先把正解放進候選。

輸入法實際送出整句的正確率，v0.6.0（換上通語 SJ-LM-7-9.7M、會意 SJ-SR-7-15M 等一整組新模型）在 2026-10-29 發版前量了保留集的兩個半邊，都是出貨設定：口語半邊（聊天設定，150 句）v0.5.0 的 115 句 → 124 句（改對 10、改壞 1，p 0.012）；新聞半邊（書面設定，150 句，不公開的報社新聞與維基新聞，只在本機驗證）125 句 → 128 句（改對 3、改壞 0，p 0.25，不顯著）。這兩份是新換的 150 句集合，v0.5.0 的數字是這兩份上重量的，下面 300 句的數字是另一份集合，不能直接比。以下是更早的版本：v0.5.0（聊天加上口語詞頻表「常談」與讀音通道項、書面換語意校正的參數）在新的保留集（300 句）上是聊天設定 79.0%（237／300，比 v0.4.7 多 3 句，改對 7、改壞 4，不顯著）、書面設定 80.3%（241／300，多 8 句，改對 8、改壞 0，p 0.008），2026-10-22 發版前量的。v0.4.7（書面設定加上三元表）在新的保留集（300 句）上是聊天設定 78.0%（234／300，和 v0.4.6 相同）、書面設定 77.7%（233／300，比 v0.4.6 多 3 句，改對 7、改壞 4，不顯著），2026-10-17 發版前量的。以下是舊保留集（227 句）上的數字：v0.4.6（詞類表換成 classes-v5）是聊天設定 84.1%（191／227，和 v0.4.5 相同，改對 3、改壞 3）、書面設定 82.4%（187／227，多 1 句，不顯著），2026-10-16 發版前量的。保留集上 v0.4.5 和 v0.4.4 相同（v0.4.5 只改中英混打、選字沒有變，2026-10-16 發版前量的），都是聊天設定 84.1%（191／227）、書面設定 81.9%（186／227，比 v0.4.3 少 3 句，不顯著），用的是 v0.4.4 出貨的模型與設定（model-v6、看前文、動漫詞包、語意校正 tinylm-v5），2026-10-15 發版前量的；v0.4.3 是 84.1%（191／227）與 83.3%（189／227）；v0.4.1 與 v0.4.2 是 84.1%（191／227）與 82.4%（187／227）；v0.4.0 用同樣的量法是 79.3%（180／227）與 81.1%（184／227）。各版本的數字在 docs/benchmark.md。

每個按鍵的處理時間是 76 句打字測驗共 2,483 個按鍵的 p95，2026-10-10 在 M5 Mac、低負載下量了兩次：教過選字並放 5 萬筆記錄是 2.2–2.5 毫秒，記憶是空的是 2.3–2.6 毫秒。這是在可省略韻母那一片（PR #98）量的，用的是 model-v4，也沒有載入動漫詞包（計時測試只在設定 ACG_PACK 時才載入詞包）；之後沒有用同一個量法重量。v0.4.7 發版前在閒置的機器上重播 dev302 五輪，每鍵 p95 的中位數聊天 2.85 毫秒、書面 2.86 毫秒（量法不同，不能和上面直接比）；v0.5.0 發版前和 v0.4.7 在同一台機器同場輪流量，每鍵 p95 是 2.05 與 2.00 毫秒，但當時機器負載約 4，只能看兩版的差距。v0.6.0 發版前和 v0.5.0 同場輪流量，每鍵 p95 是 2.06 → 2.23 毫秒（聊天設定），引擎載入 892 → 945 毫秒，記憶體（RSS）441 → 480 MB；開跑時機器的負載 5.8，不是閒置窗，也只能看兩版的差距。

安裝

需要 macOS 26（Tahoe）以上、Apple 晶片。兩種方式擇一。

安裝程式

到 GitHub Releases 下載 shanjie-installer 開頭的 zip，解壓縮後打開「安裝善解輸入法」，照四個步驟：歡迎、安裝、到系統設定加入、試打。v0.5.0 起歡迎頁有兩個選項：

  • 這台 Mac：每個帳號都能用，有程式開著安全輸入時善解照常能用；安裝和每次更新都要輸入一次管理員密碼。
  • 只有我的帳號：不需要密碼、一鍵更新；有程式開著安全輸入時，系統會暫時停用善解。
推薦

Homebrew

brew install --cask nanako0129/tap/shanjie
"$HOME/Library/Input Methods/善解輸入法.app/Contents/MacOS/shanjie" install

Homebrew 只裝在你的帳號。第二行在系統還不認得善解時註冊；結束碼是 3 時，到「系統設定 → 鍵盤 → 輸入方式」按「+」，選「繁體中文」裡的「善解輸入法」，按「加入」。升級用 brew upgrade --cask nanako0129/tap/shanjie。

兩種方式不要混用。從 Homebrew 換成安裝程式，先執行 brew uninstall --cask nanako0129/tap/shanjie；從安裝程式換成 Homebrew，先刪掉 ~/Library/Input Methods/善解輸入法.app；裝給「這台 Mac」的那份要用管理員刪：sudo rm -rf "/Library/Input Methods/善解輸入法.app" "/Library/Input Methods/.shanjie-previous"。

已經裝過舊版

v0.4.7 起可以在輸入法裡更新（設定的「關於」頁，或輸入選單的「更新到 X」）；更早的版本照當初安裝的方式升級。選字記憶和設定都放在 App 外面（v0.5.0 起搬進沙盒的資料夾），升級不會動到。升級後輸入法選單找不到善解時，照上面的系統設定步驟加回來。Caps Lock 切換不了任何輸入法時，到「系統設定 → 輔助使用 → 鍵盤」打開「慢速按鍵」，按一次 Caps Lock，再關掉。

設計原則
  • 更新檢查（v0.4.7 起）：設定→關於的「自動檢查更新」開著時，每天最多一次連到 GitHub（raw.githubusercontent.com）讀取更新清單 appcast.xml。GitHub 會看到你的 IP 位址與請求標頭：User-Agent 裡有善解與 Sparkle 的版本號，Accept-Language 是你系統的語言偏好（例如 zh-TW），其餘是一般的連線標頭。不送出任何輸入內容、選字記憶或其他系統資訊。自動檢查可以在設定→關於關掉；按「立即檢查」時一定會連線。按「更新到 X」時先再讀一次更新清單，然後從 GitHub Releases 下載新版（github.com，轉到 release-assets.githubusercontent.com），安裝前驗證 EdDSA 簽章；正式版另經 Apple 公證。v0.5.0 起由不在沙盒裡、只會更新善解的「善解更新」下載與安裝。
  • 除了更新檢查，目前版本沒有其他連網功能。之後如果加入雲端校正，會在上線前寫在這一頁：什麼時候連線、送出什麼、能不能關閉。
  • v0.5.0 起輸入法在 macOS 的 App 沙盒裡執行，只開三個權限：沙盒本身、對外連線（只為了檢查更新）、註冊輸入法的連線。沙盒擋不住輸入法把輸入內容送出去；它限制的是程式被攻破時碰得到的檔案與程式。
  • 不申請「輸入監控」與「輔助使用」權限。系統的輸入法框架本來就會把按鍵交給輸入法，不需要監看整個系統。
  • 用了哪些資料與模型、各自的授權，下載前就寫在這一頁（見「開源與授權」）。
  • 雲端功能預設關閉；開啟後只在你按快速鍵或送出時傳送，不會逐鍵傳送。
  • 雲端只能回傳候選的編號，不能產生文字；回應不合規就直接用本機結果。
  • 密碼欄、安全輸入模式下停止學習與雲端；終端機不傳送到雲端。
  • 你打的內容不寫進任何日誌或錯誤訊息。
  • 善解只在你用候選窗改字、或從預測列選詞時學習，學習檔只存在這台 Mac。檔案裡有：你選的詞和它前面最多 2 個漢字；你逐字改選拼出來的 2–4 字新詞，包括一起送出、但你沒改選的相鄰字（可能包含人名）；讀音、權重和日期。之後再打到這個新詞，會更新它的權重和日期。在候選窗按 ⌘⌫ 可以忘記一個詞（新詞的單字改選紀錄要另外忘記），選單的「清除選字記憶…」會全部刪掉。學習檔不受 macOS 的隱私權限保護，靠 FileVault 加密；預設會進 Time Machine，可以在選單排除；清除不會刪掉已經備份的副本。
